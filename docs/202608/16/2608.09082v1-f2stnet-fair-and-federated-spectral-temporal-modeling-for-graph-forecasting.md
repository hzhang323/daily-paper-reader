## 摘要
图结构数据上的时空预测是交通流量预测和环境监测的核心问题，然而分散且异质的数据使得序列建模和协作训练均面临挑战。我们提出了F$^2$STNet，一个联邦预测框架，结合了截断图傅里叶特征、轻量级对角状态空间时域编码器、图卷积以及公平感知联邦聚合（FFA）。谱分支揭示图频率结构，而状态空间层以序列长度的线性复杂度建模长时间依赖。FFA利用客户端验证损失和递增公平调度调整FedAvg先验。在PeMS04、HZMetro和KnowAir上的实验表明，相对于所评估的基线，预测准确性更优；在PeMS04上的联邦实验进一步改善了最差客户端和客户端分散度指标。

## Abstract
Spatiotemporal prediction on graph-structured data is central to traffic forecasting and environmental monitoring, yet decentralized and heterogeneous data complicate both sequence modeling and collaborative training. We propose F$^2$STNet, a federated forecasting framework that combines truncated graph-Fourier features, a lightweight diagonal state-space temporal encoder, graph convolution, and Fairness-aware Federated Aggregation (FFA). The spectral branch exposes graph-frequency structure, while the state-space layer models long temporal dependencies with linear complexity in the sequence length. FFA adjusts the FedAvg prior using client validation losses and an increasing fairness schedule. Experiments on PeMS04, HZMetro, and KnowAir show favorable forecasting accuracy relative to the evaluated baselines; federated experiments on PeMS04 additionally improve worst-client and client-dispersion metrics.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

F2STNet 整体由三大核心模块组成。

### 2.1 谱投影（Spectral Projection）

- 利用共享图拓扑（全局邻接矩阵 A）计算归一化图拉普拉斯矩阵的截断特征分解，保留前 F 个特征向量构成 U_F ∈ R^{N×F}。
- 将每个节点的图信号投影到该截断傅里叶基上，得到图频率系数 c_{b,t,f}；再将频率贡献逐节点映射回节点级向量 S_{b,t,n,f} = (U_F)_{n,f} · c_{b,t,f}。
- 通过共享 MLP（两层线性层 + GELU）将每个节点的频率向量嵌入到 d_s 维，并与原始输入拼接后投影到模型宽度 d。该谱分支能够显式揭示图的低频/高频结构信息。

### 2.2 状态空间时序建模（State-Space Temporal Modeling）

- 采用**对角线性状态空间模型**（Mamba 风格），对每个节点独立进行时序编码。
- 关键公式（零阶保持离散化）：
  - Ā_{b,t,n} = exp(Δ_{b,t,n} ⊙ A)
  - B̄_{b,t,n} = (Ā_{b,t,n} − 1) ⊘ A ⊙ B_{b,t,n}
  - h_{b,t,n} = Ā_{b,t,n} ⊙ h_{b,t−1,n} + B̄_{b,t,n} ⊙ z_{b,t,n}
  - o_{b,t,n} = Cᵀ_{b,t,n} h_{b,t,n} + D ⊙ z_{b,t,n}
- A 被参数化为负值以保证稳定性；Δ、B、C 由输入动态生成（输入依赖）。取最后一个时间步的隐状态作为时序嵌入 H_temp。
- 该模块计算复杂度为 O(T)（序列长度线性），远低于 Transformer 的 O(T²)。

### 2.3 图卷积（Spatial Modeling）

- 将时序嵌入 H_temp 输入单层 GCN：H_spatial = σ(D ̃^{-1/2} Ã D ̃^{-1/2} H_temp W_gcn)，用于捕捉节点间空间依赖。
- 最终通过线性层输出未来 H 步的预测值，使用 MSE 损失进行优化。

### 2.4 公平感知联邦聚合（FFA, Fairness-aware Federated Aggregation）

- 每个客户端在本地训练后，在本地验证集上计算验证损失 L_t^k。
- 计算相对损失偏差：r_t^k = (L_t^k − L̄_t) / max(L̄_t, ε)。
- 定义公平感知权重：q_t^k = p_t^k · (1 + λ_t · r_t^k)，其中 p_t^k 为 FedAvg 先验（样本量占比），λ_t 控制公平调整强度。
- 归一化后得到最终聚合权重 w_t^k，用于全局模型参数加权平均。
- 该机制使验证损失高于平均的客户端获得更大权重，低于平均的客户端权重略微减少，从而改善劣势客户端表现。

### 2.5 动态 λ 调度（Reverse-Annealing）

- λ_t = min(λ_max, λ_init + ηt)，即随训练轮次线性递增。训练早期 λ 小、侧重全局收敛；训练后期 λ 增大、逐步强化公平性。
- 默认配置：λ_init = 0.03，η = 0.005，λ_max = 0.2。

## 6. 论文的主要结论与发现

1. **集中式预测精度**：F2STNet 在 PeMS04 和 KnowAir 上全面优于所有基线（RMSE、MAE、MAPE 三项均最佳），在 HZMetro 上取得最优 MAE。尤其是在 KnowAir 上的表现突出，验证了方法的适应性。

3. **消融结论**：三个模块均有贡献，其中**时序模块的贡献最大**（移除后性能下降最明显），谱模块和公平聚合模块也能带来稳定增益。
4. **效率优势**：以极低的参数量（<1.2M）和 FLOPs（2.1G）取得了优于复杂模型的效果，说明轻量化方案在时空预测中是可行的。
5. **收敛特性**：F2STNet 训练收敛更快更稳定，且反向退火（reverse annealing）的λ调度优于固定λ和无公平策略。

## 7. 优点

1. **创新性的整体设计**：将谱域特征提取、线性状态空间建模与公平感知聚合三者有机结合，填补了联邦时空预测中的系统性空白。
2. **轻量高效**：以<1.2M参数量实现了SOTA级别的预测精度，计算复杂度为O(T)（时序维度线性），非常适合资源受限的联邦环境。
3. **公平性机制设计精巧**：
   - 使用验证损失而非训练损失，避免直接奖励本地过拟合；

4. **无需保护属性**：直接基于损失分布调整权重，不需要人口统计信息或敏感分组属性，适用范围更广。

6. **谱模块零运行时开销**：图傅里叶基可离线预计算，不增加推理负担。
