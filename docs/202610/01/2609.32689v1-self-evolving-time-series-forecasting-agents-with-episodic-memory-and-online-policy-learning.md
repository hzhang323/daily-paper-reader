## 摘要
基于LLM的智能体正越来越多地用于时间序列预测，因为它们能够组织上下文信息、执行多步分析，并引导完成预测任务所需的动作序列。大多数现有智能体只关注当前预测实例。然而，在实际部署中，预测通常以在线方式运行：随着预测原点前移，新的预测基于当前可用的历史数据发布，而较早实例的真实目标值也逐渐可用。这些目标值为较早实例中采取的动作提供了反馈，但现有智能体通常不会保存或利用这些信息来调整其后续动作。为解决这一局限，我们提出FASE，一种反馈感知的自进化预测智能体，它将此类反馈转化为用于后续预测实例的任务特定经验。FASE结合了情景记忆与在线策略学习：前者检索相关的已完成实例，后者将跨实例累积的反馈总结为排序指导。所提出的框架在从GIFT-Eval基准中选出的29个数据集配置上进行了评估。在这29个配置上，FASE在所评估方法中取得了最强的聚合点预测性能，并且相对于最佳单一基础模型基线将归一化MAE降低了9.1%。结果进一步表明，随着延迟反馈的累积，FASE的累积优势会增加。总体而言，这些发现表明，FASE能够通过已完成预测实例的反馈持续自进化，而无需更新LLM的参数。

## Abstract
LLM-based agents are increasingly used for time-series forecasting because they can organise contextual information, perform multi-step analysis, and guide the sequence of actions required to complete forecasting tasks. Most existing agents focus only on the current forecasting instance. However, in real-world deployments, forecasting commonly operates online, with new forecasts issued from the currently available history as the forecast origin advances and the ground-truth targets of earlier instances progressively become available. These targets provide feedback on the actions taken in earlier instances, yet existing agents generally do not preserve or utilise this information to adapt their subsequent actions. To address this limitation, we introduce FASE, a Feedback-Aware Self-Evolving forecasting agent that converts such feedback into task-specific experience for subsequent forecasting instances. FASE combines episodic memory, which retrieves relevant completed instances, with online policy learning, which summarises the feedback accumulated across instances into ranking guidance. The proposed framework is evaluated on 29 dataset configurations selected from the GIFT-Eval benchmark. Across these 29 configurations, FASE attains the strongest aggregate point forecasting performance among the evaluated methods and reduces the normalised MAE by 9.1% relative to the best individual foundation model baseline. The results further indicate that the cumulative advantage of FASE increases as delayed feedback accumulates. Together, these findings demonstrate that FASE can continually self-evolve through feedback from completed forecasting instances without updating the parameters of the LLM.

## 2. 方法论

### 2.1 核心思想
- 提出 **FASE（Feedback-Aware Self-Evolving forecasting agent）**，在固定工具库（Seasonal Naive + 5 个时序基础模型）之上维护两种**外部状态**：
  - **情景记忆（Episodic Memory）**：即时纳入每个已完成实例，按上下文相似度检索，提供"相似情境下各工具表现"的细粒度证据。
  - **在线策略学习（Online Policy Learning）**：周期性聚合跨实例反馈，产出当前历史下工具表现的**预测排序**作为粗粒度指导。
- 每个预测实例：LLM 融合"任务上下文 + 统计表示 + 检索记忆 + 策略排序 + 工具描述"选择**一个**工具输出点预测与分位数预测；其余工具也在同一历史上并行运行但不提供给 LLM。真值揭晓后，计算全部工具误差，反馈同时写入记忆与策略。

### 2.2 关键技术细节

- **统计表示**：不把原始长序列喂给 LLM（token 开销大且语义弱），而是用 **18 个统计特征**压缩描述历史（数据质量、趋势、水平/尺度变化、结构突变、非线性复杂度、谱结构、稳定性、缺失结构、周期性、协变量关系、间歇性等），存于记忆条目并随 prompt 提供。

- **情景记忆机制**：
  - 采用**统计距离**度量相似度，对各特征组内归一化偏差取均值，并用 $\rho(z)=z/(1+z)$ 做有界变换抑制极端值影响。
  - 用**保留值（retention value）**刻画条目代表性：对每个"工具使用 + 最优排名工具集合"划分 $C$，以最近邻 $j^{(1)}$ 与次近邻 $j^{(2)}$ 的距离差定义贡献 $\delta_{i,j}$（$|C|=1$ 时为 $1-d$），保留值取历次贡献的**滑动平均**。
  - **双池结构**：recent pool（容量 100）+ long-term pool（容量 900）；新条目先进 recent，溢出时最旧条目按保留值决定晋升/淘汰；每次检索 10 条。

- **在线策略学习**：
  - 输入 $z_i=[\text{Normalise}(x_i),\text{Mask}(x_i)]\in\mathbb{R}^{2N}$（最近 $8H$ 个观测 + 观测掩码），预测器为轻量 MLP $g_\theta:\mathbb{R}^{2N}\to\mathbb{R}^{|F|}$，输出各工具相对分数，升序排列即为工具排序（分数越低表示预期点误差越小），转成文本给 LLM。
  - **FIFO 反馈池**容量 3000；累计 100 个实例后初始化训练（10 个 epoch），此后每完成 25 个有效实例更新一次（25 个 minibatch × 256 条均匀采样）。
  - **成对排序损失**：对工具对 $(p,q)$ 用 softplus 加符号项，使点误差更低的工具获得更低分数，并以 $|\ell_p-\ell_q|/\bar{\ell}$ 对误差差异大的对加权。
  - 优化器 AdamW，学习率 $10^{-3}$，权重衰减 $10^{-5}$。

- **更新时序**：真值揭晓 → 计算所有工具点/概率误差 → 更新记忆条目的保留值并插入新条目 → 策略按周期更新 → **从下一个实例起生效**。

## 6. 主要结论与发现

- **点预测性能最强**：FASE 在 MASE、MAE、RMSE 上均取得最低归一化误差与最低平均排名；相对最强单模型 TiRex-2 分别降低 **6.8% / 9.1% / 5.0%**，相对最强固定集成 Uniform Ensemble 降低 **7.1% / 10.8% / 5.6%**。
- **概率预测优势不明显**：CRPS 为 0.497，**低于 TiRex-2 的 0.489**，且平均排名略逊于 Uniform Ensemble——与反馈机制偏重点误差、概率误差仅作辅助的设计一致。
- **跨预测长度稳定**：长/中/短期三组 MASE 相对 TiRex-2 分别降低约 6.0% / 6.2% / 7.3%；但 CRPS 仅在短期最优、长期不领先。
- **可持续自进化**：累计相对增益从 25 个实例时的 **3.8%** 升至 100 个的 **6.7%**、500 个的 **8.6%**，说明后期实例**增强而非稀释**早期优势。
- **两机制互补**：Memory Only 与 Policy Only 单独均大幅优于 Base Agent（MASE 0.758 → 0.683 / 0.687），二者结合取得最佳点预测（0.679）；相对 Base Agent 的净改进为 **9.7%**（改进 11.9%，退化仅 2.2%）。
- **行为分析**：Memory Only 在 61.4% 实例上更好、20.0% 更差；Policy Only 为 63.1% / 24.2%；FASE 为 64.1% / 22.1%——表明两种信号都能改善工具使用，但**偶尔也会误导**（约 1/5 实例变差）。

## 7. 优点

- **问题设定新颖且贴合实际**：显式建模"延迟反馈"这一在线预测的真实特性，而非把预测视为彼此独立的静态任务。
- **双层反馈设计有层次感**：实例级细粒度证据（记忆

级）与跨实例聚合级（策略排序）**，粒度互补：前者回答"相似情境下哪个工具好"，后者回答"当前历史状态下整体该偏好哪个工具"。
- **机制设计精巧且轻量**：保留值用最近邻–次近邻距离差定义"代表性/独特性"，避免了简单的"按误差均值排序"，且以滑动平均平滑噪声；双池 + 溢出晋升策略在有限容量下同时兼顾近期分布漂移与长期经验。
- **对 LLM 输入做了工程化降维**：以 18 个统计特征替代原始长序列，既控制 token 成本，又把"历史形态"转成 LLM 更易推理的结构化语义，是 agentic 时序工作中务实的一步。
- **不更新 LLM 参数即可自适应**：所有学习都发生在外部的记忆与轻量 MLP 中，模型可替换、反馈闭环可插拔，工程上易于部署与回滚。
- **评估协议规范**：严格在线重放、记忆/策略按配置重置以避免信息泄漏、以 Seasonal Naive 归一化并跨配置几何平均，同时给出"配置内排名"这一对异常配置更稳健的补充视角；自进化轨迹用累计曲线而非单点终值来验证"越用越好"。
- **消融与行为分析到位**：四变体设计干净隔离了记忆与策略的贡献，并进一步用"改进/不变/退化"占比与分解表刻画收益来源，避免了"只报总分"的黑箱式汇报。

## 8. 局限与不足

- **缺乏理论刻画**：论文未对"延迟数值反馈下的自进化"给出任何形式化定义（如遗憾界、收敛条件、反馈延迟与策略更新周期的关系），也未分析记忆检索偏差或策略预测误差在闭环中的累积效应；在线策略学习的"排序质量"与最终预测精度之间只有经验关联，无理论桥梁。
- **反馈信号是纯标量的、无归因**：记忆与策略都只消费"哪个工具误差更小"这一数值信号，没有利用"为什么该工具在此情境下失败"（如是否因趋势突变、间歇性、尺度漂移）的语义信息。这使得约 1/5 的实例被误导后，系统难以诊断原因，只能等待后续反馈被动修正。
- **存在自我强化与偏差固化风险**：记忆条目的保留值由历史贡献滑动平均决定，策略由 FIFO 池采样训练，二者都偏向"被反复选中且恰好表现好"的工具；对**未被 LLM 选中但实际更优**的工具，其反馈虽然也被记录（因为所有工具并行运行），但检索与排序信号能否公平地把它们"翻案"未被验证。论文未做"反事实/离线评估"来检验这一点。
- **冷启动与配置级重置的代价**：记忆与策略在配置级重置，意味着每进入一个新领域都要重新积累约 100 个实例才初始化策略，这段时间的性能接近 Base Agent；论文报告的是整段在线过程的平均表现，未单独刻画冷启动阶段的损失，也未讨论如何跨配置迁移或元学习初始化。
- **统计表示是人工设定的固定集合**：18 个特征的分组、归一化方式与相似度度量均为人工设计，未与学习式表示（如对比学习嵌入）比较，也未验证特征冗余或缺失特征对检索质量的影响。
- **单变量化处理**：所有序列统一转为单变量，丢弃了协变量与多变量依赖；而统计特征中又包含"协变量关系"，二者之间存在张力，论文未说明该特征在单变量化后如何计算。
- **策略预测器的结构固定**：$2(8H)\to2048\to128\to6$ 的 MLP 与固定的输入窗口（最近 $8H$ 个观测）对超长预测长度（如 720 步）意味着极长的输入维度，论文未讨论该窗口选择与预测长度的耦合，也未与更简单的规则型策略（如近期误差加权平均）对比。
- **成本未量化且可能难以落地**：每个实例需并行运行全部 6 个预测器（含多个大基础模型），在 29 个配置 × 最多 5000 实例的规模下开销显著；论文既未报告算力与延迟，也未做"只运行部分工具"或"按策略排序提前剪枝"的性价比分析，实际部署的经济性存疑。
- **数据子集选择可能引入偏差**：从 GIFT-Eval 97 个配置中按"测试实例数 500–5000"筛出 29 个，排除了实例过少与过多的配置，可能系统性地偏袒中等规模、中等难度的任务；未被选中的配置上表现如何未知。
- **可复现性信息不完整**：论文披露了算法超参数，但未明确说明代码/记忆与策略状态是否开源、LLM 控制器提示词模板是否完整给出、随机种子与重复实验次数如何设置。

## 9. 启示与可拓展方向

- **把"延迟反馈"作为一等公民**：该工作提示，在线时序预测的评测与建模应显式区分"即时可用信息"与"延迟揭晓真值"，后者是天然的在线学习信号；未来可将这一设定推广到带漂移、带概念漂移检测的流式预测基准中。
- **从标量反馈走向归因反馈**：可让 LLM 在真值揭晓后生成简短的失败归因文本，与数值信号一同写入记忆，从而把 Reflexion 式的文本反思与本文的数值反馈统一起来。
- **记忆与策略的联合优化**：当前两者独立更新，未来可让策略预测器以记忆检索结果为额外输入，或用策略排序反哺记忆的保留值计算，形成双向闭环。
- **成本感知的自进化**：引入"调用哪个工具"的显式成本，把问题从纯精度优化转为精度–成本帕累托优化，策略排序可直接扩展为"效用排序"。
- **跨配置迁移与元学习**：把配置级重置改为"全局记忆 + 配置级适配层"，缓解冷启动问题。

## 10. 总体评价

FASE 的贡献主要在于**问题设定与机制工程**：它准确指出在线预测中延迟反馈被现有 LLM 智能体忽视这一空白，并用"情景记忆 + 在线策略学习"两个外部状态组件，在不微调 LLM 的前提下把数值反馈闭环化。实验在公开基准上覆盖 7 个领域、29 个配置，点预测上相对最强单模型与最强固定集成分别有约 7% 量级的稳定增益，自进化轨迹与消融实验也支持"两机制互补、越用越好"的结论。但其代价是**概率预测未获优势、闭环缺乏理论保证与归因能力、推理成本未量化**，且未与同类 agentic 方法正面对比，因此更适合被视为"延迟反馈驱动的自进化预测"这一方向上有说服力的概念验证与工程基线，而非已充分论证的通用解。
