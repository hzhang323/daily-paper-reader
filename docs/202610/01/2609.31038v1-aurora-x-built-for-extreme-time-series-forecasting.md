## 摘要
时间序列基础模型（TSFMs）使跨领域预测成为可能，但作为通用预测器，其发展仍受限于尚未充分探索的训练潜力和有限的架构灵活性。为应对这些挑战，我们提出 Aurora-X，一个十亿规模的时间序列基础模型，采用渐进式课程学习和统一架构。我们首先使用通道无关的预训练来学习时间模式，然后在中期训练中引入跨变量依赖、不同的上下文长度和预测视野长度，以及未来协变量（若可用）。可变分辨率后训练进一步使推理时每个 token 的时间跨度可调。在模型权重固定的情况下，这支持在固定 token 预算下处理更长的历史，或用更少 token 处理相同历史，从而实现测试时扩展。凭借多功能的架构，Aurora-X 支持跨变量建模、协变量条件化，以及面向概率预测的未来片段并行解码。这些能力由一种新颖的模式引导混合专家机制支撑，它通过稀疏激活扩展模型容量，并利用浅层片段相似性约束深层路由，引导专家在异构时间序列上实现专业化。此外，我们提出了一种隐式分位数网络头，可预测任意分位数以刻画预测分布，增强概率预测的灵活性。在 GIFT-Eval、TIME、FEV-Bench、TFB 和 DAG-Bench 上的综合实验表明，相较于预训练 TSFMs 和任务专用的监督模型，其预测性能达到最先进水平。

## Abstract
Time series foundation models (TSFMs) enable cross-domain forecasting, but their development as general-purpose forecasters remains constrained by underexplored training potential and limited architectural versatility. To address these challenges, we introduce Aurora-X, a billion-scale TSFM with a progressive curriculum and a unified architecture. We first use channel-independent pretraining to learn temporal patterns, then introduce cross-variable dependencies, varied context and horizon lengths, and future covariates if available during midtraining. Variable-resolution post-training further enables an adjustable temporal span per token at inference. With fixed model weights, this supports longer histories under a fixed token budget or fewer tokens for the same history, enabling test-time scaling. With a versatile architecture, Aurora-X supports cross-variable modeling, covariate conditioning, and parallel decoding of future patches for probabilistic forecasting. These are supported by a novel pattern-guided mixture-of-experts that expands model capacity through sparse activation and uses shallow patch similarities to constrain deep-layer routing, guiding expert specialization across heterogeneous time series. Furthermore, we propose an implicit quantile network head that predicts arbitrary quantiles to characterize predictive distributions, enhancing probabilistic forecasting flexibility. Comprehensive experiments on GIFT-Eval, TIME, FEV-Bench, TFB, and DAG-Bench demonstrate state-of-the-art forecasting performance against pretrained TSFMs and task-specific supervised models.

## 2. 方法论

### 2.1 统一骨干（Unified Backbone）
- **Patch 嵌入**：先做可逆实例归一化 RevIN（用各变量观测历史统计量），再用 arcsinh 压缩极值；非重叠 patch，原生长度 P=48，历史得 N=⌈T/P⌉ 个上下文 token，未来得 M=⌈H/P⌉ 个 token。共享残差 MLP 嵌入 `[相对时间 ti; 归一化值 x̃; 观测掩码 m]`，未来目标在训练与推理中均填零值+掩码，已知协变量保留观测。
- **Time–Group MoE Block（L=12 层）**：每个 block 依次为
  1. **时间注意力**（RoPE，对 (N+M)×d 状态双向）；
  2. **组注意力**（在组 G_g 内、对齐 patch 位置做跨变量混合，|G_g|×d 状态）；
  3. **MoE 前馈**。
  预训练阶段变量为单例组（组注意力退化为 CI），中期训练开启跨变量混合。
- 输出 RMSNorm 后的未来状态 h_{v,j} 送入分位数头。

### 2.2 模式引导混合专家（Pattern-guided MoE）
- **结构**：每层 1 个共享专家 + 16 个路由专家，每 token 激活 top-4；**原型路由**用可学习原型 c_e 计算亲和度，跨专家做无仿射 LayerNorm 后 softmax。
- **核心思想**：仅靠负载均衡不足以促成专家专业化，因为深层时序与跨变量混合会削弱模式区分度。因此用**浅层 patch 相似性约束深层路由**：
  - 学习模式度量 W_pat（stop-gradient 分离 patch 输入），高斯核相似度 S_ij = exp((u_i^T u_j − 1)/σ²_pat)；
  - 用直通估计器把离散 top-K 指派与软概率连接，得到共选专家比例 Ω_ij；
  - **模式损失** L_pat = −(Σ Ω_ij S_ij)/(Σ Ω_ij)：对高于当前平均相似度的 patch 对鼓励共享专家，低于则抑制；
  - **正交正则** R_orth 惩罚投影方向重复；配合 Switch 风格负载均衡 L_bal。
- **理论支撑（附录 C）**：
  - 命题 C.1：1 + ℓ_pat 精确分解为**专家内核散度的 n_e² 加权平均**；
  - 推论：ℓ_pat 接近 −1 时，不相似 patch 共享专家的权重份额被上界约束；
  - 命题 C.2：给出对 Ω_ij 与路由器 logit 的直通梯度，说明「相对平均相似度」如何塑造路由信号；
  - 命题 C.3：模式分组路由与路由坍缩的目标差为 (1 − Σn_g²/N²)(μ_in − μ_out)，μ_in > μ_out 时分组严格更优（同时指出离散优化未必总能逃离坍缩）；
  - 命题 C.4：正交罚低于 1/[m(m−1)] 蕴含满行秩。

### 2.3 隐式分位数头（IQN Head）
- 条件化**连续分位数水平 τ∈(0,1)**：h 的线性投影 + τ 的余弦嵌入（R=128 个频率）相加得条件 c(h,τ)。
- 用 D=4 层带 **AdaLN** 的残差 MLP 迭代精化共享可学习 query v0，β/γ/α 提供条件相关的位移、缩放与残差门控；最后一层自适应归一化 + 投影输出 P 个分位数值。
- **优化**：每步对每个目标 patch 独立采样分位数水平，用掩码 pinball 损失 ℓ_IQN = Σρ_τ(ỹ − q_θ(h,τ)) / (Q·有效位置数)；实现上每 patch 复制 5 次、每次 20 个采样水平，即 Q=100。均匀采样近似对 τ 的积分 pinball 损失，**无显式非交叉约束**。
- **推理**：一次骨干前向得到未来状态，**并行解码所有 patch–分位数对**，拼接裁剪到 H 后经 sinh 与逆 RevIN 还原；无需轨迹采样。

### 2.4 渐进课程与可变分辨率后训练
- **五阶段课程**（各阶段接续上一 checkpoint）：
  - Pre：通道独立时序模式建模；
  - M1：引入联合变量并延长上下文与视野（跨变量建模）；
  - M2：变化上下文长度与预测视野（长度自适应）；
  - M3：引入已知未来协变量条件化（损失仅算在目标变量上）；
  - Post：可变分辨率预测。
- **多尺度后训练**：在 10 亿点子集上，对 RevIN+arcsinh 之后的历史与未来分别按整数块长 kP 重采样回 P（k<1 上采样、k>1 下采样），历史、协变量、目标做**对齐变换**，监督施加在重采样
