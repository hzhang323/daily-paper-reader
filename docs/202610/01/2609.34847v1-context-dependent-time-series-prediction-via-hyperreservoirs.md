## 摘要
时间序列预测是储备池计算的一种常见应用。当训练和测试时间序列数据包含多个动力学机制时——原因可能是某个底层参数在变化，或者数据实际上由多个不同系统组成——简单应用储备池计算原理会产生很高的预测误差。在此，我们提出 HyperReservoir，作为专门为此类情况设计的储备池计算扩展模型。HyperReservoir 将一个主储备池与一个较小的上下文储备池结合起来，后者调制前者的输出权重。该结构类似于深度神经网络文献中的超网络。然而，与之相反，HyperReservoirs 保留了标准储备池计算中通过线性回归进行的简单训练。我们将所提架构与传统的 ESN（其中上下文作用于输入）以及全矩阵 Conceptor（其中上下文调制储备池状态空间）进行比较。我们在基于 Lorenz 系统和 Rössler 系统的时间序列预测任务上评估了所有三个模型，包括变化分岔参数和时间采样尺度的情况。我们发现，HyperReservoir 在所有三个任务中取得了最低的平均测试误差，并且在从同一吸引子但在不同时间尺度上采样的数据上尤其优于 Conceptor。

## Abstract
Time series prediction is a common application of reservoir computing. When the training and testing time series data contains multiple dynamical regimes, because an underlying parameter is changing, or the data in fact consists of multiple distinct systems, simple application of the reservoir computing principle produces high prediction errors. Here, we propose a HyperReservoir as an extended model of reservoir computing especially designed for such cases. The HyperReservoir combines a main reservoir with a smaller context reservoir, where the latter modulates the output weights of the former. This structure resembles the hypernetworks from deep neural network literature. However, in contrast, HyperReservoirs retain the simple training via linear regression of standard reservoir computing. We compare the proposed architecture with a conventional ESN, in which context acts at the input, and a full-matrix Conceptor, in which context modulates the reservoir state space. We evaluate all three models on time-series prediction tasks based on Lorenz and Rössler systems, including for varying bifurcation parameters and time sampling scales. We find that the HyperReservoir achieves the lowest mean test error in all three tasks, and particularly outperforms conceptors on data that is sampled from the same attractor but at different time scales.

## 1. 核心问题与整体含义

- **背景**：储备池计算（reservoir computing）以固定高维循环动力学作为非线性基底，仅训练线性读出，训练简单、适合物理实现。但固定基底也限制了计算对条件变化的适应性。
- **核心问题**：当训练/测试数据包含**多个动力学机制**（底层参数变化、由多个系统组成、或同一吸引子在不同时间尺度上演化）时，直接把上下文当作额外输入会导致高预测误差。
- **关键洞察**：上下文可以注入循环计算的**不同阶段**——输入级（外部驱动）、状态级（限制状态空间区域）、读出级（改变从共享表示到输出的映射）。真正的问题不是"上下文是否可用"，而是"循环计算中哪些部分应保持共享、哪些自由度应随上下文变化"。
- **最困难的情形**：时间尺度缩放（ṡ = ν_c f(s)）。此时连续时间轨道几何不变，上下文差异不体现在状态空间占据区域，而体现在状态**演化速率**上；相似当前状态需要不同的未来预测，仅靠状态空间几何无法区分机制。这使状态级调制（如 Conceptor）失效，而读出级调制成为自然选择。
- **整体含义**：论文提出 HyperReservoir，在保持循环表示共享的前提下，让上下文只改变其**解码方式**，并用纯线性回归训练，从而以极小代价获得上下文灵活性。

## 2. 方法论

- **总体思想**：主储备池表示观测动力学（跨机制共享），较小的上下文储备池编码显式上下文，二者通过**双线性读出**耦合，使上下文状态参数化"主储备池特征→输出"的有效映射。结构上类似深度学习的 Hypernetwork，但上下文依赖被限制在读出层，全部系数由一次岭回归拟合。
- **主储备池**（状态 h^R_t ∈ R^N，仅由观测状态 u_t 驱动）与**上下文储备池**（状态 h^H_t ∈ R^M，仅由上下文信号 c_t 驱动）均采用泄漏积分式更新：状态增量 = 泄漏系数 ×（−当前状态 + 固定循环矩阵 × tanh(状态) + 固定输入矩阵 × 输入）。循环矩阵与输入矩阵随机初始化后**固定不变**，不进行反向传播训练。
- **增广读出特征**：ψ_aug = [ h^R ; h^H ; h^H ⊗ h^R ]，其中 ⊗ 为 Kronecker 积，第三块是上下文与主储备池状态的交叉双线性项。
- **预测式**：ŷ = W^R h^R + W^H h^H + W^RH (h^H ⊗ h^R) + b_out。
- **关键解释**：把 W^RH 按上下文维度分成 M 个块 B_m，可写成 ŷ = [W^R + Σ_m h^H_{t,m} B_m] h^R + W^H h^H + b_out。于是**有效读出矩阵** W_eff(h^H) = W^R + Σ_m h^H_{t,m} B_m 构成一个由上下文状态参数化的仿射族：W^R 是共享基线映射，其余项是上下文相关修正。
- **与已有工作区别**：不像多读出模块那样为每个机制独立拟合一个输出矩阵，各机制的读出通过共享基线 W^R、矩阵 {B_m} 和低维上下文表示耦合；双线性项被赋予"上下文修正"而非通用非线性特征扩展的含义。
- **两个对比基线**：
  - **context-input ESN**：上下文与观测一起作为储备池外部输入，循环矩阵与读出跨上下文共享。
  - **full-matrix Conceptor**：每个上下文由状态相关矩阵 R_k 构造 C_k = R_k (R_k + γ^{−2} I)^{−1}（γ 为 aperture），预测时用 C_k 过滤临时状态（x ← C_k x），读出共享。它依赖不同机制产生可区分的状态分布。
- **训练**：所有输出系数（含偏置，偏置不正则化）用岭回归闭式求解，λ = 10^{−4} 固定。
