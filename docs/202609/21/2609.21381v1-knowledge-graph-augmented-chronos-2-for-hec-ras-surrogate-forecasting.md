## 摘要
我们研究将时间序列基础模型与水力工程知识相耦合，能否改进对 HEC-RAS 水面高程（WSE）的代理预报。我们提出 KG-Chronos-2，它将冻结的 Chronos-2 预测器与精确状态残差解码、图条件历史检索以及输入对齐校正相结合。我们将该方法与持续性预报、残差 LSTM、工程条件化的循环 GeoFNO、水力 DCRNN 风格模型以及冻结的 Chronos-2 进行比较。任务特定的拟合使用 2008 年模拟数据。评估涵盖来自 2011 年和 2002 年模拟的 64 个固定 24 小时窗口，涉及共享几何上 71 个河段的 4,675 个断面。KG-Chronos-2 在原生 WSE 单位下取得事件均衡均方根误差 0.246970。相对于冻结的 Chronos-2、水力 DCRNN 风格模型和循环 GeoFNO，其 RMSE 分别降低 14.13%、29.38% 和 39.54%。其与冻结 Chronos-2 的事件均衡 RMSE 之差的 95% 层次化自助法区间为 [-0.075177, -0.016317]。在六个完整系统中，KG-Chronos-2 还取得了最低的活动窗口 RMSE 和末段预见期 RMSE。这些结果支持在固定基准上将冻结的时序预测器与工程知识相耦合，用于热启动的 HEC-RAS 预报。

## Abstract
We investigate whether coupling a time-series foundation model to hydraulic project knowledge improves surrogate forecasting of HEC-RAS water-surface elevation (WSE). We present KG-Chronos-2, which combines a frozen Chronos-2 predictor with exact-state residual decoding, graph-conditioned historical retrieval, and input-aligned correction. We compare the method with persistence, a residual LSTM, project-conditioned recurrent GeoFNO, a hydraulic DCRNN-style model, and frozen Chronos-2. Task-specific fitting uses the 2008 simulation. Evaluation covers 64 fixed 24-hour windows from the 2011 and 2002 simulations at 4,675 cross sections in 71 reaches on a shared geometry. KG-Chronos-2 achieves event-balanced root-mean-square error 0.246970 in native WSE units. It reduces RMSE by 14.13% relative to frozen Chronos-2, 29.38% relative to the hydraulic DCRNN-style model, and 39.54% relative to recurrent GeoFNO. The 95% hierarchical-bootstrap interval for its event-balanced RMSE difference from frozen Chronos-2 is [-0.075177, -0.016317]. KG-Chronos-2 also achieves the lowest active-window and final-lead RMSE among the six completed systems. These results support coupling a frozen temporal predictor to project knowledge for warm-start HEC-RAS forecasting on the fixed benchmark.

## 1. 核心问题与整体含义

- **背景**：HEC-RAS 依据工程几何、断面、结构物与边界条件计算河道水力学，数值时间步进成本高昂，因此需要数据驱动代理模型用于近期预报；近年神经算子方法多用已解算轨迹训练预报代理。
- **核心问题（研究问题）**：将**冻结的时序基础模型**与**水力工程知识**耦合，能否相对经典方法、局部训练的时序/空间/图循环方法改进 HEC-RAS 水面高程（WSE）的代理预报？
- **任务定义**：即"热启动状态延续（warm-start state continuation）"——在起点 t，给定可用状态历史、工程记录与允许的输入排程，直接预测未来 24 小时 WSE 场。本研究中 N = 4,675 个断面，H = 24，小时级输出，每次预报产生 24 × 4,675 的 WSE 数组。
- **整体含义**：若冻结预训练时序模型 + 少量工程特定适配即可超越从零训练的图谱/算子模型，则代理模型设计可转向"复用通用时序先验 + 集中学习工程特定表示与知识耦合层"，并绕过预报时域内的数值时间步进。

## 2. 方法论：KG-Chronos-2

核心思想：**保留冻结的 Chronos-2 时序预测器，将工程特定学习集中在状态表示、知识条件检索与残差校正上**。由四个环节构成：

### (a) 冻结 Chronos-2 + 精确状态残差解码
- 以小时级 WSE 增量 `d_t = y_t − y_{t−1}` 为预测对象；用源训练增量标准差定义对角尺度矩阵 **D**（对近常数通道设安全尺度）。
- 对缩放后增量做增量 PCA，得均值 **μ** 与载荷矩阵 **C ∈ R^{N×K}**（K = 256）：`z_t = Cᵀ(D⁻¹d_t − μ)`。
- 每个起点提交一个多变量任务（512 个增量、256 个潜通道），关闭跨任务学习，请求 24 步、分位数 0.1/0.5/0.9；以中位数解码：`d̂_{t+h} = D(C ẑ_{t+h} + μ)`，`ŷC_{t+h} = y_t + Σ_{j≤h} d̂_{t+j}`。
- **精确起点场绕过 PCA**，重构时保留完整当前状态；增量乘子在源验证上从 0 到 1.5 以 0.05 步长选择，选中值为 1.0。

### (b) 水力知识图谱
- 断面标识映射到 **71 个河段**；同河段按原生顺序相连，得 29 个无向对（含自环前 58 条有向邻接）；站程排序提供上下游方向近似。
- **14 个河段描述子**：断面数、宽度、深泓与岸线统计、糙率、站程范围、结构物、梯度代理；跨共享几何做插补与标准化。
- 水力相似度重加权邻接：`A_hyd_rs = A_rs · max(10⁻³, exp(−‖s_r − s_s‖²/(2σ²)))`，σ 为相邻河段描述子距离的中位数；加自环并做行归一化。
- 从 HDF Event Conditions 提取 **7 个输入通道**，按标准化原生标识符跨事件匹配，经河流/河段元数据映射到接收河段（对位置信息不明确的通道使用更粗的工程级映射）。

### (c) 图条件历史检索
- 构建 **2,353 个源训练起点**的历史银行（2 小时间隔），每个起点的历史与完整 24 小时响应都落在训练段内。
- 每个查询河段用 **8 个状态描述子**：6/24/72/168 小时累积平均 WSE 增量、24 与 72 小时增量 RMS、当前空间均值与离散度；与局部/上游/下游聚合及过去输入描述子拼接，按源数据分块标准化并按维度归一化。
- 每河段检索 8 个最近邻，反距离加权组合其未来增量序列；用查询与类比 24 小时活动之比缩放（裁剪到 [0.5, 2]），从精确查询状态积分得类比轨迹 `ŷA`。
- 河段级融合系数 `α_r ∈ [0, 1.5]` 在源验证上最小化平方误差拟合：`ỹ_{t+h,i} = ŷC_{t+h,i} + α_r(i)(ŷA_{t+h,i} − ŷC_{t+h,i})`；α_r = 0 时退化为纯 Chronos 预报。

### (d) 输入对齐残差校正
- 用重叠归一化互积选择滞后：`ρ_cr(τ) = (1/(n−τ)) Σ_{j=0}^{n−τ−1} x_{c,j} v_{r,j+τ}`，`τ_cr = argmax_{τ∈{0..168}} |ρ_cr(τ)|`；得分裁剪到 [−1, 1]，与映射河段距离组合为通道权重，在接收河段内归一化。
- 校正特征共 **35 个**：6 个过去输入、5 个未来输入、8 个状态、14 个静态、2 个基线预报描述子（检索融合的平均变化及其与辅助纯状态图检索预报之差）。
- 每个 lead 一个独立 **ridge 模型 f_h** 预测剩余平均河段误差，并广播到该河段所有断面。
- **源校准门控**：`g_rh = clip[0,1][(1 − SSE_corrected/SSE_base)/0.02]`，当基线 SSE ≤ 10⁻¹² 时门为 0；最终 `ŷKG_{t+h,i} = ỹ_{t+h,i} + η·g_{r(i)h}·f_h(ψ_{t,r(i),h})`，η = 0.75；仅 **27.35%** 的河段–lead 对获得非零门，门为 0 时保留检索融合预报。
