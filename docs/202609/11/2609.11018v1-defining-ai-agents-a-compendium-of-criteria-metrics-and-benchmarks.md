## 摘要
人工智能中的“智能体”一词缺乏标准定义，这使AI智能体研究的评估、比较和可复现性变得复杂。我们围绕智能体性（agenticness）的五个维度组织了一项综述，以应对这种模糊性：环境交互、学习与适应、自主性、目标导向行为和时间一致性。对于每个维度，我们考察其底层能力在既有研究中是如何被概念化的，并综合用于评估该能力的指标、基准和评估框架。本综述对当前智能体评估图景进行了结构化阐述，既强调了已有成熟方法，也指出了评估仍然有限或不一致的领域。此外，我们介绍了Agent Compendium，这是一个面向公众的数字资源，用于组织和扩展本综述所识别的评估方法。综述与汇编共同为跨AI系统评估和比较智能体能力提供了通用结构，支持更具可复现性的研究、更清晰的交流，以及对人工智能体更系统的研究。

## Abstract
The term agent in artificial intelligence lacks a standard definition, complicating the evaluation, comparison, and reproducibility of AI agent research. We address this ambiguity through a survey organized around five dimensions of agenticness: environmental interaction, learning and adaptation, autonomy, goal-directed behavior, and temporal coherence. For each dimension, we examine how the underlying capability has been conceptualized across prior work and synthesize the metrics, benchmarks, and evaluation frameworks used to assess it. This review provides a structured account of the current landscape of agent evaluation, highlighting both established approaches and areas where evaluation remains limited or inconsistent. We additionally introduce the Agent Compendium, a public-facing digital resource that organizes and extends the evaluation methods identified through this review. Together, the survey and compendium provide a common structure for evaluating and comparing agent capabilities across AI systems, supporting more reproducible research, clearer communication, and more systematic study of artificial agents.

- **核心问题**：人工智能领域中的“agent（智能体）”一词长期缺乏被广泛接受的标准定义，不同研究者、企业与公众对其理解差异巨大，导致 AI 智能体研究的**评估、比较与可复现性**受到严重阻碍。
- **背景动因**：
  - 自 1970 年代计算机科学引入“agent”概念以来，用法一直不统一；2026 年的教科书、研究论文对 agent 的描述也各不相同（如“智能软件实体” vs “自主完成任务并与其他 agent 通信的系统”）。

## 2. 论文提出的方法论

- **核心思想**：以 Bent（2025）提出的 **agenticness 五维度**为组织骨架，对既有评估方法进行归类和综合，并映射到具体的指标、基准与评估框架。
- **五维度定义**：
  1. **环境交互（Environmental Interaction）**：agent 对环境的感知、理解与操作能力。
  2. **学习与适应（Learning and Adaptation）**：利用资源完成任务并根据新条件调整行为的能力。
  3. **自主性（Autonomy）**：无需外部指导即可运行的程度。
  4. **目标导向行为（Goal-Directed Behavior）**：形成、理解并实现目标的能力。
  5. **时间一致性（Temporal Coherence）**：在记忆、上下文与意图之间维持逻辑一致性的能力。
- **关键技术细节（按维度梳理的指标/公式示例）**：
  - **环境交互**：
    - 架构：deliberative / reactive / hybrid 三类，基于物理符号系统假设与 Brooks 的 reactive 主张。
    - 导航：以 **SPL（Success weighted by inverse Path Length）** 为核心指标，公式为 `SPL = (1/N) Σ Si·ℓi / max(pi, ℓi)`，并梳理 point-goal、object-goal、vision-language、audio-visual、EQA、VQA 等导航类型。
    - 工具使用：MultiCAT-Bench 按 call、tool name、arguments 分类评估，含 Accuracy、Overall Recall/Precision/F1、ToolName Recall/Precision/F1、Arguments Recall/Precision/F1；并提出 **Tool Dexterity Index（TDI）**，对“最优使用”+1、“误用”-1、“忽略更优工具”-0.5。
    - 空间分析：micro / meso / macro 三级空间尺度；提出四类空间失败模式（空间幻觉、参考系混淆、尺度不敏感、时间漂移）。
    - 一致性：outcome consistency、trajectory type consistency、trajectory sequence consistency、resource consistency；使用 Bernoulli 方差归一化、Jensen-Shannon 散度、Levenshtein 距离、变异系数等公式；并引入 Agent Stability Index（ASI）的四个一致性维度。
    - 鲁棒性：RobustSucc、WorstSucc，以及 fault / environment / prompt robustness 的钳制比率公式；对抗鲁棒性涉及 AgentDojo、HarmBench、AdvBench、JailbreakBench、CyberSecEval。
  - **学习与适应**：
    - 效率与成本：**CES（Cognitive Efficiency Score）** =（生成 token 总数 + 工具/API 调用 × token 当量）/ 成功完成任务数；latency 分位数、token 用量与 token 成本公式。
    - 轨迹与规划：Action Validity Rate、Loop Rate、Plan Adherence。
    - 可靠性：跨 seed 的成功率均值与方差。
    - Agentic 能力层级（Ritchie et al., 2026）：工具使用 → 规划与目标形成 → 适应性 → 扎根性 → 常识推理。

    - 上下文保持：CRA、STA、Context Decay `C(d)=αe^{-βd}+(1-α)/(1+γd²)`，并给出短/中/长程成功阈值。
    - 可预测性：Calibration（ECE）、Discrimination（AUROC）、Brier Score。
    - 通用性：Morris et al.（2023）五级性能阈值（Emerging→Superhuman）与 Kasirzadeh & Gabriel（2025）五级任务掌握广度（Single specialty→Fully general）。

    - 目标复杂度：基于 hierarchical planning、plan length、multi-objectivity 的五级分级。

    - 韧性与适应：MTR、CRS、Adaptability Delta。
