## 摘要
协变量效应会随情境变化并随时间漂移，因此预测者需要针对每个预测情境评估如何使用这些协变量。随着预测的推进，先前预测的观测值会变得可用，为后续预测提供关于过去协变量使用情况的反馈。然而，当多个协变量共同作用时，预测误差只能揭示与观测值之间的数值差异，而无法说明这些协变量本应如何使用。我们提出 JudgeCast，一种基于经验的、带协变量的时间序列预测框架。遵循判断性调整实践，一个冻结的 TSFM 提供基础预测，而一个冻结的 LLM 利用当前情境和相关经验对其进行调整。在调整过程中，评估协变量效应与确定数值调整承担不同角色，因此 JudgeCast 首先生成显式的逐协变量判断，然后确定调整量。观测发生后，JudgeCast 利用基础预测的观测残差重构备选判断，并通过这些判断所产生的调整来评估原始判断与备选判断。表现最佳的决策被选中，并作为经过验证的经验保留下来，用于后续预测。在多种真实世界数据集上，JudgeCast 优于强基线。消融实验表明，显式的逐协变量判断能够改善预测时的调整，而由残差引导的经验构建比将原始决策作为经验保留能带来更可靠的预测增益。

## Abstract
Covariate effects vary across contexts and shift over time, requiring forecasters to assess how to use them for each forecasting context. As forecasting proceeds, observations for earlier forecasts become available, providing feedback on past covariate use for subsequent forecasts. However, when multiple covariates act together, the forecast error reveals the numerical discrepancy from the observation but not how the covariates should have been used. We introduce JudgeCast, an experience-based framework for time series forecasting with covariates. Following the judgmental adjustment practice, a frozen TSFM provides the base forecast, while a frozen LLM uses the current context and relevant experience to adjust it. Within the adjustment, assessing covariate effects and determining the numerical adjustment serve distinct roles, so JudgeCast first forms explicit covariate-wise judgments and then determines the adjustment. After observation, JudgeCast uses the observed residual of the base forecast to reconstruct alternative judgments and evaluates the original and alternatives through their resulting adjustments. The best-performing decision is selected and retained as validated experience for subsequent forecasts. Across diverse real-world datasets, JudgeCast outperforms strong baselines. Ablations show that explicit covariate-wise judgment can improve forecast-time adjustment, while residual-guided experience construction yields more reliable forecasting gains than retaining raw decisions as experience.

- **现有方法局限**：
  - 协变量感知预测器把协变量效应直接建模进预测函数，而非表示为可复用的逐协变量判断。
  - 事后归因在预测之后量化协变量贡献，而非预测时的决策。
  - 基于反馈的 LLM 预测方法（反思、指导、推理轨迹等）复用过去的误差或反思，但**未利用观测来重构预测时关于"如何使用情境信息"的决策**。

- **论文主张**：从预测反馈中构建关于协变量使用的**可复用经验**，且无需更新任何模型参数。

## 2. 方法论

### 2.1 核心思想
- 将带协变量预测形式化为对基础预测的**判断性调整**（judgmental adjustment，源自人工预测实践）。
- **冻结 TSFM** 仅用目标自身历史生成基础预测；**冻结 LLM** 结合当前情境与相关经验进行调整。
- 关键解耦：**评估协变量效应**与**确定数值调整**是两个不同角色，因此首先生成显式逐协变量判断，再据此确定调整量。

### 2.2 问题形式化
- 记目标序列为 $y$，协变量 $X=(x_1,\dots,x_C)$；预测在连续窗口 $w$ 上进行，目标上下文长度 $L$，预测视野 $H$。
- 基础预测：$\hat{y}^{base}=f_\phi(y_{1:L})$，$\hat{y}^{base}\in\mathbb{R}^H$。
- 最终预测：$\hat{y}=\hat{y}^{base}+a$，其中 $a\in\mathbb{R}^H$ 为 LLM 决定的数值调整。

### 2.3 预测时的判断性调整
- **判断标签集** $S=\{--,-,0,+,++\}$，$J_{c,h}\in S$ 表示协变量 $x_c$ 在第 $h$ 步相对基础预测的方向与定性强度；全体构成 $J\in S^{C\times H}$。
- **判断形成**：从已验证经验记忆 $M_{<w}$ 中按归一化协变量值与基础预测的相似性检索 $E^{jud}_w$，LLM 生成：
  $$J = g^{jud}_\theta(y_{1:L},\ X_w,\ \hat{y}^{base},\ E^{jud}_w)$$
- **数值调整**：对协变量判断模式相同的预测步归为一组，按目标上下文与基础预测的相似性检索匹配经验 $E^{adj}_w$，LLM 确定：
  $$a = g^{adj}_\theta(y_{1:L},\ X_w,\ \hat{y}^{base},\ J,\ E^{adj}_w)$$

### 2.4 残差引导的经验构建（观测后）
- **观测残差**：$r_h = y_{L+h}-\hat{y}^{base}_h$，$1\le h\le H$，$r=(r_1,\dots,r_H)$。
- **备选判断生成**：$g^{alt}_\theta$ 使用当前情境、基础预测与观测残差生成 $N$ 个备选判断 $\tilde{J}^{(1)},\dots,\tilde{J}^{(N)}$；生成时**刻意排除**原判断与记忆，避免污染。原判断与备选合并为 $\mathcal{J}=\{J\}\cup\{\tilde{J}^{(i)}\}$。
- **评估与选择**：每个 $J'\in\mathcal{J}$ 通过 $g^{adj}_\theta$（不使用存储经验）产生调整 $a(J')$；原判断也在此条件下重新评估而非沿用预测时调整。选择使 $L(r,a(J'))$ 最小的判断：
  $$J^\star=\arg\min_{J'\in\mathcal{J}} L(r,a(J')),\quad a^\star=a(J^\star)$$
- **验证与记忆更新**：仅当 $L(r,a^\star)<L(r,0)$（即调整优于不调整）时，才将判断、调整及其理由 $R^{J,\star},R^{a,\star}$ 与残差一起作为**已验证经验**存入记忆；否则记忆不变。
- 论文明确声明：此验证**并不**证明所选判断忠实反映了协变量真实效应。

## 6. 主要结论与发现

- **整体性能**：JudgeCast 在全部 7 个数据集的 MSE 与 MAE 上均最低，相对最强基线平均提升 **16.7%（MSE）** 和 **6.5%（MAE）**；长期任务（ENTSO-e、Rossmann）上优势尤为明显，而仅推理 LLM 方法在长期任务上明显不具竞争力。
- **显式判断的作用**：在 5 个短期数据集上，先形成逐协变量判断再做数值调整，相比直接调整降低 MSE 3.4%（无经验）和 4.6%（有原始经验）；在长期任务上改善不一致，因为相同判断模式的不同预测步可能需要不同数值调整。
- **经验构建**：
  - 原始经验（Raw）在某些数据集改善、在另一些数据集退化，不可靠。
  - 仅验证原始决策（Raw+Valid.）多数情况下优于 Raw，但仍不能稳定超过无经验。
  - **已验证经验（Validated）** 稳定优于无经验与两种原始设置，相对无经验平均降低 MSE 12.1%、MAE 9.7%。说明增益来自**观测后重构预测时决策**，而非仅验证原决策。
- **协变量利用**：
  - 在直接条件化无改善的 3 个任务（UK COVID、Rohlik Orders、M5）上，JudgeCast 仍能利用相同协变量提升目标-only 预测，说明直接条件化收益有限≠协变量本身无用。
  - 时间错位下，直接条件化误差急剧上升，而 JudgeCast 更鲁棒；在 NP 两个偏移量与 DE 12h 偏移下，直接条件化的优势被逆转。错位协变量的 0 判断率上升，未变协变量保持稳定，说明显式逐协变量评估可限制不可靠协变量的影响而不丢弃其他信息。
- **经验分析**：
  - 记忆从 25% 增至 100% 时，判断检索距离从 0.508 降至 0.374，调整检索距离从 0.802 降至 0.646；全量记忆在 5 个数据集上 MSE 均最低，相对无经验平均降低 MSE 5.3%、MAE 7.4%。
  - **判断检索起主要作用**：相关判断检索即使搭配随机调整检索也能降低 MSE 1.9%，而仅相关调整检索无改善；两者都相关时增益最大。
- **案例研究（PJM）**：在 JudgeCast 与 MemCast 差异最大的第 9–16 步，JudgeCast 检索到前序周末窗口的已验证 COMED 判断（多为向下效应），据此施加负向调整修正基础预测的高估；该区间 MSE 为 1.4，MemCast 为 39.6。JudgeCast 的显式决策可追溯到影响它的前序决策。
- **失败模式**（PJM）：① 调整方向错误（协变量偏离幅度较小、前序窗口残差方向不一致时更易发生）；② 不必要的调整（基础预测已接近观测，但预测时无法预知残差异常小）；③ 错过视野内反转（所需修正方向在视野内变化，而判断与调整偏向单侧）。

## 7. 优点

- **概念解耦清晰**：将"协变量效应评估"与"数值调整确定"分离，用显式逐协变量判断作为中间表示，既提升可解释性，又为观测后的重构

提供结构化的监督信号，使经验可以被显式检索、比较和验证。
- **无需参数更新**：所有模型保持冻结，仅通过外部经验记忆吸收反馈，避免了重训练/微调的计算开销与灾难性遗忘风险，也适用于参数不可更新的闭源模型场景。
- **反馈利用方式新颖**：不是复用过去的误差数值或自然语言反思，而是复用"预测时如何使用情境信息"的决策，并用观测残差来**重构**而非仅**验证**原决策，这在概念上更接近人类预测者的学习方式（从结果反推"当初该怎么判断"）。
- **验证机制稳健**：记忆仅在调整严格优于不调整时写入，避免污染记忆；同时论文诚实地声明该验证不等于判断的因果忠实性，态度严谨。
- **实验维度丰富**：从骨干鲁棒性、消融、协变量错位、经验积累曲线、检索消融到案例与失败分析，形成较完整的证据链，并刻意对齐 MemCast 的数据规模以支持直接比较。
- **可解释性与可追溯性**：案例研究显示单窗口预测的调整可追溯到影响它的前序已验证决策，为部署时的审计与信任提供基础。

## 8. 局限与不足

- **协变量效应识别仍非因果**：论文明确承认，通过残差最小化选出的判断只保证"使调整更优"，并不保证忠实反映协变量的真实作用；多个协变量纠缠时，选择可能落入"碰巧数值对齐"的解，判断的语义可信度存疑。
- **成本与效率不透明**：未报告 LLM 调用次数、token 消耗、延迟或 GPU 资源；由于每步预测需要判断生成、调整确定、以及观测后的备选生成与多次评估，推理开销可能显著高于直接条件化方法，论文未做效率-精度权衡分析。
- **统计严谨性不足**：未报告多次运行的均值±方差或置信区间，主实验单骨干（Chronos-2 + GPT-5 mini），骨干鲁棒性仅在 NP、PJM 两个短期数据集上验证，对长期任务与更多领域的泛化性证据有限。
- **对基础预测器的依赖**：方法以基础预测为锚点做增量调整，若基础预测本身系统性偏差过大或残差结构复杂，调整可能失效（失败模式中的"调整方向错误""错过视野内反转"即体现此点）。
- **经验记忆的规模与遗忘问题未充分讨论**：记忆随时间累积，检索 top-5 可能在大规模、长历史场景下失效；论文未讨论记忆的容量管理、冗余去重或概念漂移下的记忆过期策略。
- **超参数与设计选择的影响未系统分析**：如判断标签集 $S$ 的粒度、备选判断数 $N=4$、top-5 检索、误差度量 $L$ 的选择等，均未做敏感性分析。
- **协变量类型覆盖有限**：实验协变量多为数值型（市场预测、天气、日历），对高维类别协变量、文本/图像协变量、协变量缺失或延迟到达等现实情形的处理未涉及。
- **可能的评估泄漏与协议细节**：记忆在训练集累积、测试集固定虽设计合理，但论文对训练/测试时间边界、窗口重叠、协变量可得性（尤其长期任务中未来协变量是否真实可得）等协议细节描述不够充分。

## 9. 对领域与后续研究的启示

- **"判断-调整"范式可推广**：将预测分解为"对每个外部信息的定性判断"与"基于判断的数值决策"两个角色，这一解耦思路可迁移到其他条件化预测任务（如带外生变量的金融预测、库存规划），也为构建更可解释的 LLM 增强预测器提供模板。
- **反馈学习的第三种路径**：在"重训练/微调"与"自然语言反思"之外，论文提出"观测后重构决策并验证后写入记忆"的路径，为冻结模型下的在线适应提供了可复用的方法论。
- **协变量利用的评估视角**：论文区分"直接条件化是否带来增益"与"协变量本身是否有用"，提示未来基准应更细致地评估模型在协变量错位、噪声、缺失下的鲁棒性，而非仅看平均精度。
- **检索质量决定收益**：经验分析表明判断检索起主要作用，这暗示未来可研究更优的检索表示（如情境嵌入、结构相似度）与记忆组织方式（如分层、去噪、因果筛选）。
- **开放问题**：如何赋予判断以更强的因果/可识别性？如何在多协变量纠缠下分解效应？如何控制记忆增长与推理成本？如何为判断学习引入不确定性量化与拒答机制？这些是该方法走向实用与可信的关键方向。

## 10. 总结性评价

JudgeCast 提出了一个概念清晰、设计自洽的框架：在冻结 TSFM 与冻结 LLM 的前提下，把带协变量预测转化为对基础预测的显式逐协变量判断加数值调整，并通过观测残差在事后重构预测时的决策、经严格验证后写入可检索经验记忆。实验覆盖短期电价、长期负荷与零售等多领域，消融与错位分析较充分，平均相对最强基线在 MSE 上提升约 16.7%，且增益主要来自"已验证经验"这一关键设计。其最大贡献在于提供了一条无需参数更新、可解释、可追溯的反馈利用路径。主要短板在于成本与统计透明度不足、因果识别能力有限、骨干与超参数敏感性验证偏窄。总体而言，这是一项在"LLM + 基础模型 + 外部记忆"交叉方向上具有启发性的工作，其"重构决策而非复用误差"的核心洞察值得后续研究深入。
