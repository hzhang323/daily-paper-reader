## 摘要
尽管自主移动智能体在协助老年人使用智能手机方面具有巨大潜力，但现有的图形用户界面（GUI）基准主要依赖明确且目标导向的指令，很少捕捉老年用户自然出现的语言模式，例如间接表达、指代歧义和请求信息不足。这种基准指令与真实老年人交互之间的不匹配可能阻碍智能体的可靠部署。为解决这一问题，我们提出了ElderBench，这是首个在真实面向老年人场景中评估移动GUI智能体的基准。ElderBench由从20个应用程序的老年人中自然诱发的249个智能手机任务构成。我们首先从句法、语义和语用角度刻画老年人指令与现有GUI基准指令之间的语言差异。随后，我们在在线和离线设置下评估了主流GUI智能体和视觉语言模型，揭示了在处理面向老年人的指令时性能显著下降。通过受控指令规范化、失败分析和细粒度语言特征分析，我们进一步识别了老年人特有语言模式导致智能体失败的原因。我们的研究结果为开发更具适应性、可解释性和年龄包容性的老年人GUI智能体提供了可行的设计启示。

## Abstract
While autonomous mobile agents hold great potential for assisting older adults with smartphone usage, existing GUI benchmarks mainly rely on explicit, goal-oriented instructions and rarely capture the naturally occurring language patterns of older users, such as indirect speech, referential ambiguity, and under-specified requests. This mismatch between benchmark instructions and real-world elderly interactions may hinder reliable agent deployment. To address this gap, we present ElderBench, the first benchmark for evaluating mobile GUI agents in authentic elderly-oriented scenarios. ElderBench is constructed from 249 naturally elicited smartphone tasks collected from older adults across 20 applications. We first characterize the linguistic divergence between elderly instructions and existing GUI benchmark instructions from syntactic, semantic, and pragmatic perspectives. We then evaluate mainstream GUI agents and Vision-Language Models under both online and offline settings, revealing substantial performance degradation when handling elderly-oriented instructions. Through controlled instruction normalization, failure analysis, and fine-grained linguistic feature analysis, we further identify how elderly-specific language patterns contribute to agent failures. Our findings provide actionable design insights toward more adaptive, interpretable, and age-inclusive GUI agents for older adults.

### 1. 论文的核心问题与整体含义（研究动机与背景）

- **研究动机**：当前主流图形用户界面（GUI）智能体基准（如 AndroidWorld、MobileWorld、AndroidLab 等）主要使用**显式、目标导向、完整规范**的任务指令进行评估。这些指令与实际老年用户的真实表达方式存在巨大鸿沟——老年人往往使用**间接言语（Indirect Speech）、指代歧义（Referential Ambiguity）、请求信息欠明确（Under-specification）** 等自然语言模式来表达需求。
- **核心问题**：现有基准与老年人真实交互之间缺乏一致性，导致 GUI 智能体在真实老年人场景中的部署可靠性无法得到保障。
- **论文目标**：构建首个面向老年人真实场景的移动 GUI 智能体评估基准 **ElderBench**，系统分析老年人指令的语言学特征，评估主流智能体的执行表现，识别失败原因，为开发更具包容性、适应性和可解释性的年龄友好型 GUI 智能体提供设计洞见。

### 2. 论文提出的方法论

**核心思想**：以自然诱发（naturally elicited）的老年人真实任务指令为基础，构建一个具备在线（Online）与离线（Offline）双模式评估能力的基准框架，结合语言学分析与受控实验，揭示老年人特定语言模式对智能体性能的影响。

**关键技术细节与流程**：

- **数据采集**：
  - 招募 28 名年龄在 59–84 岁之间的中国老年人（男性 8 人，女性 20 人），覆盖不同智能手机使用年限（1–8 年至 10 年以上）与日常使用时长（约 1–2 小时至 5–6 小时）。
  - 采用**半结构化访谈**：第一阶段引导参与者描述日常智能手机活动；第二阶段探讨希望智能体协助的困难场景。全程不提供预设任务列表、模板或语言示例，以保留老年人自然表达方式。
  - 原始收集 251 条指令，经三名作者讨论过滤 2 条无效指令后，保留 **249 条有效任务**，覆盖 **20 个 Android 应用**。
- **语言学分析框架**（基于 Silverstein (1972) 与 Kasirzadeh & Gabriel (2023) 的理论，从句法、语义、语用三个维度展开）：
  - **句法维度**：比较指令长度、动词密度（predicate density）、句法结构类型（规范式、叙述式、省略式、复合式）。
  - **语义维度**：采用主题分析（Thematic Analysis），将指令分为五类——清晰明确（Clear and Explicit）、欠明确（Under-specification）、不流利/纠正（Disfluency/Correction）、指代歧义（Referential Ambiguity）、间接言语（Indirect Speech）。
  - **语用维度**：分析任务场景分布（如生活服务、社交沟通、系统设置等）。
- **评估框架（双模式）**：
  - 操作环境：单轮任务执行（single-turn），从初始设备状态出发完成一次用户请求；动作空间包括 Tap、Long Press、Swipe、Type、Home、Back，坐标统一归一化至 [0,1000]。
  - **评估指标**：
    - 任务成功率（SR）：SR = (1/N) Σ I(Successᵢ)
    - 平均推断延迟（AIL）：每次操作轮次的平均推理+解析时间
    - 货币成本指标（MCM）：每任务平均 Token 消耗量
  - **成功判定条件**：系统层面成功 = Agent 自主结束 ∩ 任务验证通过；离线图匹配条件 = Agent 输出 finish(...) 且达到 DONE 节点。

### 3. 实验设计

- **ElderBench 任务组成**：共 249 项任务，覆盖 20 个 Android 应用。
  - 在线子集：130 个任务 × 15 个应用（系统设置、今日头条、大众点评、天气、App Store、抖音、腾讯新闻、浏览器、电话、相册、短信、美团、豆包、闹钟、QQ 音乐）。
  - 离线子集：119 个任务 × 5 个应用（支付宝、微信、高德地图、淘宝、携程）。
- **任务划分原则**：在线任务需满足执行环境可复现、不涉及隐私敏感操作、外部应用状态稳定；离线任务（涉及支付、通讯、实时内容）通过人工演示构建任务图进行离线评估。
- **对比方法**：
  - **VLM 类**：Qwen3-VL-Flash、GLM-4.6V、Kimi K2.5、Qwen3-VL-Plus、Gemini-3-Flash。
  - **GUI 智能体类**：AutoGLM (Phone-9B)、Doubao-1.5-UI-TARS (7B)、GUI-Owl-1.5 (8B-Think)、UI-Venus-1.5 (8B)。
- **实验环境**：Android 模拟器（Google Pixel 6a / Android 17 / 4 核 / 6GB 内存 / 1080×2400 分辨率），在线环境通过 ADB 与智能体交互；评估最大步数为 25 步，超时时间为 120 秒。
- **额外实验**：
  - **受控指令规范化实验**：按五类语义类别分层抽样 100 条指令，改写为简洁、动作导向的规范指令，对比 AutoGLM 与 Qwen3-VL-Flash 在改写前后的任务成功率。
  - **失败分析**：人工检查 AutoGLM 在线子集 63 条失败轨迹，按四类原因分类（意图/能力边界、规划/状态追踪、环境感知、视觉/动作执行）。
  - **语言特征归因分析**：使用皮尔逊相关系数分析单一特征与任务成功率的关系；使用因子分解机（FM）模型分析二阶交叉特征对执行结果的影响。

### 6. 论文的主要结论与发现

1. **现有智能体在老年人自然指令上表现整体欠佳**：所有模型的总体成功率均低于 50%，其中 Gemini-3-Flash 和 GUI-Owl-1.5 分别达到 VLM 与 GUI 智能体的最优表现（49.80% 和 45.38%），仍有巨大提升空间。
2. **在线与离线表现存在显著差异**：在线子集上 Qwen3-VL-Plus 最优（76.15% SR），离线子集上 UI-Venus-1.5 最优（31.09% SR）。离线评估的严格图匹配协议（每步动作需要与图中一条有效边匹配）增加了执行难度，模型无法轻易从错误中恢复。
3. **语言不规范是重要的失败来源**：将原始老年指令改写为规范、明确指令后，AutoGLM 成功任务数从 37 提升到 61（+24），Qwen3-VL-Flash 从 23 提升到 46（+23），两者的提升都非常显著，证明语言不匹配是智能体失败的实质因素。
4. **失败的主要原因集中于意图理解和规划追踪**：AutoGLM 的失败轨迹中，意图/能力边界错误（57.1%）与规划/状态追踪错误（33.3%）合计占 90.4%，远高于环境感知与视觉/动作执行错误，说明瓶颈在于高层认知推理，而非低层感知。
5. **隐含/不完整表达与任务失败相关**：省略句、间接表达以及“描述状态而非动作”的表达方式（如“声音太小我听不见”）与较低的成功率显著相关。
6. **语言特征是场景相关的，不能简单一概而论**：在信息查询类场景中详细描述反而有助于操作（+0.70），而长文本叠加系统设置类任务则形成显著的负面交互（−0.42）。

### 7. 优点

- **填补研究空白**：ElderBench 是首个使用 **真实诱发数据** 而非模板/改写数据来评估移动 GUI 智能体的老年人场景专项基准，直接回应了现有基准在人群多样性上缺失的问题。
- **语言学理论支撑的系统性分析框架**：从句法、语义、语用三个理论维度对指令差异进行系统量化，而非简单给出数据集描述，分析方法严谨。
- **双协议互补评估**：在线评估再现真实交互动态性，离线评估基于人工演示任务图提供可复现的评估途径，兼顾真实性与可控性。
- **归因设计严谨**：受控指令规范化实验在固定任务、环境条件下隔离语言因素与任务难度；配对的统计检验（McNemar 检验）保证了结论可信。
- **失败分析+交叉特征分析揭示了可操作的瓶颈信息**：例如意图识别失败的频率远超视觉/执行失败，指明后续模型应优先改进的方向；因子分解机识别的二阶交互模式说明设计者需情景化处理语言特征。
- **提取了具有实际落地价值的设计启示**：状态感知的意图理解、主动澄清和上下文感知解析等建议对后续老年智能体开发具有参照意义。
- **数据采集方法规范**：招募参与者在年龄、性别、地区、时长等方面多样化；不以预设模板影响表达，过程公开透明。

### 8. 不足与局限

- **语言和文化覆盖范围有限**：语料全部来自中国大陆老年人群、使用中文对话，未对非中文语言或跨文化场景进行验证，基准的泛化性有待考证。
- **应用覆盖面不均衡**：在线子集以日常工具为主，离线子集以支付/通讯等高隐私应用为主；虽然出于隐私和稳定性考虑合理，但不同子集的难度差异较大，影响整体成功率解读。
- **缺乏多轮对话评估**：作者明示采用单轮任务设置，虽基于实际约束与当前技术水平，但真实老年人使用中可能存在多轮交流与澄清的需求，这一重要交互维度未被覆盖。
- **智能体评估范围有限**：仅包含 9 个模型，均为当时主流模型，缺少商业化大参数 GUI 智能体（如训练于更大规模 GUI 数据的新版本模型）的对比；未包含基于人类示范的强化学习微调的差异对比。
- **机器人式评估局限**：对候选“智能体是否真正理解需求”的判定依赖最终截图视觉与中间帧（经由 VLM judge），本质上是对任务完成的近似判断（在线 93.08% 与人工判断一致），仍有约 7% 误差。
- **高级别任务失败分析面窄**：详细失败分析仅针对 AutoGLM 一种模型，可能反映其特有缺陷而非普适问题；对其他智能体失败原因的深入分析缺失。
