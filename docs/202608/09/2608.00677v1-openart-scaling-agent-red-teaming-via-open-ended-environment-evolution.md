## 摘要
AI智能体在持久环境中运行，早期的状态变化可能影响遥远未来的决策。与传统的语言模型交互不同，智能体的行为通过一个共享状态进行调节，该状态在长时间跨度的任务中被反复修改和复用。当前的安全基准测试往往无法捕捉这些累积风险，因为它们聚焦于短期的、静态的任务。为解决这些局限性，我们引入了OpenART，一个通过环境进化进行可扩展智能体红队测试的开放式竞技场。OpenART提供了跨越50个领域的超过10,000个经过验证的有状态场景，利用了超过500,000个工具和技能的池子。这些任务中位数需要97次工具调用，并支持对75种不同的智能体-模型配置进行统一评估。为了系统性地探索这些不断演化的攻击面，我们提出了进化马尔可夫超图攻击（EMHA）。EMHA是一种黑盒策略，通过协调授权的状态转换执行基于反馈的环境进化，无需参数更新。在整个评估过程中，任务目标保持不变，仅环境状态发生变化。在所有配置中，EMHA实现了85.0%的合并攻击成功率（ASR）。其相对于仅指令进化的优势从简单环境中的约2%增加到最复杂环境中的超过17%，表明随着任务复杂性的增长，环境进化日益暴露安全失败。此外，我们的分析表明，智能体的具体运行时实现解释了超出底层模型能力之外的显著安全差异部分。这些结果确立了OpenART作为在复杂、进化环境中研究智能体安全的可扩展基础。

## Abstract
AI agents operate in persistent environments where early state changes can influence decisions far into the future. Unlike conventional language-model interactions, agent behavior is mediated through a shared state that is repeatedly modified and reused across long-horizon workflows. Current safety benchmarks often fail to capture these cumulative risks because they focus on short, static tasks. To address these limitations, we introduce OpenART, an open-ended arena for scalable agent red teaming through environment evolution. OpenART provides over 10,000 validated stateful scenarios across 50 domains, drawing from a pool of more than 500,000 tools and skills. These tasks require a median of 97 tool calls and enable unified evaluation across 75 different agent-model configurations. To systematically explore these evolving attack surfaces, we propose the Evolutionary Markov Hypergraph Attack (EMHA). EMHA is a black-box policy that performs feedback-driven environment evolution by coordinating authorized state transitions without requiring parameter updates. Throughout the evaluation, task objectives remain fixed while only the environment state changes. Across all configurations, EMHA achieves a pooled Attack Success Rate (ASR) of 85.0%. Its advantage over instruction-only evolution increases from approximately 2% on simple environments to over 17% on the most complex ones, demonstrating that environment evolution increasingly exposes safety failures as task complexity grows. Furthermore, our analysis shows that the specific runtime implementation of an agent explains a significant portion of safety variation beyond the underlying model's capabilities. These results establish OpenART as a scalable foundation for studying agent safety in complex, evolving environments.

### 1. 核心问题与整体含义

- **研究动机与背景**：AI智能体越来越多地运行在持久环境中，能够通过工具调用持续修改共享状态（数据、权限、外部资源）。其行为通过不断演化的环境被耦合起来，一个在孤立状态下看似良性的动作可能引入潜在的状态变化，并通过后续交互传播，最终在很远的未来才显现为有害行为。这表明安全失败是整条交互轨迹的性质，而非单一动作，传统的“提示级”评测难以捕捉此类长程风险。
- **现有方法不足**：现有的智能体安全基准（如InjecAgent、AgentDojo、AgentHarm、ASB、DTap等）大多评估短时、静态或可重置环境中的行为，工作流程较短，且与特定基础设施耦合。它们评估的是“智能体能否在给定环境中操作”，而不是“当环境在其周围演变时智能体是否仍保持安全”，因此未能覆盖状态持久化、延迟攻击传播和长距离安全失败等关键问题。
- **整体含义**：OpenART将“可执行环境”而非单个提示或任务作为智能体红队测试的基本单元，通过受控的环境进化来揭示传统静态基准遗漏的累积性安全风险，为研究复杂演化环境下的智能体安全性提供了统一、可比较的可扩展基础设施。

### 2. 方法论

- **核心思想**：将“场景”作为语义评估单元。一个场景联合指定一个良性任务目标、该任务所处的可执行环境，以及一个区分安全与不安全执行的隐藏安全契约。环境可以进化，但底层场景目标与安全契约（评估器）保持不变。评估聚焦于目标可见的环境状态，而非修改提示或任务。
- **场景构建流程**：
  - 基于O*NET职业分类和现有交互式基准建立50个域的分类体系。
  - 规划器根据场景种子从超过50万个Tools、MCPs和Skills的能力语料库中检索兼容能力，将其组合成可执行的工作流DAG，并定义任务、初始环境、隐藏安全契约与确定性评估器。
  - 场景模型经编译生成初始环境，通过自动化行为探针验证评估器能正确区分安全完成与不安全泄露，并经过人工专家审计（正确率99.3%）才被接纳。
- **跨智能体运行时投影**：为每个运行时关联一个适配器ψr，将场景投影到该智能体原生的指令、能力和状态消耗位置，确保跨异构智能体保持相同的任务语义与评估标准。支持八个目标可见攻击面：工作区、指令、技能、工具、MCP、短期记忆、计划状态和长期记忆。攻击方与目标方运行于独立容器中，投影接口是唯一通信通道。
- **受控环境进化（EMHA）**：环境演变通过一个黑盒策略（EMHA）实现，每一轮通过超图路径选择、attacker LLM解码生成环境更新，经投影过滤后供目标执行，再将评估器反馈写入外部攻击状态，以引导后续提案。EMHA中目标和攻击模型参数全程冻结，仅通过外部攻击状态（检索反馈、路径价值、图池）进行测试时自适应，属于上下文学习式演化。
- **关键技术细节**：EMHA将协同环境变化建模为超图遍历，顶点为攻击子目标，超边连接先决条件与后继，通过软路径策略（soft policy）平衡勘探与利用；采用质量-多样性搜索（MAP-Elites）维护档案，用返回再分配（return redistribution）处理延迟反馈，并利用两种图编辑算子生成子代进行图演化搜索。整个过程为黑盒、无参数更新。

- **数据集 / 场景**：OpenART构造了10K个已验证的场景规格，覆盖50个领域（分为软件、IT与数据、商业与物流、金融法律政府、健康教育与研究等八大类），基于超过50万个工具/MCP/技能的本地能力库物化。任务复杂度中位数达到97次工具调用、依赖深度32、并行宽度12.5、96.5个状态对象和7.5种文件格式，远高于现有智能体安全基准（1-15次工具调用）。
- **基准对比**：与InjecAgent、ToolEmu、AgentDojo、AgentHarm、ASB和DTap等六个基准进行任务复杂度对比；与DTap进行覆盖规模、能力数量、复杂度、目标智能体数、攻击向量和搜索方式的全面对比。

### 6. 主要结论与发现

- EMHA在所有75种配置上达到**合并严格ASR 85.0%**，其中目标模型解释了ASR变量的73.6%，目标智能体解释了25.2%；智能体身份在控制模型与能力后仍额外解释7.6%的ASR差异，说明运行时实现显著影响智能体安全。

- 成功攻击揭示了当前智能体的三类反复出现的漏洞：旧假设未随环境变化而失效（计划-指称漂移、能力重绑定、检查点过期）、安全决策被传播而非重新计算、风险在长工作流中通过多个良性变化组合涌现。

### 7. 优点

- **创新单位**：以“场景”为基本评估单位，使环境可进化而任务语义与评估标准不变，实现了对持久环境状态操纵的系统研究。
- **大规模与多样性**：10K+场景、50个域、50万+能力语料，任务复杂度远超现有基准，并记录能力来源哈希以支持溯源。
- **跨智能体可比性**：目标无关的场景表示与轻量级适配器使异构智能体、模型、界面和攻击面可以受控、直接比较。
- **黑盒且参数不变**：EMHA不需要模型参数更新，通过外部状态进行测试时自适应，具有通用性和即插即用性。
- **方法论清晰**：超图建模、软策略路径学习、质量-多样性档案与返回再分配等设计均有明确表述，并与现有系列方法（如MAP-Elites、Options框架、RVF）建立联系。
- **分析深入**：对复杂度分组、传播距离、归一化执行时序和机制性案例的详尽分析，提供了远超单纯ASR指标的安全洞见。

- **算力信息缺失**：未报告GPU资源、训练或评估时长，难以为复现和扩展估算成本，也不利于生态化普及。
- **依赖LLM判断器**：严格ASR同时依赖确定性评估器和GLM-5.2判断器，判断器本身的倾向和误判可能影响结论。
- **智能体能力差异的干扰**：Aider等智能体良性完成率偏低，其ASR结果可能受能力限制影响而非纯粹的安全漏洞，解读时需谨慎。
- **环境与真实复杂度差异**：虽然OpenART努力模拟真实服务（MCP、工具、技能），但仿真或受控环境无法完全等同生产环境，攻击效果在真实部署中的迁移性尚未验证。
- **攻击面覆盖有限**：目前覆盖8个向量，但未覆盖所有潜在攻击面（如跨任务长期记忆、未指定的原生控件、多目标合作等），且向量支持因适配器而异，可能会遗漏某些智能体的特有风险。
- **机制解释仍为关联性**：智能体身份与ASR的关联虽统计显著，但具体机制未加以识别和验证，“运行时差异为何导致安全差异”有待进一步探究。
- **策略与攻击通用性局限**：EMHA作为参考策略表现良好，但并未验证其他黑盒搜索策略或防御机制在该竞技场上的表现；安全契约和评估器固定也限制了探索场景演化的其他可能方向。
