## 摘要
大型语言模型智能体日益依赖可复用技能来扩展其超越参数化知识的能力。然而，从大规模技能库中检索合适技能仍具挑战性，因为现实中的用户请求往往简洁且描述不充分，仅陈述任务目标，而所需能力和执行步骤则隐含其中。现有基准对此类请求的覆盖有限。为弥补这一空白，我们引入了 SkillReason-Bench，一个大规模跨域基准，包含 3,729 个查询和涵盖九个领域的 61,228 个技能的检索语料库。我们进一步提出 SkillReason，一个两阶段框架，将思维链推理作为技能检索的训练时监督。在第一阶段，由更强的教师模型生成的能力推理轨迹，通过对比学习、检索分布对齐和语言建模提供显式监督，鼓励检索器在查询表示中内化能力推理。在第二阶段，检索引导的 GRPO 目标鼓励模型探索更适应自身能力且对检索更有效的推理轨迹。在推理时，SkillReason 直接编码原始查询，无需自回归 CoT 生成，从而保持仅基于查询的高效检索。在 SkillReason-Bench、SkillRet 和 SRA-Bench 上的大量实验表明，SkillReason 在所有三个基准上均达到最先进性能，验证了推理增强训练能更好地弥合高层任务目标与技能能力之间的语义鸿沟。

## Abstract
Large language model agents increasingly rely on reusable skills to extend their capabilities beyond parametric knowl- edge. However, retrieving the appropriate skill from a large- scale library remains challenging because realistic user re- quests are often concise and underspecified, stating only the task goal while leaving the required capabilities and execu- tion steps implicit. Existing benchmarks provide limited cov- erage of such requests. To address this gap, we introduce SkillReason-Bench, a large-scale cross-domain benchmark containing 3,729 queries and a retrieval corpus of 61,228 skills spanning nine domains. We further propose SkillRea- son, a two-stage framework that uses chain-of-thought rea- soning as training-time supervision for skill retrieval. In Stage I, capability reasoning traces generated by a stronger teacher provide explicit supervision through contrastive learning, re- trieval distribution alignment, and language modeling, en- couraging the retriever to internalize capability reasoning in its query representation. In Stage II, a retrieval-guided GRPO objective encourages the model to explore reasoning trajecto- ries better suited to its own capabilities and more effective for retrieval. At inference, SkillReason directly encodes the orig- inal query without autoregressive CoT generation, preserv- ing efficient query-only retrieval. Extensive experiments on SkillReason-Bench, SkillRet, and SRA-Bench show that Skill- Reason achieves state-of-the-art performance across all three benchmarks, demonstrating that reasoning-enhanced training better bridges the semantic gap between high-level task goals and skill capabilities.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：大语言模型（LLM）智能体正日益依赖外部可复用技能（skills）来扩展能力边界。一个技能通常封装了任务特定指令、执行流程和辅助资源，使智能体能够复用既有经验，而非从零开始解决相似任务。
- **核心问题**：随着技能库规模不断增长，从大量候选中准确检索出适配用户请求的技能变得愈发困难。这一困难的根源不只是候选数量庞大，更根本在于**用户请求与目标技能之间存在隐含映射**——现实用户请求通常简洁自然，只陈述任务目标（如"维护频繁变载工业机械臂的稳定轨迹跟踪"），而不说明所需能力和执行步骤，检索器必须从任务目标中推断底层能力需求。
- **现有不足**：已有技能检索基准（如 SkillRet、SRA-Bench 等）的查询往往包含显式的过程描述和专业术语，对简洁、描述不充分的现实请求覆盖不足。
- **论文目标**：构建覆盖隐含请求的跨域基准 SkillReason-Bench，并提出 SkillReason 框架，弥合高层任务目标与技能能力之间的语义鸿沟，同时保持高效的查询端推理。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 整体框架概览

SkillReason 是一个两阶段推理增强训练框架，核心思想是将**思维链（Chain-of-Thought, CoT）推理作为训练时的特权监督信号**，使检索器在查询表示中内化能力推理过程，而推理阶段**无需生成 CoT**，直接编码原始查询即可完成检索。

### 2.2 问题形式化

- 给定用户请求 q 和技能语料库 S = {s₁, …, s_M}，目标是从中检索与完成任务最相关的技能。
- SkillReason 使用共享编码器 f_θ 将查询和技能文档映射为归一化表示，相关度分数由余弦相似度计算：h_θ(q, s) = e_θ(q)ᵀe_θ(s)。
- 推理时技能表示可离线预计算，模型仅编码一次原始查询即可获得检索结果。

### 2.3 阶段一：从教师推理中学习（Stage I: Learning from Teacher Reasoning）

- **核心思想**：利用更强教师模型生成的能力推理轨迹 c\* 作为特权监督。构造增强查询 q̃ = [q; c\*]，同时优化原始查询和增强查询的检索，并对齐二者的检索分布。

具体包含四个目标：

| 目标 | 公式 | 作用 |
|------|------|------|
| 原始查询对比学习 ℒ_CL^raw | 对原始查询 q 与目标技能 s⁺ 做对比学习 | 直接优化推理时使用的查询检索路径 |
| 增强查询对比学习 ℒ_CL^cot | 对增强查询 q̃ 与目标技能做对比学习 | 促使 c\* 中的能力信息改善查询-技能匹配 |
| 检索分布对齐 ℒ_KL | 将增强查询的软化检索分布迁移到原始查询（带 stop-gradient） | 使原始查询无需 c\* 也能做出与特权视图类似的检索决策 |
| 能力推理语言建模 ℒ_LM | 教师强迫方式训练模型生成推理轨迹 c\* | 使模型内化能力推理，并为阶段二初始化策略 |

- 完整目标：ℒ_SFT = ℒ_CL^raw + λ_cot·ℒ_CL^cot + λ_KL·ℒ_KL + λ_LM·ℒ_LM

### 2.4 阶段二：检索引导的推理优化（Stage II: Retrieval-Guided Reasoning Optimization）

- **动机**：阶段一学习的是一条固定的教师推理轨迹，可能与模型自身推理能力不匹配，且未必对检索目标最优。
- **方法**：采用检索引导的 GRPO（Group Relative Policy Optimization）。策略 π_θ 对每个查询采样 G 条推理轨迹 {c^(g)}，由冻结的阶段一检索器计算检索奖励。
- **奖励设计**包含三部分：
  - **检索边际奖励** R_margin：衡量增强查询与目标技能相似度减去最强负例相似度的差距（tanh 归一化），鼓励正负分离；
  - **增益奖励** R_gain：衡量增强查询相对原始查询的检索边际提升（clip 到 [-1,1]），鼓励推理轨迹比原始查询更有效；
  - **长度惩罚** P_len：对超过预算的推理长度施加封顶惩罚，避免无意义的长推理。
- 最终奖励：R^(g) = λ_margin·R_margin^(g) + λ_gain·R_gain^(g) − P_len(c^(g))
- 策略生成与查询编码共享骨干网络 f_θ，因此通过生成学到的检索相关推理能力可被内化到查询表示中。

### 2.5 推理阶段

- 直接编码原始查询，无需自回归生成 CoT，保持高效的仅查询检索。

## 6. 主要结论与发现

- **SkillReason-Bench 有效揭示基线差距**：现有技能检索器（SkillRouter、SkillRet-Embedding）在长查询的 SkillRet 上表现好，但在隐含请求的 SkillReason-Bench 上显著下降，甚至低于通用嵌入模型 Qwen3-Embedding-0.6B。SkillReason 在三个基准上均保持领先，证明推理增强训练能提升跨分布鲁棒性。
- **SkillReason 达到最先进水平**：SkillReason-4B 在 SkillReason-Bench 上 R@1 达 53.58%（较 Qwen3-Embedding-4B 提升 18.91 个百分点）；SkillReason-0.6B 对比其骨干平均提升 17.56 个百分点的 R@10，且全面超越 Qwen3-Embedding-8B。
- **推理能力可在训练时被内化**：推理时自生成 CoT 增强未带来一致增益，教师（235B）CoT 增强效果也接近查询端模型，证明训练已将能力推理内化到查询表示中，无需增加推理时延迟。
- **检索质量改善可转化为下游性能提升**：SkillReason-4B 流水线在 5 种下游 LLM 上任务准确率提升 14.66–25.03 个百分点，接近使用人工标注"黄金技能"的上界。
- **Stage-II 收益集中于隐含请求场景**：在显式过程描述为主的 SkillRet 上，阶段二未进一步改善，说明其价值体现在隐含请求推理。

## 7. 优点

- **问题定义准确**：精准识别了现实技能检索的痛点——简洁隐含请求与技能能力之间的语义鸿沟，现有基准确实覆盖不足。
- **基准构建严谨**：SkillReason-Bench 的构建流程包含多层质量控制和人工仲裁，备选技能审计和敏感性分析使评估更可靠；独立 LLM 审计显示 99.3% 通过率，验证了数据质量。
- **方法设计新颖且实用**：将 CoT 推理作为训练时监督而非推理时生成，通过分布对齐将推理知识蒸馏到查询表示中，既获得推理增强又保持推理时零额外开销。
- **检索引导 RL 设计合理**：奖励函数综合考虑检索边际、相对增益和长度惩罚，多角度塑造推理轨迹质量。
- **实验完整充分**：三个基准、多规模模型、大量消融和对照实验，以及端到端验证，证据链完整。
- **效率优势明显**：延迟测量显示 SkillReason 不增加任何在线检索开销，实际部署友好。

## 8. 不足与局限

- **基准标注的主观性**：每个查询仅标注一个官方目标技能（SkillRet 有多个），而大型开放技能库中功能可替换的技能较多。虽然论文做了备选技能敏感性分析（R@1 提升 1.37–3.54 个百分点），但分析仅覆盖 top-5 预测中的候选，相对排序虽稳定，绝对分数可能仍被低估。
- **训练数据依赖合成生成**：训练查询由 Claude Sonnet 4.6 生成，隐含改写由 Claude Haiku 4.5 完成，可能引入模型偏置和特定句法模式，尽管有质量过滤和去重，但与真实用户请求分布仍有差距。
- **部分结论的归因可进一步细化**：消融实验显示某些组件在单独使用时的效果与累积使用不一致（如分布迁移单独使用显著退化），对组件间交互机制的解释尚不充分。
- **Stage-II 有效范围有限**：检索引导 RL 在 SkillRet 上未带来增益甚至略有下降，对显式、流程化长查询可能产生过度专门化，跨分布泛化仍需关注。
- **SkillBench 评估样本量过小**：每个 split 仅 75 条查询，统计功效有限，论文也将其定位为诊断性结果。
- **与真实智能体效果的关联有待验证**：端到端评估仅在 SRA-Bench 上使用 top-1 技能的单次直接推理设置，未考察多技能组合、错误恢复等更复杂的真实智能体场景。
