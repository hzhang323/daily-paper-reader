## 摘要
现实世界的时间序列应用日益需要能够处理时间序列预测、上下文条件预测和基于语言的时间推理的模型。然而，当前的时间序列基础模型在这些能力上仍然彼此割裂：数值专用模型通常能提供最强的预测，而基于语言的模型则提供更广泛的上下文理解与分析。核心挑战在于统一这些异构能力，同时不降低它们各自的性能。我们提出 OpenTSLM TeeMoE，一个通用时间序列语言模型，能够直接根据观测到的时间序列进行预测，对文本上下文和时间模式进行推理，并综合和精炼来自外部数值预测专家的预测。我们在共享主干网络上独立训练三个低秩专家，分别用于预测聚合、原生预测和时序分析。随后，一个学习得到的 LoRA 混合专家控制器会针对每个请求对其冻结的参数更新进行加权。我们提出的模型在时间序列预测、上下文条件预测和基于语言的时间推理的广泛使用基准上取得了强劲性能，在 GIFT-Eval 上按平均 MASE 排名、在 Context is Key 上按 RCRPS、在 TimeSeriesExam 上按准确率均位列前三。

## Abstract
Real-world time-series applications increasingly require models that can handle time series forecasting, context-conditioned prediction, and language-based temporal reasoning. Yet current time-series foundation models remain fragmented across these capabilities: numerical specialists often provide the strongest forecasts, while language-based models offer broader contextual understanding and analysis. A central challenge is to unify these heterogeneous capabilities without reducing their individual performance. We introduce OpenTSLM TeeMoE, a generalist time-series language model that can forecast directly from observed time series, reason over textual context and temporal patterns, and synthesize and refine predictions from external numerical forecasting specialists. We independently train three low-rank experts for forecast aggregation, native forecasting, and temporal analysis over a shared backbone. A learned LoRA mixture-of-experts controller then weights their frozen parameter updates for each request. Our proposed model achieves strong performance on widely used benchmarks for time series forecasting, context-conditioned prediction, and language-based temporal reasoning, ranking among the top three on GIFT-Eval by mean MASE rank, Context is Key by RCRPS, and TimeSeriesExam by accuracy.

## 1. 核心问题与整体含义

- **研究动机**：真实时序应用常需同时处理三类请求——**数值预测**（forecast future demand）、**上下文条件预测**（预测干预措施的效果）、**语言化时序推理**（解读异常历史模式）。
- **现状割裂**：数值时序基础模型（TSFM，如 TimesFM、Chronos、Moirai、Toto）预测最强；时序语言模型（TSLM，如 ChatTS、OpenTSLM、TS-Reasoner）提供上下文理解与语言接口，但二者能力分离。
- **核心挑战**：能否构建一个通用模型，**同时具备广度能力而不稀释各专用模型的性能**？现有通用时序模型（UniTS、MOMENT、TsLLM、TimeOmni-1/VL）虽扩大任务覆盖，却未必保留强专用模型的表现。
- **整体含义**：论文主张通过**混合专家（MoE）+ 冻结 LoRA 组合**的模块化路线，实现"能力保留式"的统一，为通用时序语言模型提供一条实用路径。

## 2. 方法论

### 核心思想
- 在共享的 **Qwen3.6-27B** 骨干上，**独立训练三个低秩能力专家**，再用可学习的 LoRA 混合专家控制器按请求加权其**冻结**的参数更新，从而统一三类能力。

### 三个专家
- **预测聚合专家（Aggregation）**：
  - 用 XGBoost 对 8 个精选预测模型（TiRex 2、Toto 2.0、Chronos-2、Timer-S1、TimesFM 2.5、Moirai 2、FlowState、PatchTST-FM）预测相对排名并加权池化 CDF；
  - 与 Toto-FnF（十模型集成）按学习到的标量权重 **α≈0.386** 混合，构成参考预测（两池共享 5 个模型，共 **13 个候选**）；
  - 数值编码器将参考分位数、候选中位数、宽度、非对称性等编码为连续 token 输入骨干；解码器输出有界修正：
    - `q_{t,τ} = q0_{t,τ} + g_t · s_t · d_t`，约束 `|d_t| ≤ 1/2`，`0 ≤ g_t ≤ 1`
    - 分歧门 `g_t = v_t / (v_t + r_t²)`，候选分歧越大，修正越小，以保持分位数顺序与区间宽度。
- **原生预测专家（Native Forecasting）**：由 LM head 直接根据历史 + 文本上下文生成 (timestamp, value) 序列，多次采样得到经验预测分布。
- **时序分析专家（Temporal Analysis）**：回答模式识别、异常检测、序列比较、数值读取等分析问题，输出选项标签+文本或自由答案。

### 控制器与组合
- **两遍执行（Two-pass）**：
  - Pass I：禁用所有适配器，骨干编码请求，形成控制器输入表示；
  - Pass II：应用混合适配器计算响应。
- 控制器表示：`h = (1−α)h_text + α h_full`，`π = softmax(Ah + b)`，输出 3 路 softmax 权重（各层共享，整段响应固定）。
- 组合公式：`W′_ℓ = W_ℓ + Σ_{e=1..3} π_e ΔW_{e,ℓ}`，`π_e ≥ 0`，`Σ π_e = 1`。
- **输出路径选择**：当 `π_agg > 0.5` 时走数值解码器，否则走语言模型 head（无硬编码规则）。

### 训练
- 骨干、专家、数值组件全程冻结；**仅训练控制器**，损失为
  - `L_ctrl = (1/3) Σ_c (L_c + H_c)`，`L_c` 为能力预测损失，`H_c` 为输出格式损失（数值样本 `−log π_agg`，文本样本 `−log(1−π_agg)`）。
- 专家 LoRA 配置：聚合 rank 4/alpha 8；原生 rank 32/alpha 64；分析 rank 16/alpha 32。
- 文本专家使用教师强制交叉熵 + 前向（及反向）KL 正则；聚合专家使用加权 SmoothL1 + 平方编辑惩罚。

## 6. 主要结论与发现

- **三项基准均进入前三**：GIFT-Eval 平均 MASE 排名 **19.990（第 3）**；CiK RCRPS **0.115（第 3）**；TSE 准确率 **78.552%（第 1）**。
- **能力保留是最大收益**：独立训练的专家组合后仍保持各自强项——原生专家 CiK 最优（0.123），分析专家 TSE 最优（78.418%）。
- **组合带来额外增益**：相对原生专家，TeeMoE 在 CiK 上再降 RCRPS **6.6%**；TSE 上较分析专家提升 0.134 个百分点；GIFT 上略优于聚合专家。
- **优于联合训练**：TeeMoE 在 GIFT（−0.670 vs −0.608）、CiK（−0.036 vs −0.028）、TSE（+3.619 vs +2.949 pp）上均超过联合共享适配器方案。
- **学习加权优于固定混合**：等权或全强度组合均在某一任务上劣化，学习权重取得更好平衡；但 Top-1 路由已能捕获大部分收益，专家交互的额外增益较小。
- **模块化成本更低**：分离专业化 30.756 H100 小时 vs 联合 58.657，且可单独重训某一专家。
- **效率对比**：约 40B 总参数的 TeeMoE 在 CiK 上超过 405B 的 Llama-3.1-405B-Instruct，在 TSE 上超过约 117B 的 GPT-oss-120B 混合智能体，也优于 GPT-5.2 的预测修正方案。
