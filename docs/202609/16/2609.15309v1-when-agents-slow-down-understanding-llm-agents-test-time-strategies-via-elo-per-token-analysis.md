## 摘要
大型语言模型（LLM）智能体在修改解答、使用工具、探索备选方案以及决定何时停止时，会自适应地分配测试时计算量。这种测试时策略使得衡量智能体性能如何扩展变得困难。我们研究能够为中间提交提供连续分数的开放式任务，从而使长轨迹中的进展可被观测。我们提出每 token Elo 分析（Elo-per-token analysis），它追踪每个 token 预算下找到的最佳解，并使用 Bradley-Terry 模型将任务内的排序聚合为跨任务的 Elo 评分，以适用于分数尺度不同的任务。我们将其应用于四个通用智能体在四个开放式基准上的表现（会话长度最高达 1 亿 token），以及三个反馈驱动的 LLM 优化框架在受控单任务干预中的表现。独立采样提供了一个具有理论刻画的参照，其 Elo 随 log 计算量线性增长。相对于该参照，智能体在初始阶段能比独立采样更快地将 token 转化为 Elo，但其边际收益递减，最终低于该参照。相比之下，最强的历史人类选手在共享的 AtCoder Heuristic Contest 任务上随比赛时间呈超线性提升，这提供了持续学习以及智能体放慢后仍有可观提升空间的证据。我们将缩放拐点定义为边际 Elo 收益与独立采样参照相等的每会话预算。以该点作为每会话预算，我们在 FrontierCS Polyomino Packing 上将 1 亿 token 分配到并行的多个会话中，相比一个长会话获得 +264 Elo，相比十个短会话获得 +355 Elo。

## Abstract
Large language model (LLM) agents allocate test-time compute adaptively as they revise solutions, use tools, explore alternatives, and decide when to stop. This test-time strategy makes it difficult to measure how agent performance scales. We study open-ended tasks that provide continuous scores for intermediate submissions, making progress observable throughout long trajectories. We propose Elo-per-token analysis, which tracks the best solution found at each token budget and uses a Bradley-Terry model to aggregate within-task orderings into Elo ratings across tasks with different score scales. We apply it to four general-purpose agents on four open-ended benchmarks, with sessions of up to 100M tokens, and to three feedback-driven LLM optimization harnesses in controlled single-task interventions. Independent sampling provides a theoretically characterized reference, for which Elo grows linearly with log compute. Against this reference, agents can initially convert tokens into Elo faster than independent sampling, but their marginal gains diminish and eventually fall below the reference. In contrast, the strongest historical human contestants improve superlinearly over contest time on shared AtCoder Heuristic Contest tasks, providing evidence of continual learning and substantial headroom after agents slow down. We define the scaling inflection point as the per-session budget where marginal Elo gains match the independent-sampling reference. Using this point as the per-session budget, we split 100M tokens across parallel sessions on FrontierCS Polyomino Packing, gaining +264 Elo over one long session and +355 over ten short sessions.

## 1. 核心问题与整体含义

- **研究动机**：LLM 智能体在测试时（test-time）会自适应地分配推理算力——修改解答、调用工具、探索备选方案、决定何时停止。这种"测试时策略"使得衡量智能体性能随计算量如何扩展变得困难。
- **现有评测的缺陷**：标准基准（如 SWE-bench）只返回一次通过/失败判定，并丢弃整个轨迹；开放式任务虽有连续分数，但原始分数在不同任务间单位不一，且任务内相同增量并不代表相同进展（如从 80% 到 81% 可能远比 50% 到 60% 困难）。
- **核心问题**：智能体性能究竟如何随测试时计算量扩展？其自适应策略把 token 转化为性能的速度是快于还是慢于独立采样？
- **整体含义**：论文揭示了一个反直觉的结论——当前通用智能体在最初几轮上下文压缩后，其扩展速度不再快于独立重复采样；而人类顶尖选手在同一任务上持续超线性提升，说明"持续学习"仍是智能体与人类之间的关键差距，且智能体放慢后仍有巨大提升空间。

## 2. 方法论：Elo-per-token 分析框架

- **核心思想**：不比较原始分数，而是比较排序。在每个 token 预算下追踪"迄今最佳解"（best-so-far），用 Bradley-Terry 模型将任务内两两比较结果聚合为跨任务的 Elo 评分，从而在不同分数尺度的任务间建立统一标度。
- **关键构造**：
  - 对会话 τ 记录所有（分数 $s_i$，累计 token $b_i$）对，定义最佳前缀最大值 $S^{(d)}_\tau(b) = \max\{s_i : b_i \le b\}$。
  - 每个（智能体系统，token 预算检查点）构成一个"选手" $p_{a,b}$；在任务内两两比较，高分胜、同分平局。
  - Bradley-Terry 期望胜率：$E[y_{pq}] = 1/(1+10^{-(r_p-r_q)/400})$，用 MM 算法（Hunter 2004）做最大似然估计，锚定最低预算选手为 1000。
- **两种曲线**：
  - **Joint-Elo**：保留所有跨检查点对局，将不同系统置于同一评分尺度。
  - **Self-Elo**：只保留同一系统内检查点对局，并剔除同一会话内的对局（因前缀最大值单调，同会话对局会被预先决定，造成虚假上升漂移），仅保留跨会话对局以隔离系统自身的扩展性。
- **独立采样参考线**：定理 3.1 证明，若尝试分数 i.i.d. 连续分布，独立采样 best-of-n 与 best-of-m 的群体 Elo 差为 $400\log_{10}(n/m)$，即每十倍 token 预算恰好增益 **400 Elo**（分布无关）。
- **缩放拐点（Scaling Inflection Point）**：$b_{\text{inf}} = \sup\{b : dr(b)/d\log_{10}b > s_{\text{ref}}\}$，即边际 Elo 增益恰好等于独立采样参考的每会话预算。
- **分配规则**：给定总预算 $B$，设 $K = \max\{1, \lfloor B/b_{\text{inf}} \rceil\}$，运行 K 个独立并行会话并取最优解。定理 6.2 证明该分配相对单会话可获 $400\log_{10}K$ 的 Elo 增益。

## 6. 主要结论与发现

- **智能体至多 log-linear，最终低于独立采样**：所有四个智能体系统在四个基准上均随预算增加而提升，但边际收益递减；局部 self-Elo 斜率最初可超过 400，但随后下降，在最大预算处普遍低于 400 Elo/decade 参考线。
- **上下文管理仍是显著问题**：在最初几次上下文窗口压缩后，智能体的自适应策略不再提供相对独立采样的渐近扩展优势。
- **人类持续超线性提升**：在 AHC 任务上，前 10 与前 50 人类选手的 self-Elo 曲线对 log 比赛时间呈凸形（超线性），且前 10 选手最终在时间对齐的 joint-Elo 上反超智能体，表明人类存在持续学习。
- **专用测试时策略不改变扩展形状**：AdaEvolve、GEPA、TTT-Discover 均只获得早期优势，随后同样回归递减回报，未能恢复超线性扩展。
- **缩放拐点可指导预算分配**：在 FrontierCS Polyomino Packing 上，拐点为 38M token，预测 3 会话分配；在 100M 总预算下，3 会话分配比单长会话 +264 Elo，比 10 个短会话 +355 Elo；MLS-Bench 上同样优于两个极端。
- **粘性盆地假说**：早期轨迹将智能体锁定在某个解盆地（算法思路、代码结构、高层策略），继续增加深度只能在盆地内改进，任何固定倍数的深度增加相对盆地间差异最终可忽略（定理 7.1）。

## 7. 优点

- **指标设计新颖且具理论支撑**：Elo-per-token 只依赖任务内排序，天然跨任务可比、对原始分数非线性不敏感；独立采样参考线（400 Elo/decade）分布无关，为智能体曲线提供了外部、可解释的基准。
- **人类-智能体同台比较**：利用 AtCoder 历史提交记录经同一评测器重评，实现真正时间对齐的人类 vs 智能体对比，而非间接推断。
- **理论贡献完整**：给出独立采样参考（定理 3.1）、拐点后框架失效（定理 6.1）、拐点分配增益（定理 6.2）、粘性盆地极限（定理 7.1）四组定理，形成从度量到分配的闭环。
- **实验设计严谨**：剔除同会话对局、session-level bootstrap、随机化分配平均、人类数据一致性校验（要求 top-10 在 ≥90% 两两比较中胜过 11–50 名）等细节处理到位。
- **可操作性强的分配规则**：从 Elo-per-token 曲线直接读出拐点，给出简单且经验证有效的并行会话数选择规则。

## 8. 不足与局限

- **拐点难以事先预测**：论文明确指出，领域级曲线（如 Kimi K2.7 的 FrontierCS 域曲线）的斜率交叉点与任务级拐点（Polyomino Packing 的 38M）不一致；如何从任务属性或早期会话统计预测任务级拐点仍是未解问题。
- **粘性盆地仅为假说**：定理 7.1 基于高斯盆地与独立同分布候选的简化模型，盆地并非字面局部最优，其经验验证有限。
- **Token 记账的可比性问题**：cache-inclusive 与 uncached token 轴在不同策略类之间不可直接比较（演化方法 84% uncached，智能体会话仅 3–5% uncached），跨类别比较依赖轴选择；规模扫描也受服务商混杂影响。
- **模型与任务覆盖限制**：仅评测四个通用智能体与特定版本模型；14 个任务虽跨四基准，但对整个开放式任务空间仍属有限；人类对比主要基于 AHC 竞赛，外部效度有待检验。
- **深度与 token 的互换性仅为猜想**：附录 F.3 中"更深模型需要比例更少 token"的论断被明确声明为 conjecture，因规模扫描混杂了宽度、专家数与训练差异。
- **成本与可复现性**：100M token 级会话依赖商业 API，成本高且受速率限制；部分遥测数据缺失导致某些系统被排除在特定分析之外。
