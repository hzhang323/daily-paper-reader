## 摘要
长期时间序列预测受益于保留趋势和季节性等全局结构。最近的基于LLM的预测器通常通过测试时扩展（例如，迭代细化）来提高准确性，但这些方法计算成本高昂，并且随着预测范围的延长，越来越容易出现全局形状不匹配的问题。我们提出了SCALER，一种从粗到细的预测框架，首先采用专为长期形状建模设计的轻量级Transformer来预测未来动态的粗粒度表示。然后，该预测形状作为紧凑的指南，通过迭代的从粗到细的残差令牌细化，引导LLM进行测试时扩展，同时在每一步处理显著更少的令牌。通过使用显式的未来形状预测来指导细化，SCALER减少了对长描述提示的依赖，其固定步数的细化避免了昂贵的基于奖励模型的选择，进一步降低了计算开销。实验结果表明，SCALER在长期、短期和零样本预测中均优于强预测基线，同时显著降低了与扩展LLM用于时间序列预测相关的推理成本。代码：https://github.com/xuanmay2701/SCALER。

## Abstract
Long-term time series forecasting benefits from preserving global structure such as trends and seasonality. Recent LLM-based forecasters often improve accuracy through test-time scaling (e.g., iterative refinement), but these methods are computationally expensive and increasingly prone to global-shape mismatch as the prediction horizon extends. We propose SCALER, a coarse-to-fine forecasting framework that first employs a lightweight Transformer tailored to long-term shape modeling to predict a coarse representation of future dynamics. This predicted shape then serves as a compact guide for an LLM to perform test-time scaling via iterative coarse-to-fine residual token refinement, while processing substantially fewer tokens at each step. By guiding refinement with an explicit future-shape prediction, SCALER reduces reliance on long description prompts, and its fixed-step refinement avoids costly reward-model-based selection, further lowering computational overhead. Experimental results demonstrate that SCALER outperforms strong forecasting baselines in long-term, short-term and zero-shot forecasting while significantly reducing the inference cost associated with scaled LLM for time series forecasting. ## 1. 论文的核心问题与整体含义（研究动机和背景）

长期时间序列预测（Long-term Time Series Forecasting, LTSF）在诸多实际领域（金融、医疗、天气、能源等）中至关重要，其关键在于**保留全局结构**（如趋势、季节性和状态变化）。近年来，基于大语言模型（LLM）的预测器通过**测试时扩展（Test-Time Scaling）**（如迭代细化、候选生成与奖励模型筛选）显著提升了预测精度，但该方法面临两个核心挑战：

- **计算成本高**：迭代细化和候选选择需要反复处理长序列，推理成本随预测长度和精度要求快速增长。
- **全局形状漂移（Global-Shape Drift）**：重复的局部修正会累积为全局形状失配，尤其是在预测范围延长时，趋势和季节性易被扭曲。

此外，现有方法往往依赖长文本提示或昂贵的奖励模型筛选，进一步加重了上述问题。为解决这些痛点，论文提出 **SCALER（Coarse-to-Fine Test-Time Scaling）** 框架，通过“先粗后细”的解耦设计，实现高效且形状稳定的测试时扩展。

## 2. 论文提出的方法论

### 2.1 核心思想

SCALER 采用**两阶段粗到细（Coarse-to-Fine）**框架：

- **Stage I（粗形状预测）**：用一个轻量级 Transformer 预测未来序列的**下采样粗粒度形状**（捕捉低频结构如趋势/季节性）。
- **Stage II（固定步长多尺度细化）**：用预训练 LLM 作为 refiner，以粗形状为锚点，逐步细化生成更精细的 token 块。

### 2.2 关键技术细节

**（1）多尺度 Patch 编码（Multi-Scale Patch Encoding）**
- 将原始时间序列 patch 化，通过编码器 E（原型交叉注意力机制，将 LLM 词嵌入矩阵映射为原型集）转换为 token 序列，使时间序列 patch 对齐到 LLM 嵌入空间。
- 定义从粗到细的下采样尺度集 `{Scale_1, ..., Scale_K}`，通过“归一化→插值下采样”操作生成不同尺度的目标序列。

**（2）Stage I：全局粗形状预测器**
- 轻量 Transformer F 基于历史序列 X 预测粗形状 Ŝ₁（回归损失 L_shape = MSE(Ŝ₁, S₁)）。该预测器仅建模低分辨率下的全局结构，计算成本极低。

**（3）Stage II：固定步长多尺度细化**
- 初始化上下文：历史 token 序列 Z_I = Encoding(X) + 粗形状 token Z_S = [Encoding(Ŝ₁)]。
- 迭代细化：第 k 步，LLM refiner G 在条件上下文 (Z_I, Z_S) 上预测更细尺度的 token 块 Ŝ_k，并追加到 Z_S 中。共执行固定 K 步。
- 每一步的细化目标为当前尺度下采样后的 token 序列，使用 L_refine = Σ‖Ŝ_k - S_k‖² 作为逐尺度损失。
- 解码：最终用解码器 D 将累积的 token 上下文解码为全分辨率预测 Ŷ，并施加时间序列空间 L_ts 损失。

**（4）总体训练目标**：
```
L = L_shape + λ·L_refine + β·L_ts
```
其中 λ、β 为平衡权重（默认均为 1）。

**（5）推理流程**：固定 K 步细化，无需候选生成或奖励模型筛选，计算成本可预测，部署友好。

### 2.3 算法流程（文字描述）

- **训练**：输入历史 X 和未来 Y → 对 Y 做下采样得到粗目标 S₁ → F 预测 Ŝ₁（L_shape）→ 编码历史得 Z_I → 初始化解码上下文 Z_S=[Encoding(Ŝ₁)] → 循环 K 步：下采样 Y 得 Y_k → LLM 预测 Ŝ_k（累积 L_refine）→ 追加到 Z_S → 解码得 Ŷ（L_ts）→ 联合优化。
- **推理**：F 预测粗形状 → 编码历史和粗形状 → 固定 K 步 LLM 细化 → 解码最终预测。

- SCALER 在**长期、短期和零样本**三大类基准上均取得最佳或接近最佳精度，且多次获得第一名计数（长期 19/28 的 MSE 和 MAE 双第一；短期 12/12 全第一；零样本 9 个第一）。
