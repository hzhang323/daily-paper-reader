## 摘要
在上下文学习、检索增强生成和基于提示的时间序列预测中，基于相似度的检索是对大语言模型（LLM）进行条件化的主导规则。该规则聚焦于近似重复的候选，这一问题推动了多样性感知检索，但在其他以检索为条件的流程中仍未得到考察。我们以基于提示的时间序列预测作为试验平台来研究这一问题，其中通过相似度检索一个可学习的提示池。该场景中的主流方法通过余弦相似度检索前 K 个条目，而不进行冗余控制，从而偏向主导性时间模式，同时忽视稀有但信息丰富的事件。我们提出 CASP-LLM，一种覆盖感知的语义提示框架，它通过将使用跟踪与饱和门控技术结合为一个不增加可学习参数的覆盖正则化器，来解决这种提示选择偏差。在六个长期基准和 M4 短期基准上，CASP-LLM 在大多数数据集-预测长度设置中与基于相似度的 LLM 预测器持平或更优，但 Electricity、M4-Monthly 和少样本长时程设置除外。一项对照研究将失败模式定位在跨批次使用层面，而不是每次检索的冗余：诸如 MMR 之类的检索内多样化没有帮助，而在训练过程中对锚点使用进行正则化则有效。

## Abstract
Similarity-based retrieval is the dominant rule for conditioning large language models (LLMs) in in-context learning, retrieval-augmented generation, and prompt-based time series forecasting. The rule concentrates on near-duplicate candidates, an issue that has motivated diversity-aware retrieval but remains unexamined in other retrieval-conditioned pipelines. We study this issue using prompt-based time series forecasting as a test bed, where a learned prompt pool is retrieved by similarity. Dominant methods in this setting retrieve top-K entries by cosine similarity without redundancy control, producing a bias toward dominant temporal patterns while overlooking rare but informative events. We propose CASP-LLM, a coverage-aware semantic prompting framework that addresses this prompt selection bias by combining usage-tracking and saturating-gate techniques into a coverage regularizer that adds no learnable parameters. On six long-term benchmarks and the M4 short-term benchmark, CASP-LLM matches or improves on similarity-based LLM forecasters on most dataset-horizon settings, with the exceptions of Electricity, M4-Monthly, and the few-shot long-horizon setting. A controlled study locates the failure mode at the cross-batch usage level rather than per-retrieval redundancy: within-retrieval diversification such as MMR does not help, whereas regularizing anchor usage across training does.

## 1. 核心问题与整体含义

- **背景**：在上下文学习（ICL）、检索增强生成（RAG）以及基于提示的时间序列预测中，"基于相似度的检索"（top-K 余弦相似度）是给大语言模型做条件化的主导规则。
- **已知缺陷**：该规则倾向于选中近重复候选，导致所选集合坍缩、无法覆盖候选池的表示多样性。这一问题在 ICL 示例选择和 RAG 中已有大量补救工作（MMR、DPP、子模覆盖等），但在其他"检索条件化"的 LLM 流程中**尚未被系统考察**。
- **研究切入点**：作者以"基于提示的时间序列预测"作为试验台——该场景中有一个小型、可学习、显式检索的提示池（如 TEMPO、S²IP-LLM），使选择机制及其后果可直接测量。
- **核心问题命名**：作者将相似度检索集中在少数语义锚点、偏向主导时序模式、忽视稀有但信息丰富事件的现象称为 **prompt selection bias（提示选择偏差）**。
- **整体含义**：论文主张，该偏差的根源不在"单次检索内部的冗余"，而在**跨训练批次的锚点使用累积**；因此正确的干预点应是训练目标层面，而非单次检索的重排序层面。

## 2. 方法论

### 2.1 核心思想
- 在保持 top-K 相似度检索规则**完全不变**的前提下，通过一个**不引入可学习参数**的覆盖正则项，在训练过程中重塑嵌入几何，使被过度使用的锚点相似度下降、欠使用锚点变得可竞争。

### 2.2 关键技术细节

- **语义对齐（Semantic Alignment）**
  - 时间序列按 PatchTST 方式切分为重叠 patch（patch 长度 16，步长 8）。
  - 每个 patch 做经典加性季节-趋势分解，得到趋势、季节、残差三分量，沿通道维拼接并展平为统一 patch 向量（维度 D = 3·P_patch）。
  - 经可学习线性投影映射到 LLM 嵌入空间（d = 768，与 GPT-2 词嵌入宽度一致）；对 patch 取平均得到样本级查询表示。
  - **锚点分支**：不采用随机初始化的软提示，而是对预训练 GPT-2 词嵌入表 E ∈ R^{V×d}（V = 50257）施加可学习线性投影 f(·)，得到 V′ = 1000 个"语义锚点"。每个锚点是预训练词嵌入的线性组合，不对应具体词。

- **覆盖感知检索（核心贡献）**
  - 相似度：s_{b,i} = 归一化查询 · 归一化锚点，取值 [−1, 1]。
  - **锚点使用追踪（EMA）**：  
    c̃_i^(t) = β·c̃_i^(t−1) + (1−β)·s̄_i^(t)，其中 s̄_i^(t) = (1/B)·Σ_b max(s_{b,i}, 0)，β = 0.99。  
    零截断保证 c̃_i 与 s_{b,i} 同尺度，这是饱和门有效的前提。EMA 更新**仅在训练时进行**，验证/推理时冻结。
  - **Top-K 选择**：I_b = TopK(s_b, K)，该规则保持不变。
  - **复合目标**：L_total = L_forecast + λ_sim·L_sim + λ_cov·L_cov。
    - L_sim 惩罚所选锚点与查询的相似度差距：L_sim = (1/B)·Σ_b Σ_{i∈I_b} (1 − s_{b,i})。
    - **覆盖损失（饱和 min 门）**：  
      L_cov = (1/B)·Σ_b Σ_{i=1}^{V′} min( max(s_{b,i}, 0), sg[c̃_i^(t)] )，sg[·] 为 stop-gradient。
  - **饱和门语义**：对累积使用量 c̃_i 高的锚点，门返回 s_{b,i}，在很大范围的查询上压低其相似度；对 c̃_i ≈ 0 的锚点，门饱和于 c̃_i，几乎不施加惩罚。
  - **stop-gradient 的作用**：防止优化器通过整体压低所有相似度来"作弊"降低 L_cov；闭式梯度显示每个相似度的覆盖梯度贡献至多 λ_cov/B，不会在量级上压倒预测梯度。

- **提示增强预测**
  - 以 GPT-2 为解码骨干（6 层、768 隐维、12 头）。
  - top-K 锚点嵌入作为前缀与 patch 嵌入拼接，经因果注意力处理，再经线性输出层预测。
  - 遵循 OFA/S²IP-LLM 的部分微调策略：**冻结多头注意力和前馈层，只微调位置嵌入和层归一化**。

- **算法流程（文字化）**：每个前向 pass 计算相似度矩阵 → 训练时用 max(s,0) 的批均值更新 EMA 缓冲 → 按原始相似度做 greedy top-K → 用 min(s⁺, sg[c̃]) 逐元素门控得到 L_cov → 收集所选锚点相似度得到 L_sim → 汇总为 L_total 反传。

## 6. 主要结论与发现

- **性能**：长期 24 个 MSE 单元中 18 个取得最好或次好（14 个最好）；MAE 17/24。跨全部步长平均后，在 Weather、ETTh2、ETTm1、ETTm2 上取得最低平均 MSE；ETTh1 上 S²IP-LLM 最好；Electricity 上 iTransformer 最好（0.1640 vs 0.1702）。M4 上跨频率平均 sMAPE 与 MASE 最佳。
- **例外情形**：Electricity（四单元无可测效应，最长步长反而 +1.4%）、M4-Monthly（OFA 更优）、少样本长步长（10% 数据、步长 720 时，CASP-LLM 在全部 ETT 数据集上落后于 S²IP-LLM 和 OFA，在 ETTm1/ETTm2 上落后于 DLinear）。
- **失效模式定位（关键发现）**：问题在**跨批次使用层面**，而非单次检索内的冗余。
  - MMR 在四个单元上**没有任何配置**优于纯相关性选择（α = 0.5 在 ETTh1-96 上劣化 2.2%）。
  - 熵正则化和 KL-to-uniform **完全不改变选择分布**（每个单元都停在下限 ln K）。
  - Switch 负载均衡虽把使用熵推高到远高于下限（选中数百个锚点），但**误差最高**。
  - 唯独覆盖项在 ETTh1 两个步长上降低误差。
- **机制刻画**：
  - 覆盖项**不拓宽**收敛后的使用集合（熵保持在下限 ln K），而是**重新定位**所选锚点到池中不同区域（不同条件下所选集合近乎不相交，Jaccard 重叠接近零）。
  - 它改变的是**所选键的几何排布**：ETTh1-96 上键平均余弦从 0.9971（λ_cov = 0）降到 0.3657（最优设置）。
  - 效应**被限定**：ETTh1-336 上余弦在所有权重下都高于 0.92，误差仍改善 4.2%，说明几何重塑既非误差下降的必要条件，也不在每个步长出现。
  - PCA 显示锚点嵌入在 λ_cov = 0 时高度各向异性（PC1 占 0.985），随 λ_cov 增大变得更各向同性（0.1 时 PC1 = 0.558、PC2 = 0.410）。
  - 分层分析：高残差（最难 decile）窗口改善 −0.64%（40/64 对改善，p = 0.085），最易 30% 窗口几乎不变（−0.02%，p = 0.818），增益集中在困难输入且未牺牲易样本精度——但该效应只是边际显著。
  - 覆盖项**与分解表示耦合**：仅在分解输入行降低误差（8 种子中 7 个改善，p = 0.039）；在原始输入下效果消失甚至反向。
  - 锚点替换实验：15/16 个设置-扰动对性能下降，随机替换劣化（+2.6%）大于打乱替换（+1.2%），说明检索到的锚点携带超越嵌入空间邻近度的任务相关信息。
