## 摘要
我们提出了一种贝叶斯广义网络自回归（BGNAR）模型，用于其分量序列与已知网络节点相关联的多元时间序列。所提出的框架将广义网络自回归（GNAR）模型的简约网络结构与借鉴贝叶斯向量自回归（BVAR）建模的结构化收缩和持续性先验相结合。我们将 Minnesota 型收缩适配到自身滞后和网络滞后系数上，先验方差随滞后阶数增加而递减，并且对于网络效应，随邻域阶数增加而递减。自身滞后系数上的分层先验允许信息跨节点共享，同时保留节点特定的异质性。我们进一步将系数和先验与虚拟初始观测先验适配到 GNAR 参数化中。后验推断使用 Gibbs 采样器进行。模拟研究表明，BGNAR 可以在不同数据集上使用相同的、刻意过度设定的时间与邻域结构，而无需针对数据集进行 BIC 阶数选择，同时保持与 BIC 选择的 GNAR 相当的预测精度，并在所考虑的情形中优于无限制的 BVAR 基准。结构化先验在该固定模型内将支持较弱的系数正则化到零附近。动态系数的后验分布和未来观测的后验预测分布直接量化了参数不确定性和预测不确定性。一个风速网络的应用表明，BGNAR 达到了与 GNAR 相当的点预测性能，同时还提供了对自身滞后和网络滞后效应的后验推断以及后验预测不确定性。

## Abstract
We propose a Bayesian generalized network autoregressive (BGNAR) model for multivariate time series whose component series are associated with the nodes of a known network. The proposed framework combines the parsimonious network structure of the generalized network autoregressive (GNAR) model with structured shrinkage and persistence priors adapted from Bayesian vector autoregressive (BVAR) modeling. We adapt Minnesota-type shrinkage to both own-lag and network-lag coefficients, with prior variances decreasing over temporal lags and, for network effects, neighborhood orders. A hierarchical prior on the own-lag coefficients allows information to be shared across nodes while retaining node-specific heterogeneity. We further adapt the sum-of-coefficients and dummy-initial-observation priors to the GNAR parameterization. Posterior inference is performed using a Gibbs sampler. Simulation studies show that BGNAR can use the same deliberately over-specified temporal and neighborhood structure across datasets without dataset-specific BIC order selection, while maintaining forecasting accuracy comparable to BIC-selected GNAR and outperforming the unrestricted BVAR benchmark in the settings considered. The structured prior regularizes weakly supported coefficients toward zero within this fixed model. Posterior distributions for the dynamic coefficients and posterior predictive distributions for future observations provide direct quantification of parameter and predictive uncertainty. An application to a wind-speed network demonstrates that BGNAR achieves point-forecast performance comparable to GNAR while additionally providing posterior inference on own-lag and network-lag effects and posterior predictive uncertainty.

## 1. 核心问题与整体含义

- **研究背景**：大量多元时间序列观测于存在交互关系的单元之上（如空间监测站、贸易国家、流行病区域），可用已知网络刻画节点间依赖。此时变量的演化不仅取决于自身历史，还受邻居历史影响。
- **现有方法的痛点**：
  - **无约束 VAR**：p 阶 VAR 对 N 个变量含 N²p 个动态系数，参数量随维度二次增长，在时间序列较短时估计不确定性大、样本外表现差。
  - **BVAR**：通过 Minnesota 先验、和系数（SOC）与虚拟初始观测（DIO）先验施加结构化收缩，缓解过度参数化，但**不利用已知网络结构**。
  - **GNAR（Knight et al., 2020）**：利用网络结构使参数量随 N 线性增长（个体 α 设定下为 Np + Σsⱼ），但**需要针对每个数据集用 BIC 选择时序阶与邻域阶**，缺乏统一固定模型。
- **整体含义**：本文提出 **BGNAR（Bayesian Generalized Network Autoregressive）**，将 BVAR 的收缩与持续性先验体系系统性地适配到 GNAR 参数化中，目标是在**无需逐数据集选阶**的前提下，用一个刻意过度指定的固定模型同时实现：预测精度不劣于 BIC-GNAR、优于无约束 BVAR，并直接提供参数与预测的不确定性量化。

## 2. 方法论

- **GNAR 基础模型**：
  - 节点 i 的 r 阶邻域 N⁽ʳ⁾ᵢ = {q : d_G(i,q)=r}，权重矩阵 W⁽ʳ⁾ 行归一化（w⁽ʳ⁾ᵢq = 1/|N⁽ʳ⁾ᵢ|，若 q∈N⁽ʳ⁾ᵢ，否则 0），使邻域项为**邻域平均**而非度相关求和。
  - 个体 α 的 GNAR(p,s)：X_{i,t} = μᵢ + Σⱼ[α_{i,j}X_{i,t−j} + Σ_r β_{j,r} Σ_{q∈N⁽ʳ⁾ᵢ} w⁽ʳ⁾ᵢq X_{q,t−j}] + u_{i,t}。
  - 向量形式：Xₜ = μ + Σⱼ ΦⱼX_{t−j} + uₜ，其中 Φⱼ = diag(αⱼ) + Σ_r β_{j,r}W⁽ʳ⁾；进一步写成回归形式 Xₜ = Hₜγ + uₜ，γ = (μ⊤, θ⊤)⊤。
  - 误差假设对角协方差：Dᵤ = diag(σ²₁,…,σ²_N)，即无跨节点同期相关，避免估计完整 N×N 协方差。
- **Minnesota 型结构化收缩（核心创新）**：
  - **自身滞后系数分层建模**：α_{i,j} = bⱼ + v_{i,j}，其中 bⱼ ~ N(0, λ²_α j^{−a}) 为跨节点共享成分，v_{i,j} ~ N(0, κ_αλ²_α j^{−a}) 为节点偏离。κ_α 控制池化强度（Corr(α_{i,j}, α_{q,j}) = 1/(1+κ_α)）：κ_α 小则强池化，大则保留异质性。
  - **网络滞后系数**：βⱼ | λ²_β, a, d ~ N(0, λ²_β j^{−a}D_{β,j}(d))，D_{β,j}(d) = diag(1^{−d},…,sⱼ^{−d})，即 Var(β_{j,r}) = λ²_β j^{−a} r^{−d}。
  - **双维度衰减**：a 控制时序滞后衰减（自身与网络系数共用），d 控制邻域阶衰减（仅网络系数）。二者均取离散网格 {1, 1.5, 2, 2.5, 3}，均匀类别先验，从而支持 Gibbs 中的精确类别更新。
  - 合并为 θⱼ | bⱼ,… ~ N(m_{θ,j}(bⱼ), V_{θ,j})，进而 γ | b,… ~ N(m_γ(b), V_γ)。
- **SOC 与 DIO 持续性先验的适配**：
  - **SOC**：目标 (Φ₁+…+Φ_p)diag(X̄₀) ≈ diag(X̄₀)，通过虚拟观测 X_soc、Y_soc 实现；因 GNAR 参数化下 N² 个方程仅有 q = rank(M_soc) 个非冗余方向，**用 SVD 投影到 q 维非零奇异子空间**，避免冗余方向进入高斯归一化项而夸大紧度信息。
  - **DIO**：目标 μ + (Φ₁+…+Φ_p)X̄₀ ≈ X̄₀，无需降维，虚拟块为 N 维。
  - 两者以独立紧度参数 τ²_soc、τ²_dio（逆伽马先验）控制影响，虚拟块残差不参与 Dᵤ 更新。
  - 采用**维度校准先验**，使后验均值适应平均平方虚拟残差而非原始残差平方和；取 a_τ = 2.5、b_τ = 1。
- **超参数设置**（所有模拟与实际应用统一）：
  - c_μ = 10⁷s²_X（极扩散截距先验，s_X 为原始训练数据池化标准差）。
  - σ²ᵢ ~ IG(2, s²_X)，κ_α ~ IG(3, 2)，λ²_α, λ²_β ~ IG(3, 0.16)（众数 0.04，系数尺度约 0.2，参照 BVAR 实现）。
  - 训练数据不中心化、不标准化。
- **后验计算**：Gibbs 采样器，9 个步骤——γ（高斯）、σ²ᵢ（逆伽马）、bⱼ（高斯）、λ²_α、κ_α、λ²_β（逆伽马）、a 与 d（类别/离散）、τ²_soc 与 τ²_dio（逆伽马）；所有全条件分布均为闭式。代码开源：`github.com/zlatjdals/BGNAR`。

## 3. 实验设计

- **对比基准**：
  - **BGNAR**：固定 p = 5、s = (3,3,3,3,3) 的刻意过度指定包络，个体 α 设定；Gibbs 2000 次迭代，丢弃前 1000，每 2 抽 1，保留 500 后验样本。
