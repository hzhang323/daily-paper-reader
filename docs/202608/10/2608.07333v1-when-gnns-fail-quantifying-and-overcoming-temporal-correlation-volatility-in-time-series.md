## 摘要
通过将多元时间序列表示为图（其中各个序列作为节点，成对的时间相关性作为边）进行建模已获得广泛关注。图神经网络（GNN）的最新进展通过假设静态图拓扑并聚合来自相邻序列的信息，展现了强大的性能。在本工作中，我们研究了GNN在静态和动态设置（即成对相关性随时间剧烈演化）下进行预测的表征能力，并识别了当前架构中的关键局限性。为形式化这一研究，我们首先提出时间相关性波动（TCV），一种与模型无关的度量，旨在量化这些潜在结构的分布演化。我们建立了TCV与性能下降之间的明确联系，表明许多流行模型（包括Transformer）在高TCV场景下泛化能力较差，并且往往被简单的、与结构无关的基线所超越。为解决这些局限性，我们提出动态环境推断图层（GLIDE），一种新颖的GNN层，通过两种有理论依据的设计机制增强：（D1）基于路径的消息传递，捕获基于路径的邻域；（D2）静态与动态传播分离，通过局部静态近似识别最优动态。这些组件显著提升了动态拓扑下的学习能力，同时保持静态场景下的鲁棒性。在合成和真实世界基准上的大量实验表明，GLIDE在静态和动态设置下的平均性能提升高达45.6%，最大增益达到85.7%。源代码可在https://github.com/ChenS676/GLIDE获取。

## Abstract
Modeling multivariate time series by representing them as graphs, where individual series act as nodes and pairwise temporal corre- lations serve as edges, has gained significant traction. Recent advances in Graph Neural Networks (GNNs) have demonstrated strong perfor- mance by assuming a static graph topology and aggregating information from neighboring series. In this work, we investigate the representa- tional power of GNNs for forecasting under both static and dynamic settings (i.e., when pairwise correlations evolve drastically over time) and identify critical limitations in current architectures. To formalize this, we first propose Temporal Correlation Volatility (TCV), a model- agnostic metric designed to quantify the distributional evolution of these latent structures. We establish a clear connection between TCV and performance degradation, demonstrating that many popular models, including Transformers, generalize poorly in high-TCV settings and are often outperformed by simple structure-agnostic baselines. To address these limitations, we propose Graph Layer for Inference in Dynamic En- vironments (GLIDE), a novel GNN layer enhanced by two theoretically grounded design mechanisms: (D1) Path-based Message Passing, which captures path-based neighborhoods and (D2) Static and Dynamic Propagation Separation, which identifies optimal dynamics via local static approximation. These components significantly improve learning under dynamic topology while preserving robustness in static scenarios. Ex- tensive experiments on synthetic and real-world benchmarks show that GLIDE improves average performance by up to 45.6% across static and dynamic settings, with the largest gain reaching 85.7%. The source code is available at https://github.com/ChenS676/GLIDE.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：多变量时间序列预测（MTSF）是能源管理、气象预测、金融建模等领域的核心挑战。近年来，图神经网络（GNN）通过将各变量视为图节点、成对时间相关性视为边，为这一任务提供了新的范式。但这类方法通常**隐含假设图拓扑是静态的**，即变量间依赖关系在整个时间跨度上近似不变。
- **核心问题**：在现实场景中（如电网故障、能源危机、宏观经济冲击），变量间的相关性会随外部事件**发生剧烈突变**，原有的静态图假设被打破，导致现有GNN模型性能严重退化。论文系统揭示了这一“表征瓶颈”（representational bottleneck）。
- **关键发现**：
  - 现有模型（Transformer、空间/谱GNN）在高动态拓扑环境下性能显著下降，**最严重时退化达36.6%**（Autoformer）。
  - 甚至**简单的、不考虑图结构的MLP基线**在高动态场景下比复杂的图模型更鲁棒，说明问题出在图架构对静态拓扑的隐式依赖上。
  - 该领域缺乏一个**定量的诊断框架**来度量拓扑的时间变化程度，导致模型失效的边界条件难以刻画。

### 2. 方法论（核心思想、关键技术、公式/算法流程）

论文提出两大贡献：一个诊断指标 TCV 和一个动态感知模型 GLIDE。

#### 2.1 TCV（Temporal Correlation Volatility）—— 量化时间相关性波动

- **定义**：给定时间序列 \(X \in \mathbb{R}^{N \times T}\)，通过滑窗构建每个时间步的相似性图 \(\hat{A}_t\)，TCV定义为相邻时间步图之间的平均变化率，用Frobenius范数度量：
  \[
  TCV = \frac{1}{2(T-1)N} \sum_{t=2}^{T}\lVert \hat{A}_t - \hat{A}_{t-1}\rVert_F
  \]
  其中，\(\hat{A}_t\) 是从滑动窗口数据中通过Pearson相关系数计算得到的 \(|N \times N|\) 相似矩阵。分母中的 \(2N\) 因子确保 \(0 \leq TCV < 1\)。
- **实践意义**：
  - TCV → 0 表示静态图（如 Exchange Rate 数据集，TCV≈0.007）；
  - TCV → 1 表示图结构剧烈波动（如 Germany 和 France 能源数据集，TCV > 0.96）。

#### 2.2 GLIDE（Graph Layer for Inference in Dynamic Environments）

GLIDE 由三个组件构成：

- **C1: 时间卷积层（TC-Layer）**：采用膨胀因果卷积（dilated causal convolution）捕捉节点的时间动态，感受野随层数指数增长。
- **C2: GLIDE 层（核心创新）**，包含两种互相补充的设计机制：
  - **(D1) 基于路径的消息传递（Path-based Message Passing）**：
    - 动机：直接边容易受瞬时噪声干扰，而高阶路径（多跳邻域）在动态环境下更稳定。如能源危机中，煤→碳→可再生能源的间接耦合比直接相关性更可靠。
    - 技术：定义 \(R^{(w)}_{ij} = [\sum_{k=0}^{K} w_k \hat{A}^k]_{ij}\)，即通过多项式展开聚合从1阶到K阶的路径信息，绕过瞬时一阶噪声。
  - **(D2) 静态与动态传播分离（Static and Dynamic Propagation Separation）**：
    - 动机：将拓扑分解为**持久静态结构**（稳定、时不变）与**瞬态动态结构**（时变冲击）。论文通过定理1（Graph-LASSO + 核加权估计）从理论上保证时变拓扑可通过局部静态近似恢复。
    - 技术：使用梯度变体 \(\hat{A}^{(t)}_d = \text{ReLU}\left(\frac{1}{B}\sum_{k}(\nabla \tilde{x}_k)(\nabla \tilde{x}_k)^\top M_d\right)\) 构造动态图（其中 \(\nabla \tilde{x}_k = \tilde{x}_k - \tilde{x}_{k-1}\)），与静态图 \(\hat{A}_s\) 分别传播后再加性融合：
    \[
    H = \sigma\left(\sum_{k=0}^{K} w_k^s A_s^k W_s H + \sum_{k=0}^{K} w_k^d A_d^k W_d H\right)
    \]
- **C3: 预测层（Prediction Layer）**：通过1D卷积将最终的节点表征映射为未来预测值。

完整的模型流程为：输入 → 归一化 → TC-Layers → GLIDE层 → 预测输出，各层均含残差连接和跳跃连接。

- **TCV与性能退化强相关**：高TCV环境下，空间GNN性能下降15.9%-27.2%，Transformer下降32.1%-36.6%，验证了现有模型无法应对动态拓扑的结论。

  - 合成数据：在所有6列（2场景×3时步）中均取得最优MAE/RMSE；

### 7. 方法优点与亮点

- **诊断先行**：TCV是首个专门面向时间序列相关性波动量化的模型无关指标，为后续研究提供了评估拓扑动态性的标准工具。
- **有理论支撑的设计**：
  - 定理1将动态图识别转化为带核权重的Graph-LASSO问题，为D2的静态/动态分离提供了坚实的理论依据；
  - 附录B给出了完整的收敛性证明（偏差界和大偏差不等式），限定性保证了估计器与真实拓扑的一致性；
  - D2设计架构直接内嵌了定理中的核权重机制，做到了“理论指导实践”。
- **多尺度拓扑感知**：D1利用高阶路径的稳定性优势，D2通过梯度差分捕捉瞬态冲击，两者互补性强。
- **无损静态鲁棒性**：GLIDE在动态增强的同时，在近静态基准（Exchange Rate, TCV=0.007）上也保持领先，说明设计不会“矫枉过正”。
- **效率可控**：复杂度分析显示与主流GNN模型相当，且在 Germany 数据上兼顾了性能与效率。

### 8. 不足与局限性

- **理论假设较强**：
  - 定理1假设时间扰动 \(\{Z_t\}_{t=1}^{T}\) 相互独立，但这在能源、金融等具有明显时间依赖的实际领域中往往不成立。作者虽通过Germany/France实验表明D2在存在时间依赖时仍有效，但缺少严格的理论推广。
- **TCV仅覆盖线性关系**：
  - TCV基于Pearson相关，只能捕捉线性依赖的波动；对非线性相互作用（如同步性、相位锁定等）不敏感。作者已在展望中承认这一点，但缺少以非线性度量（如DTW、互信息）为基准的经验对比。
- **实验公平性的透明空间**：
  - 部分基线直接沿用论文报告结果而非在本框架下统一训练，可能导致比较标准不一致；
  - 未与最新动态图时间序列模型（EvolveGCN、AGCRN等）同台竞技，削弱了对“GLIDE是动态场景下最佳方案”这一结论的论证强度。
- **算力与消融细节缺失**：
  - 未披露GPU型号、训练时间与内存消耗的具体数值（仅有复杂度分析和三维图）；
  - 对超参数敏感性（如多项式阶数K、窗口大小B、带宽h）的分析不足。
- **泛化边界**：
  - 验证偏重能源与汇率领域，对金融高频数据、交通流、生物信号等其他动态系统的泛化能力未被证明；
  - 高TCV真实数据集只有Germany和France两个（TCV > 0.96），样本多样性有限。
