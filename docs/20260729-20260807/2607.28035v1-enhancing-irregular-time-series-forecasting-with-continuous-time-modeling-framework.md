## 摘要
不规则多元时间序列广泛出现在医疗监测、人类活动识别和环境感知等应用中。其核心挑战源于异步观测、非均匀采样间隔，以及时间模式本身携带关键动态信息这一事实。现有方法要么依赖于基于离散化的预处理（如插值、填充或聚合），这会破坏底层连续时间语义；要么采用基于ODE框架的连续时间建模，但这通常需要专用架构，并因数值求解器而带来大量计算开销。为解决这些局限性，我们提出了WrapFlow，一个用于不规则时间序列预测的连续时间建模框架。在输入侧，WrapFlow引入了连续时间分词（Continuous-Time Tokenization），它直接编码原始观测事件，并通过间隙感知标记显式建模长期未观测区间。得到的连续时间标记随后由标准Transformer主干处理，以捕捉长期时间依赖。在输出侧，我们开发了一种无模拟训练范式用于残差流匹配（Residual Flow Matching），该范式在基础预测周围学习条件残差向量场，同时避免训练期间的数值求解器模拟和反向传播。这种设计使得仅需在推理时使用少量固定 rollout 步骤即可实现高质量连续预测。在多个真实世界数据集上的大量实验表明，WrapFlow达到了最先进的性能。

## Abstract
Irregular multivariate time series are widely encountered in applications such as healthcare monitoring, human activity recognition, and environmental sensing. Their core challenges stem from asynchronous observations, non-uniform sampling intervals, and the fact that temporal patterns themselves carry critical dynamic information. Existing approaches either rely on discretization-based preprocessing (e.g., interpolation, imputation, or aggregation), which disrupts the underlying continuous-time semantics, or adopt continuous-time modeling via ODE-based frameworks, which typically require specialized architectures and incur substantial computational overhead due to numerical solvers. To address these limitations, we propose WrapFlow, a continuous-time modeling framework for irregular time series forecasting. On the input side, WrapFlow introduces Continuous-Time Tokenization, which directly encodes raw observation events and explicitly models long unobserved intervals via gap-aware tokens. The resulting continuous-time tokens are then processed by a standard Transformer backbone to capture long-range temporal dependencies. On the output side, we develop a simulation-free training paradigm for Residual Flow Matching, which learns conditional residual vector fields around base predictions while avoiding numerical-solver simulation and backpropagation during training. This design enables high-quality continuous forecasting using only a small number of fixed rollout steps at inference. Extensive experiments on multiple real-world datasets demonstrate that WrapFlow achieves state-of-the-art performance.

**研究动机与背景：**
- 不规则多元时间序列（IMTS）广泛存在于医疗监控、人类活动识别、环境感知等领域，其数据具有**异步观测、非均匀采样间隔**的显著特征。
- 在IMTS中，**时间不仅是索引，更是反映系统动态的关键信号**：密集观测可能意味着状态快速变化，而长时间间隔可能意味着系统相对稳定。
- 现有方法存在两类局限：
  - **基于离散化的方法**（插值、填充、聚合）：简单但对齐过程会不可逆地扭曲原始时间语义；
  - **基于ODE的连续时间方法**：理论更合理但依赖专用架构与数值求解器，导致计算开销高、优化复杂。
- 核心挑战是：**如何在保持连续时间语义的前提下，高效且有效地建模不规则时间序列的动态演化？**

## 2. 方法论：WrapFlow框架

**核心思想：**
- 从输入和输出两侧同时建模连续时间动态：输入侧用连续时间分词保留事件语义，输出侧用模拟自由的残差流匹配做连续细化预测。
- 总体框架由**连续时间分词（Continuous-Time Tokenization）+ Transformer主干 + 基于查询的解码器 + 残差流匹配（Residual Flow Matching）**四部分组成。

**关键技术细节：**

**（I）连续时间分词（Continuous-Time Tokenization）：**
- 将原始观测事件编码为三类token：
  - **事件Token（Event Token）**：编码观测值、变量ID、绝对时间戳、相对时间间隔和事件类型嵌入；
  - **GAP感知事件Token（GAP-aware Event Token）**：当同一变量的观测间隔超过阈值$\tau_{gap}$时，在事件Token上叠加GAP类型嵌入，显式建模长时间未观测区间；
  - **掩码GAP Token（Mask GAP Token）**：训练时随机掩码一段连续历史区间，用去除值项、保留变量与时间信息的token替代，用于历史恢复的自我监督。

**（II）Transformer主干与查询解码器：**
- 每个变量生成独立token序列，送入共享的掩码注意力Transformer编码器得到历史记忆；
- 未来查询和掩码历史查询均为无值查询，包含变量ID、绝对/相对时间和查询类型嵌入，通过交叉注意力从历史记忆中检索时间感知上下文。

**（III）残差流匹配（Residual Flow Matching）：**
- 将最终预测分解为**确定性基础预测 + 残差修正**；
- 训练时，对残差目标在随机噪声与真实残差之间线性插值，直接回归目标速度场，**不需要数值求解器模拟与反向传播**；
- 未来分支与掩码历史分支共享同一向量场网络，历史分支提供辅助自我监督；
- 推理时，从零状态出发，仅需少量固定步长的Euler积分即可生成平滑的残差修正轨迹。

**损失函数：**
$$\mathcal{L} = \mathcal{L}_{dir} + \lambda_f \mathcal{L}_f + \lambda_h \mathcal{L}_h$$
其中$\mathcal{L}_{dir}$为基础预测直接损失，$\mathcal{L}_f$为未来残差流损失，$\mathcal{L}_h$为历史残差流损失。
