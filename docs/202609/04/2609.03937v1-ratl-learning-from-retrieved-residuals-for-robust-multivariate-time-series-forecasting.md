## 摘要
检索增强生成（RAG）通过检索外部证据来补充参数化模型。同样的思想对于连续输出回归也具有吸引力，但当样本在输出水平、数值尺度或局部动态上存在差异时，直接复用检索到的目标值往往不够鲁棒。此外，传统预测流程通常使用残差进行模型优化和误差诊断，但不会将个体历史残差示例作为可在推理时访问的記憶保留。针对多元时间序列预测，我们提出RATL，一种即插即用的残差检索与反馈校正方法。RATL冻结基础预测器以构建检索键，并将其历史预测残差转化为特定于该基础模型的仅训练记忆。在推理时，RATL从类似的历史上下文中检索残差轨迹，受因果可用性约束，然后使用一个在预测块和变量上操作的集合感知路由器来选择和组合这些轨迹。实验表明，与当前上下文匹配的历史残差包含可复用的预测信息，且RATL在大多数实验设置中提升了冻结基础预测器的性能。消融实验进一步显示，学习到的路由增强了原始残差反馈，而基于验证的校正强度选择限制了残差的过度注入。在真实世界基准上，我们以iTransformer作为主要冻结基础预测器，与多个强基线预测方法进行比较，并测试了跨主干的可迁移性。结果表明，RATL在大多数设置中能进一步提升基础预测器的性能。总体而言，RATL将检索对象从历史目标值转移到基础模型特定的历史预测误差，为连续输出预测中的学习反馈校正提供了一种即插即用的、基于残差记忆的范式。

## Abstract
Retrieval-augmented generation (RAG) complements parametric models with retrieved external evidence. The same idea is attractive for continuous-output regression, but directly reusing retrieved target values is often not robust when samples differ in output level, numerical scale, or local dynamics. Moreover, conventional forecasting pipelines generally use residuals for model optimization and error diagnosis, but do not retain individual historical residual examples as memory that can be accessed at inference time.For multivariate time-series forecasting, we propose RATL, a plug-in residual-retrieval and feedback-correction method. RATL freezes a base forecaster to construct retrieval keys and turns its historical forecast residuals into a train-only memory specific to that base model. At inference time, RATL retrieves residual trajectories from similar historical contexts subject to causal availability constraints, then uses a set-aware router operating over forecast blocks and variables to select and combine these trajectories. Experiments show that historical residuals matched to the current context contain reusable forecasting information and that RATL improves frozen base forecasters in most experimental settings. Ablations further show that learned routing strengthens raw residual feedback, while validation-based correction-strength selection limits residual over-injection.On real-world benchmarks, we use iTransformer as the primary frozen base forecaster, compare against multiple strong forecasting baselines, and test transferability across backbones. The results show that RATL can further improve base-forecaster performance in most settings.Overall, RATL shifts the retrieved object from historical target values to base-model-specific historical forecast errors, providing a plug-in, residual-memory-based paradigm for learned feedback correction in continuous-output forecasting.

## 1. 核心问题与研究动机

- **问题背景**：多元时间序列的长时程预测需要从局部回看窗口映射到未来轨迹。现代线性、MLP 与 Transformer 预测模型虽然显著提升了精度，但它们只依赖固定长度回看窗口，并将历史模式压缩进模型参数中。
- **局限性**：当某个与当前预测高度相关的历史模式出现在回看窗口之外时，参数化模型无法在推理时显式“翻阅”该历史片段，导致信息利用受限。
- **现有检索增强方案的不足**：检索增强预测虽可通过检索历史相似上下文并复用其未来值来缓解上述问题，但直接复用目标值存在两点风险：
  1. 相似上下文并不一定具有相同的输出水平、尺度或局部动态；
  2. 当基础模型本身预测已较准，外来检索信号的注入可能造成负迁移，这类问题在多元、长时程、预测结果需随变量与时间块变化时尤为明显。
- **论文定位**：不同于“检索历史未来值用于直接预测”，RATL 提出检索**冻结基础模型的历史预测残差**，将模型在过去犯过的错误作为可复用记忆，在输出空间进行残差修正。其核心思想是：检索任务从“找到可替换的预测”转变为“找到可纠正当前模型误差的模板”。

## 2. 方法论

### 2.1 问题设定与整体结构

RATL 是即插即用的后处理校正模块。设回看窗口为 $X_t \in \mathbb{R}^{L \times D}$，未来值为 $Y_t \in \mathbb{R}^{H \times D}$。基础预测器 $f_\theta$ 先被正常训练并冻结，输出基础预测：

$$\hat{Y}^0_t = f_\theta(X_t), \quad R_t = Y_t - \hat{Y}^0_t$$

RATL 只训练一个残差估计器 $\hat{R}_t$，最终预测为：

$$\hat{Y}_t = \hat{Y}^0_t + \gamma \hat{R}_t, \quad 0 \le \gamma \le 1$$

这种设计使同一套残差检索接口可以适配不同的冻结预测器，且每条记忆都具有清晰语义：即基础模型在该历史上下文上的预测误差。

### 2.2 仅训练可用的残差记忆

- 对每个训练窗口存储 $M_i = (k_i, X_i, R_i, a_i)$，其中 $k_i = \phi_\theta(X_i)$ 是冻结基础模型的表示向量。
- $a_i = t_i + H$ 表示第 $i$ 个样本完整目标值可被使用的时间点，用于约束检索的因果可用性。
- 主配置中，检索键 $\phi_\theta$ 采用 iTransformer 编码器输出的逐变量 token 表示；其他基座模型则使用各自预登记的键构造方式。

### 2.3 因果可用性约束与逐变量 Top-K 检索

- 在预测原点 $t$，只有满足以下条件的候选能参与检索：$a_i \le t - H$。该约束在候选目标可获取之后额外加了一个长度为 $H$ 的间隔，防止未来信息的泄漏。
- 检索按变量独立进行。查询键 $k_{t,d}$ 为变量 $d$ 在整个回看窗口上的表示，相似度采用逐变量平均平方欧氏距离。
- 对每个变量取满足可获取性约束的 Top-K 个历史样本，并取这些样本对应的完整残差轨迹作为候选。预测块划分在检索之后进行。

### 2.4 Direct 非参数化基线

Direct 将检索相似度经 softmax 转换为权重：

$$\hat{R}^{\text{dir}}_{t,:,d} = \sum_{i \in \mathcal{N}_{t,d}} \pi_{t,i,d} R_{i,:,d}$$

其中 $\pi_{t,i,d}$ 由检索得分与温度参数得到。Direct 是一个参数自由的基线，固定 $\gamma=1$，用于检验“学习式路由是否优于简单相似度加权”。

### 2.5 分块残差候选与软 Oracle 教师

- 由于一条残差轨迹在整段预测区间内未必同样有效，RATL 将预测时域按长度 $B_h=8$ 切成连续时间块，并按块—变量粒度分配权重。
- 每个检索候选在当前块的一个变量上与“当前真实残差”比较，得到候选误差：
  $$e_{t,i,b,d} = \text{MSE}(R_{i,b,d}, R_{t,b,d})$$
- 候选 $i=0$ 代表零残差，即“不做修正”。
- 对负候选误差做温度 softmax，得到软 Oracle 教师分布 $q^*_{t,i,b,d}$。相比硬标签，软分布能保留多个相似候选的概率质量，降低训练不稳定。该教师仅在训练期间使用，推理时不访问真实未来。

### 2.6 J5 集合感知路由器

- J5 是 RATL 中的学习式路由模块。对每个候选构建一个 token，包含当前查询、候选残差块、Direct 残差参考、块/变量位置信息以及若干标量特征。
- 在所有候选及零残差候选上执行 set attention，使路由器能在候选间交换信息，然后输出块—变量级别的归一化权重：
  $$\hat{R}^{\text{J5}}_{t,b,d} = s \sum_{i=1}^{K} \alpha_{t,i,b,d} R_{i,b,d}$$
- 零残差候选的权重 $\alpha_{0,b,d}$ 可让路由器在局部放弃修正；训练中随机打乱候选顺序以强化集合语义。

### 2.7 训练损失与校正强度选择

- J5 的训练损失为预测损失与 Oracle 模仿损失的加权组合：
  $$L = \text{MSE}(\hat{Y}_t, Y_t) + \lambda_{\text{teach}} \text{CE}(q^*, \alpha)$$
- 预测损失端到端约束最终残差修正有效，Oracle 交叉熵则提供细粒度的“何时、哪个变量、用哪个候选”监督信号。
- 校正强度 $\gamma$ 在验证集上从 $\{0, 0.1, \ldots, 1\}$ 选取最小验证 MSE，取较小者为最终值。$\gamma=0$ 意味着完全回退到冻结基础模型。该机制用于抑制残差过度注入；Direct 基线不做这一调参。

## 5. 主要结果与发现

- **RATL 相对冻结 iTransformer 的稳定提升**：RATL 在绝大多数（52 个中的大部分）“数据集 × 预测长度”单元上取得更低 MSE/MAE。从表 2（正文中以相对提升和平均排名形式展示）来看，RATL 不仅能降低平均误差，还能减小不同随机种子间的性能波动。
- **Direct 的竞争力与 J5 的增益机制**：Direct 作为纯相似度加权残差检索基线，已能明显改善冻结 iTransformer 的预测，说明“检索残差”这一思路在输出空间上是有效的。J5 路由器进一步带来相对稳定的额外收益，印证了“不同变量、不同未来时间块应当选择不同记忆”这一假设。
- **跨基座可迁移性**：在表 4 中，RATL 接口被应用到 DLinear、PatchTST、TimesNet、TimeMixer 等不同架构上。论文报告：对部分基座（如 PatchTST、TimeMixer），RATL 能带来普遍下降；但个别组合的提升幅度较小。论文将差异归因于不同骨干的键空间兼容性和基础预测残差模式不同，而非 RATL 本身失效。
- **消融实验要点**：
  1. 历史可用性约束（$a_i \le t-H$）对防止未来信息泄漏至关重要；放宽该约束会引入明显的数据泄漏并虚高测试性能。
  2. 教师分布的软 Oracle 设计优于硬标签选择；后者训练稳定性差，且易放大错误候选的影响。
  3. 候选排序打乱有助于集合路由器的稳定性，去掉后性能下降有限但训练方差增大。
  4. 校正强度 $\gamma$ 的可调性缓解了残差注入过度的问题；将 $\gamma$ 固定为 1 在部分长程数据集上会略微伤及原本已较高的基础预测精度。
- **案例观察**：论文给出的定性分析显示，RATL 检索出的残差候选往往对应着基础模型系统性偏差（如趋势跟踪滞后、周期性峰谷偏移）相近的历史片段，学习式路由器能够按“是否需要修正”与“用哪段修正”在变量间做出区分。

## 6. 局限性

- **存储与检索开销随规模增长**：记忆库存放的是完整历史窗口、冻结表示与残差轨迹，逐变量 Top-K 检索在训练次数增多、变量维数增大时开销明显增加；论文未提供近似最近邻（ANN）等加速方案。
- **非严格跨架构公平性**：表 4 中不同骨干采用不同的检索键定义与覆盖范围，论文未借此宣称一种统一、公平的跨架构比较。
- **与既有检索增强预测方法的数值对比缺失**：论文未在同一实验框架下与 kNN-MTS、RAFT、PFRP 等做端到端数字比较，只通过消融与相关讨论说明 RATL 的差异。
- **“未修正也很有用”的边界尚需明确**：论文虽然通过 $\gamma=0$ 设置允许回退到基础模型，但没有系统性地分析在何种基础模型、何种数据特征下残差修正会自然地失去价值。

## 7. 总结与展望

RATL 的核心方法论贡献可归纳为三点：将检索目标从“历史未来值”改为“基础模型历史预测残差”；用因果可用窗口严格避免测试期泄漏；用集合感知分块路由器在“何时、何变量、用哪段记忆修正”上做软决策。论文在多个长程多元基准上证明了该方法能持续改善冻结的现代预测模型。未来工作的自然方向包括：压缩记忆表示以降低存储、引入 ANN 索引以加速检索、在不同键空间中学习适配层以增强跨架构迁移，以及在基础模型训练过程中将残差修正整合为联合优化目标。
