## 摘要
混沌时间序列预测因其对初始条件的敏感性和长期不可预测性而成为一项具有挑战性的任务。传统方法通常依赖足够的时间轨迹来学习长期动态，这限制了它们在仅有短期观测时的适用性。虽然近期的大型语言模型（LLMs）在时间序列预测方面显示出巨大潜力，但它们的时间表示并未显式针对混沌系统的相空间结构和非线性演化进行定制。为解决这些问题，我们提出了PAC-LLM，一种由LLM驱动的面向长期混沌时间序列预测的相空间感知自适应融合框架。PAC-LLM利用学习到的相空间特征和文本信息，充分激发LLM的时间序列预测能力。特别地，我们设计了一个辅助特征模块和一个门控加权机制，用于多变量耦合信息的融合与选择。在代表性混沌系统上的大量实验表明，我们的方法在短期和长期预测中均优于现有的微调和零样本基线。我们的消融研究进一步证实了PAC-LLM中每个关键组件的有效性。

## Abstract
Chaotic time series forecasting is a challenging task due to its sensitivity to initial conditions and long-term unpredictability. Traditional methods typically rely on sufficient temporal trajectories to learn long-term dynamics, which limits their applicability when only short-term observations are available. While recent Large Language Models (LLMs) have shown great potential for time series forecasting, their temporal representations are not explicitly tailored to the phase-space structure and nonlinear evolution of chaotic systems. To address these issues, we propose PAC-LLM, a phase-space-aware adaptive fusion framework for long-term chaotic time series forecasting powered by LLMs. PAC-LLM leverages learned phase-space features and textual information to fully enable LLM's time series forecasting capacity. In particular, we design an auxiliary feature module and a gated weighting mechanism for multivariate coupling information fusion and selection. Extensive experiments on representative chaotic systems demonstrate that our method outperforms existing fine-tuned and zero-shot baselines in both short-term and long-term predictions. Our ablation study further confirms the effectiveness of each key component in PAC-LLM.

## 2. 论文提出的方法论

PAC-LLM 是一个**相空间感知的自适应融合框架**，将 LLM 的通用时序能力与显式混沌动力学建模相结合，共四个核心组件：

**① 相空间感知表示学习（Phase-Space-Aware Representation Learning）**

- **可学习延迟嵌入**：受 Takens 嵌入定理启发，对每个变量单独施加时间延迟嵌入重构相空间状态。延迟参数 $\{\tau_i\}$ 是连续可学习的，用可微插值核计算延迟值（避免固定延迟选取）：
  $$z_t^{(v)} = [\tilde{x}^{(v)}(t-\tau_0),\ \ldots,\ \tilde{x}^{(v)}(t-\tau_{m-1})] \in \mathbb{R}^m$$
- **混沌统计调制（FiLM）**：从观测中提取系统级的动力学统计量（复杂度、峰度、谱熵等）$c$，通过 MLP 映射为 FiLM 参数 $[\gamma,\beta]$，对相空间隐表示进行逐通道调制，使表征对齐当前动力学状态。
- **Patch Tokenization**：将调制后的序列划分为重叠 patch，展平后投影为 latent token，供后续 LLM 处理。

**② LLM 时序建模主分支（LLM-Powered Temporal Modeling）**

- 先构造动力学感知的文本 prompt（含趋势、能量、形态等描述），嵌入 LLM 语义空间。
- 由于时序 token 与文本 token 空间异构，使用**轻量级 reprogramming 模块**（以 patch token 为 query、LLM 词表嵌入为 key/value 的交叉注意力）将时序 token 对齐到 LLM 输入空间。
- Prompt 与重编程 token 拼接后送入**冻结的预训练 LLM**（默认 GPT-2 前两层），提取时序位置对应的隐状态作为主分支特征 $F_{\text{main}}$。

**③ 辅助通道交互建模（Auxiliary Channel Interaction Modeling）**

- 在 patch token 序列上显式保留变量维度，对每个时间 patch 沿通道（变量）方向做多头自注意力，以建模多变量耦合依赖；经残差归一化、门控与辅助编码器处理后输出辅助特征 $F_{\text{aux}}$。

**④ 加权融合预测（Weighted Fusion Forecasting）**

- **相似度门控**：计算 $F_{\text{main}}$ 与 $F_{\text{aux}}$ 的余弦相似度，结合拼接特征（含绝对差）经门控网络生成逐特征可靠性权重，得修正后辅助特征 $F'_{\text{aux}}$。
- **自适应融合门**：再次以 $F_{\text{main}}$、$F'_{\text{aux}}$ 及差值构造门控输入，得到权重 $\alpha$，融合公式：
  $$F_{\text{fusion}} = F_{\text{main}} + \alpha \odot \Delta F$$
  其中 $\Delta F$ 是辅助校正头输出。以此抑制不可靠的辅助修正、保留有效耦合信息。
- 最终用残差预测头输出未来轨迹；总损失为融合预测损失与辅助预测损失的加权组合：
  $$\mathcal{L} = \lambda_f \mathcal{L}_{\text{fusion}} + (1-\lambda_f)\mathcal{L}_{\text{aux}}$$

整体上，PAC-LLM 同时利用 LLM 的长期上下文建模、Takens 嵌入的局部状态恢复、统计量校准与变量耦合辅助信号，并通过门控机制控制多源信息的融合强度。

## 6. 主要结论与发现

- **整体有效性**：PAC-LLM 在全部对比中取得 23 项最佳、1 项第二，综合表现显著优于 9 种代表性基线。
- **长时程优势更明显**：在 $H=120$ 与 $H=300$ 步时性能差距进一步拉大，说明门控融合与相空间特征有助于缓解误差累积、延长有效预测时间。
- **动力学结构保持**：在 $D_{\text{frac}}$ 与 $D_{\text{stsp}}$ 等吸引子指标上明显优于基线，不只降低逐点误差，还能较好重构混沌吸引子的几何/分布结构。
- **消融关键发现**：辅助分支贡献最大（移除后 MSE/MAE 平均增加 57.9%/62.2%）；Takens 嵌入、混沌统计 FiLM、加权融合、辅助监督与 prompt 均各有增益。
- **LLM 贡献验证**：替换为随机初始化 Transformer 后性能下降，预训练 LLM 表征提供了不可归因于架构本身的增益；增大骨干规模（Qwen/Llama-3B）并不必然提升性能，针对任务做微调更有效——**提示任务自适应比单纯缩放模型更关键**。
- **短观测优势**：PAC-LLM 在短输入（~30–40 步）下最优，误差随上下文变长反而增加；Panda 等 foundation model 必须依赖更长历史才能接近，体现 PAC-LLM 在有限观测场景中的独特价值。

## 7. 优点

- **任务定义新颖且贴近实际**：明确“短期观测 + 长期预测（≥多个 Lyapunov 时间）”设置，并验证结果不依赖单一输入长度。
- **方法设计有理论依据**：将 Takens 延迟嵌入定理引入深度学习管线，并用可学习延迟与可微插值避免了传统手工选择延迟参数的缺陷；FiLM 统计调制使表征对系统动力学状态敏感。
- **架构互补性好**：LLM 主分支管时序演化、辅助分支显式建模变量耦合，门控融合避免冗余/噪声特征干扰——消融证实了两分支缺一不可。
- **评估体系全面**：除 MSE/MAE/sMAPE 外，引入 VPT、$D_{\text{frac}}$、$D_{\text{stsp}}$ 等动力学结构指标，更契合混沌预测“长期统计保持”的核心目标。
- **严谨的对照组设计**：PAC-Transformer 与 PAC-Numeric-Transformer 的设计有效分离了“LLM 预训练知识”与“Transformer 架构/重编程接口”各自的贡献。
- 真实双摆实验验证了噪声环境下的鲁棒性和实际应用潜力。

## 8. 不足与局限

- **真实数据覆盖有限**：仅使用 IBM 双摆一个真实系统（且规模较小），缺乏气象、金融、神经科学等更广泛真实场景的验证，外部有效性有限。
- **动态范围局限**：合成系统虽涵盖 3D–8D，但未覆盖高维时空混沌（如大规模耦合格点系统），无法判断方法在高维场景的扩展性。
- **计算资源信息不透明**：未报告 GPU 数量、总算力消耗与训练时长；3B 级 LLM 骨干的实验资源代价不清楚，可复现门槛较高。
- **统计检验缺失**：未报告多随机种子的均值/方差或显著性检验，单次结果可能存在偶然性。
- **噪声鲁棒性测试较粗**：只做了高斯噪声单调递增实验，未对比其他基线在相同噪声下的表现，难以定位方法在噪声场景中的相对优势。
- **超参数敏感性未充分讨论**：嵌入维度 $m$、patch 大小 $P$、融合系数 $\lambda_f$ 等关键超参数主要靠经验设定，未给系统的敏感性分析。
- **预测上限局限**：即使 VPT 领先，在 $H=300$（10 Lyapunov 时间）仍无法避免发散；对混沌系统本质的不可预测边界缺乏更深入讨论。
