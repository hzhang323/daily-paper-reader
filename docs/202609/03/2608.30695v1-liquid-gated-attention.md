## 摘要
真实世界的时间序列往往表现出不规则采样和较长的时间跨度，要求模型能够捕捉任意间隔内的连续时间动态，而不会产生过高的扩展成本。离散时间方法将可变的时间间隔压缩为静态的位置步骤；依赖求解器的连续时间模型保留了时间结构，但依赖于顺序积分，从而阻碍了并行化；而无需求解器的近似方法避免了这一成本，但它们都没有将观测到的时间间隔与输入驱动的状态调制相结合。我们提出了液体门控注意力（LGA），一种无需求解器的并行时间算子。通过用观测到的时间间隔参数化输入驱动的门控机制，LGA引入了连续时间的归纳偏置，并将隐藏状态演化表述为快速权重联想记忆，从而能够在时间维度上进行并行计算。在非因果编码中利用矩阵结合性，在因果编码中利用前缀扫描，LGA在两种模式下都实现了序列长度的线性时间复杂度。序列级别的归一化限制了累积时间衰减，以保证长时间跨度的稳定优化。基于LGA，我们实例化了LFormer，一个用于连续时间表示学习的模块化骨干网络。在跨越六个任务和十六个数据集（最长可达17,984步）的实验中，LFormer展示了长程依赖建模、细粒度状态跟踪以及从稀疏和噪声观测中进行轨迹重建的能力，同时在与最先进的离散时间和连续时间基线相比时，以线性扩展效率实现了具有竞争力的性能。

## Abstract
Real-world time series often exhibit irregular sampling and extended temporal horizons, requiring models to capture continuous-time dynamics across arbitrary intervals without prohibitive scaling costs. Discrete-time methods collapse variable time intervals into static positional steps; solver-dependent continuous-time models preserve temporal structure but rely on sequential integration, precluding parallelization; and solver-free approximations avoid this cost yet none couples observed time intervals with input-driven state modulation. We propose Liquid Gated Attention (LGA), a solver-free parallel temporal operator. By parameterizing an input-driven gating mechanism with observed time intervals, LGA introduces a continuous-time inductive bias and formulates hidden state evolution as a fast-weight associative memory, enabling parallel computation across the temporal dimension. Using matrix associativity in non-causal encoding and a prefix scan in causal encoding, LGA attains linear temporal complexity in sequence length in both modes. A sequence-level normalization bounds cumulative temporal decay for stable long-horizon optimization. Building on LGA, we instantiate LFormer, a modular backbone for continuous-time representation learning. Across six tasks and sixteen datasets spanning up to 17,984 steps, LFormer demonstrates long-range dependency modeling, fine-grained state tracking, and trajectory reconstruction from sparse and noisy observations, while delivering competitive performance against state-of-the-art discrete-time and continuous-time baselines with linear scaling efficiency.

## 1. 核心问题与整体含义（研究动机与背景）

### 问题定义
- 现实世界的时间序列（如生理信号、金融波动、气候监测等）往往伴随不规则采样和长时程跨度，这对时间建模提出三重挑战：
  1. 需要在任意观测间隔上表征连续时间动态；
  2. 需要在长序列上捕捉远距离依赖而控制计算成本；
  3. 需要从稀疏、噪声观测中还原底层连续过程形态。

### 现有三类范式的鸿沟
- 离散时间模型（RNNs、Transformers 等）：
  - 将连续轨迹映射到均匀时间步，通过修补、插补或时间编码等手段丢弃或回避观测之间真实的时间距离，无法建模真正的连续时间动态，不利于区分真实状态变化和噪声。
- 依赖求解器的连续时间模型（NODE、Latent-ODE、NCDE 等）：
  - 保留时间结构，但依赖迭代数值积分，无法沿时间维度并行化，求解耗时大且积分超长时会累积截断误差。
- 免求解器的连续时间模型（CfC、状态空间模型 SSM、路径签名方法等）：
  - 以固定闭式或线性离散形式解析计算连续演化，但缺少让观测时间间隔直接调制输入状态的门控机制，对噪声鲁棒性有限。
- **核心结论**：现有模型无法同时满足三个条件：① 编码观测时间间隔本身；② 支持时间维度并行；③ 对噪声观测具备鲁棒性。LGA 即面向这一“三难困境”提出的解。

## 2. 方法论：LGA（Liquid Gated Attention）的设计思路

### 总体思路
- LGA 是一个免求解器的并行时序算子，把液体时间常数（LTC）微分方程的闭式门控结构、快速权重联想记忆、前缀扫描和序列级归一化整合为一个统一可并行的公式，同时保留连续时间的归纳偏置。

### 关键公式与设计四步

#### （1）连续时间门控（Continuous-time Gating）
- 从一维 1D LTC 方程出发，省略自连接并经对称性假设后用线性 ODE 求闭式解：相邻时刻的状态转移化为
  `s(tₙ) = g(tₙ)·s(tₙ₋₁) + (1−g(tₙ))·bₜ`，
  其中液体门控 `g(tₙ) = exp[−wₜ·δₙ − ∫f(x(u))du]`，由观测时间间隔的大小和输入信号共同决定，构成连续时间的状态衰减调节机制；当输入与状态耦合时，该门控还能衰减噪声高频扰动。

#### （2）计算高效性：学习式端点插值（Learnable Interpolation）
- 为避免直接对输入积分求值（需数值求解器），使用仿射非线性把相邻 token 投影为标量信号后用端点加权插值近似积分：
  `∫x̃(u)du ≈ δₙ[μx̃ₙ₋₁ + (1−μ)x̃ₙ]`，其中 `μ = σ(θ)`，当 μ = 0.5 时恢复经典梯形公式并具有二阶局部精度；学习式 μ 则作为可训练的数值替代规则，从而并行化门控计算。简化后的门向量为 `gₙ = exp(−δₙ·xₙ)`，时间衰减和输入调制耦合在一个标量中。

#### （3）表达能力：矩阵态联想记忆与快速权重编程
- 将 1D LTC 的门控式更新从标量提升为 d×d 矩阵的联想记忆：
  `Sₙ = gₙ Sₙ₋₁ + (1−gₙ) kₙᵀ vₙ`，
  即门控是线性注意力的对角尺度矩阵；key、value、query、output-gate 由输入线性投影后按门值调制。输出读取为 `yₙ = oₙ ⊙ (qₙSₙ)`。
- 将左乘/右乘时间调制因子换算到 Q、K、V 上，即可打开并行形式：
  - 非因果模式：用矩阵结合律，把 Q(KᵀV) 全局乘积实现 O(nd²) 线性复杂度；
  - 因果模式：用前缀扫描（CumSum）沿时间维度计算 `Q ⊛ CumSum(K ⊗ V)`，同样线性复杂度。

#### （4）数值稳定性：序列级归一化（Sequence-level Normalization）
- 对累计衰减 log 值做 `û = u/(Σuᵢ+ε)` 的序列级归一化，使指数衰减系数和指数累积门控均落在(0,1] 的区间，有效避免长序列累积导致的下溢或溢出。
- 数学上把梯度衰减从指数级降为多项式级（相对于总非负衰减和 S 为 O(S⁻²)），在公式上给出梯度下界证明，支持超长时程的稳定训练。

### LFormer 骨干网络
- LFormer = Embedder（任务特定嵌入器）+ L 个 Liquid Mixer（MHLGA + SwiGLU 残差层，前置 LayerNorm）+ Predictor（任务特定预测头）
- MHLGA 将 d 维分成 H 个子空间，每个头独立执行各自的时间间隔插值和门控，再拼接线性投影联合输出，实现解耦多头的多尺度时间捕捉。

## 6. 主要结论与发现
1. **LFormer 在 LTS-C 上大幅领先**：UAE 六分类平均准确率 71.3% vs. 最强基线 RFormer 64.5%，相对提升 +10.5%；平均排名 1st（1.33），并在四/六个数据集中第一，无任何基线能在更多数据集中进入前二。
2. **LTS-R 任务全面占优**：HR/RR/SpO₂ 的 MAE 相对最强基线分别下降 47.7% / 20.4% / 71.6%，在多步外推的临床场景体现出对长期模式的精细追踪能力。
3. **PTS 任务上对细粒度状态跟踪出色**：HA 数据集准确率 92.9%，比 ACSSM 高 1.6%；PDL 数据集 MSE 1.9‰，相对 ACSSM 降 31%；在 PDL 上固定 µ 为梯形规则反而优于学习 µ，表明稀疏条件对对称平滑先验的需求强于局部自适应。
4. **稀疏/噪声轨迹重建**：TS-I 在 PHY 和 USH 上 MSE 相对最强基线分别降 65.3% 和 83.3%；2DS-α 在 α=0.02（噪声主导）环境下插值和外推下降幅度可达 37.7%–50.0%，对比 ContiFormer 大幅领先，显示液体门控的凹性衰减能有效抑制高频噪声。
5. **限制边界明确**：PHY 外推任务落后于 mTAND、USH 的 TS-E 边际提升和部分 2DS-α 精度波动共同验证了 LGA 状态转移更擅长平滑动力学，但无法与非平稳强不规则的边界局部波动竞争，提出了对更强的多尺度、非稳态解码网络的需求。
6. **效率验证**：显存和单步延迟随序列长度线性增长，Transformer 在 2¹³ 长度 OOM，R-ODE 在更长序列上严重退化；LFormer 的吞吐比 Mamba 低约 2 倍但比标准 Transformer 高约 47 倍，在 Pareto 前景中同时保持高精度和高吞吐。

1. **结构层面的限制**：归一化方式本质上是序列级全局归一化，离线全序列可用，但对在线流式或自回归推理不友好；作者在限制段落中也承认需发展 prefix-normalized 变体。

3. **非平稳外推是明确短板**：在 PHY 的极端非平稳外推上输给 mTAND；其恢复系数对边界漂移缺乏敏感度，系统级限制目前只能由人工报告弥补，没有提出一体化的多尺度查询解码方案来收敛差距。
4. **计算公平性存疑**：与 Mamba 对照时未用自研硬件层扫描算子，而是原生 PyTorch 实现，所得吞吐差距可视作“实际工程差距”但同时也就低估了算法本身的加速理论上限。
5. **部署与推广的验证局限**：没有提及训练配置的 GPU 数量、能源开销或 batch 维度的扩展行为（只考察 batch=8/16 的序列长度曲线）；在真实生产规模的超大序列（十亿级 token）上的稳定性、推理时显存峰值未给出。
