## 摘要
时间序列多模态大语言模型（TS-MLLMs）近来开始利用大语言模型（LLMs）的推理能力来完成问答任务。然而，这些模型往往无法捕捉动态时间模式，只能提供隐式推理，缺乏对医疗等高风险应用至关重要的底层解释。尽管基于强化学习（RL）的时间序列语言模型试图解决这一问题，但它们通常表现不佳，因为它们是在狭窄的分布内数据上训练的，并且难以处理分布外的组合问题。为应对这些挑战，我们提出了 TimeThink，一个用于激发组合式时间序列推理的合成框架。核心时间序列基元（例如趋势、季节性）与领域无关，并且可以被确定性生成。基于这一前提，TimeThink 首先设计了一个合成数据生成器，用于生成原子和复合问答对，提供带有推理轨迹的客观真值。在此框架基础上，TimeThink 采用可验证奖励的强化学习（RLVR）训练策略，以鼓励显式推理。与依赖模板的方法不同，该方法使模型能够学习组合的底层逻辑，而不仅仅是模仿推理轨迹。大量实验表明，仅在合成数据上训练的 TimeThink 在合成和真实世界基准上均显著优于强基线。

## Abstract
Timeseries multimodal large language models (TS-MLLMs) have recently begun leveraging the reasoning capabilities of large language models (LLMs) for question-answering tasks. However, these models often fail to capture dynamic temporal patterns, providing only implicit reasoning that lacks the underlying explanations critical for high-stakes applications like healthcare. While reinforcement learning (RL)-based timeseries language models aim to address this, they often fall short because they are trained on narrow, in-distribution data and struggle with out-of-distribution compositional questions. To address these challenges, we present TimeThink, a synthetic framework for eliciting compositional timeseries reasoning. Core timeseries primitives (e.g., trend, seasonality) are domain-independent and can be deterministically generated. Guided by this premise, TimeThink first designs a synthetic data generator that produces atomic and composite question-answer pairs, providing objective ground truth with reasoning traces. Building on this framework, TimeThink employs a reinforcement learning with verifiable rewards (RLVR) training strategy that encourages explicit reasoning. Unlike template-reliant methods, this approach enables the model to learn the underlying logic of composition rather than simply imitating traces. Extensive experiments show that TimeThink, trained only on synthetic data, significantly outperforms strong baselines on both synthetic and real-world benchmarks.

## 1. 核心问题与研究动机

- **背景**：时间序列多模态大语言模型（TS-MLLMs）已开始借助 LLM 的推理能力做时间序列问答，现有工作主要在"数值信号如何编码进语言空间"上分化：转成文本字符串、转成可视化图像交给 VLM、或直接把数值 patch 投影进 LLM 嵌入空间。
- **共性问题**：这些模型几乎只以**最终答案**为监督信号，趋势、季节性、异常等时间模式被隐式吸收，**推理过程不可见、不可审计**。
- **为何重要**：下游动作往往取决于"哪个模式触发了预测"，而非预测本身。例如旋转机械故障告警究竟来自持续电机负载、轴承温度上升还是瞬时振动尖峰，直接决定维修路由到哪个部件；医疗场景同样要求可辩护的诊断依据。
- **已有 RL 路线的不足**：
  - TimeOmni-1、STReasoner 等虽引入可验证奖励，但能力主要来自**推理模板上的 SFT**，RL 只是"精修"格式与小幅提点；
  - 模板按任务定制，模型被绑定在训练分布内的窄带时间模式（单一预测目标、固定传感器域、封闭问题类型）；
  - 真实问题往往需要**组合多个时间现象**（如在季节趋势中定位异常、在非平稳状态下关联两变量），跨模式新组合时模型容易"掉线"，退回模板启发式。
- **本文主张**：核心时间序列基元（趋势、季节性等）是**领域无关且可确定性生成**的，因此可用合成数据 + 可验证奖励强化学习（RLVR）显式激发**组合式时间序列推理**。

## 2. 方法论

### 2.1 整体框架
TimeThink = 合成数据生成器 + 两阶段训练（SFT → RLVR）。任务定义为多元时间序列 x ∈ R^{T×d} 上的问答，模型自回归生成"推理轨迹 + 最终答案"，采用结构化输出格式 `<think>...answer: {value}</think>` + ⟨post-think 回答⟩，便于独立验证格式与答案。

### 2.2 合成数据生成（原子 / 复合 / OOD）

- **原子算子 F_atom（9 个）**：MEAN、STD、PERCENTILE、EXTVAL、EXTPOS、EVENTENUM、SEGENUM、PERIOD、TRENDCLASSIFY。原子 QA 即单算子作用于 x，输出"原子事实"（如"最大值出现在哪一步"）。共实例化 14 种单变量问题变体。
- **子技能算子 F_op（9 个）**：COUNT、SUM、FILTER、LOCATE、COMPARE、THRESHOLD、ARGMAX、RANK、ARITH。子技能不直接读原始序列，而是组合原子事实或上层子技能结果。
- **复合 QA**：读取 m ≥ 1 个原子事实，再用 K ≥ 1 个子技能组合成最终答案，即 a = (g_K ∘ … ∘ g_1)(f_1(x), …, f_m(x))。例："x 的前半段均值是否高于后半段？" = MEAN(I₁), MEAN(I₂) → COMPARE。所有复合问题都有已知的"程序"，因此推理链与真值都可验证。
- **三类数据划分（按监督程度）**：
  - **Comp-D（CoT 示范）**：SFT 中给出思维链分解，同一复合题也进入 RL 池（36 类组合）；
  - **Comp-R（仅奖励）**：只出现在 RL 池，模型必须仅凭结果奖励自行求解（32 类组合）；
  - **OOD（留出）**：两阶段均不出现，只在测试时评估，衡量组合能力迁移（34 类组合）。
- **原子与复合混合**：因复合答案可能有多条等价分解路径，只用单条 CoT 会过拟合风格模板；但 RL 中省略原子 QA 又会导致基元技能退化与死记硬背，故 SFT 与 RL 两阶段都混合原子与复合 QA。
- **LLM 驱动的 QA 演化（图 1C）**：对一小部分训练数据，以原始问题 + 推理块 + 答案为条件，让 LLM 生成更复杂、措辞更多样的问答对，但**保留原有推理结构与已验证真值**（遵循 WizardLM 的演化策略自动选择），并额外做问题改写增强。与 ChatTS 不同之处在于保留了问题与答案之间的显式推理接地，避免走捷径。

### 2.3 训练流程

- **骨干与编码**：沿用 ChatTS 的时间序列编码器融合 LLM 与保值的归一化方式。
- **Stage 1：SFT**。在 (x, q, y*) 三元组上最大化参考输出（工作推理链 + 最终答案）的对数似然：
  L_SFT(θ) = −E[ Σ_n log π_θ(y*_n | x, q, y*_{<n}) ]。
- **Stage 2：RLVR（GRPO）**。对每个 (x, q) 采样 G 条响应，奖励分解为：
  **r(x, q, y) = r_fmt(y) + r_ans(x, q, y)**，两者均 ∈ [0,1]，故 r ∈ [0,2]。
  - r_fmt：结构合规性，必须恰好一个 `<think>...</think>` 块，末行符合 `answer: {value}` 模板；
  - r_ans：按答案类型做问题感知验证，分四类：**Binary**（布尔精确匹配）、**Categorical**（有限语义标签精确匹配）、**Proximity**（数值按与真值距离给分级奖励）、**Set-F1**（枚举/分组任务按预测集与金标集的 F1 给部分分）。
  - 采用 GRPO：组内奖励归一化得相对优势，PPO 式裁剪代理目标 + 对冻结参考策略 π_ref（即 SFT 模型）的 KL 惩罚；π_θold 为每轮 PPO 更新内固定的 rollout 策略。实现基于 verl 库。
- **关键设计意图**：奖励只校验答案，模型可自由探索 SFT 未曾模仿的推理链，从而学习"组合的底层逻辑"而非复制模板。

## 6. 主要结论与发现

- **组合能力显著提升**：Comp-D 上 SFT 已达 0.696，RL 再 +3.5 pp 至 0.731；**Comp-R 上 SFT 仅 0.532，RL 提升到 0.733（+20.1 pp）**，说明在缺乏 CoT 示范的复合族上，仅凭结果奖励即可获得大幅提升。
- **增益来源可归因**：RL 对原子基元的提升（Δa）在各组合间基本恒定，故 Δc 的差异不来自原子波动；Comp-R 的 Δc = +0.18 > Δa = +0.10，说明 RL 真正学到了**组合原子的子技能**；OOD 上 +0.09 表明该子技能可迁移到未见组合形态。
- **OOD 与真实世界**：OOD 上 RL 比 SFT 提升近 10 pp（0.533 → 0.629），并领先所有时序原生基线；TSEvol 上 TimeThink (RL) 加权平均 0.709（SFT 0.632），在因果与归纳子任务上最优。
- **长度与变量数泛化**：在未见长度 [769,1536] 上全面领先（整体 +0.085，组合类增益更大）；随提示中时间序列变量数增加，RL 相对 SFT 的优势从 1 变量的约 8 pp 增至 ≥5 变量的约 10 pp，说明 RL 对**多变量证据整合**尤为有效。
- **数据效率**：从 ChatTS 起加 110K SFT 样本仅提升 SenTSR-Bench 均值 2.8 pp 且 MCQ2 退化 8.0 pp；而从 TimeThink (SFT) 起加 **10K RL 样本**即提升 SenTSR-Bench 8.1 pp、MCQ2 5.7 pp，即 RL 配方以约
