## 摘要
时间序列基础模型（TSFMs）近来在多种预测任务中展现出令人印象深刻的零样本性能。然而，现实世界的决策常常依赖于不规则多变量时间序列（IMTS），其中观测间隔不一致、变量间异步采样与信息性缺失并存。现有 TSFMs 处理此类输入的方式，要么是通过插补引入伪值，要么是通过基于索引的位置编码忽略连续时间。对于遵循原始 IMTS 模式的基础模型，仍存在空白。本文提出一种混合注意力模型，学习用于 IMTS 预测的统一时间感知补丁表示。我们首先设计了一种时间感知补丁编码，将补丁内数量可变的时间戳映射为固定大小的嵌入，从而在不进行插补的情况下为不规则补丁生成统一格式。随后，我们引入了一种时间偏置注意力机制，将补丁间的时间错位和跨通道异步依赖校准为辅助注意力偏移。最后，在仅解码器 Transformer 主干之上，我们采用了一种混合因果掩码，它在历史上下文上保留双向全视图，同时使预测范围严格保持自回归。为支持不规则设置下的大规模预训练，我们还构建了 VersaTSA，一个包含 300 亿条观测的数据档案，保留了其来源的原生采样稀疏性。在三个 IMTS 基准和一个标准规则 MTS 基准上的实验表明，我们的模型在 IMTS 上取得了最先进的零样本性能，并在迁移到规则预测时仍具有竞争力。

## Abstract
Time series foundation models (TSFMs) have recently delivered impressive zero-shot performance across diverse forecasting tasks. However, real-world decision-making frequently relies on \emph{irregular multivariate time series} (IMTS), where inconsistent inter-observation intervals and asynchronous sampling across variables coexist with informative missingness. Existing TSFMs handle such inputs either through imputation that injects spurious values or through index-based positional encodings that ignore continuous time. There is still a gap in the foundation model that follows the original IMTS patterns. In this paper, we propose a hybrid attention model that learns a unified time-aware patch representation for IMTS forecasting. We first design a \emph{time-aware patch encoding} that maps a variable number of intra-patch timestamps into a fixed-size embedding, producing a uniform format for irregular patches without resorting to imputation. We then introduce a \emph{time bias attention} mechanism that calibrates inter-patch temporal misalignment and asynchronous cross-channel dependencies as auxiliary attention offset. Finally, on top of a decoder-only Transformer backbone, we adopt a \emph{hybrid causal mask} that preserves a bidirectional full view over the historical context while keeping the forecast horizon strictly autoregressive. To support large-scale pretraining under irregular settings, we also curate VersaTSA, an archive of $30$B observations that retains the native sampling sparsity of its sources. Experiments on three IMTS benchmarks and a standard regular-MTS benchmark show that our model achieves state-of-the-art zero-shot performance on IMTS and remains competitive when transferred to regular forecasting.

  - 不同变量异步采样；
  - 存在信息性缺失。
- **现有方法的问题**：
  - 基于插补的方法会注入伪值，破坏原始缺失模式；
  - 基于索引的位置编码（如 Sinusoidal、RoPE、T5 Bias）只编码序列顺序，无法表达连续时间、非均匀间隔和变量间异步性；
  - 逐点建模方法虽能处理不规则性，但信息密度低、计算复杂度高，难以随模型规模扩展。
- **核心空白**：缺少一种遵循 IMTS 原始采样模式、无需插补、可大规模预训练的时间序列基础模型。
- **整体含义**：论文提出 UniTIMS，用统一的时间感知 patch 表示和混合注意力机制，把 decoder-only TSFM 扩展到不规则多变量时间序列预测，并构建 300 亿观测的 VersaTSA 预训练语料。

## 2. 方法论

### 2.1 核心思想

- 将不规则多变量时间序列表示为三元组集合：观测值 \(u_k\)、时间戳 \(t_k\)、通道标识 \(c_k\)。
- 把序列切分为非重叠 patch，每个 patch 内可能包含不同数量的有效观测。
- 不进行插补，而是分别对“值”和“时间”建模：
  - 值：按标准 TSFM 方式投影为 patch 值嵌入；
  - 时间：设计时间感知 patch 编码，将可变数量的 patch 内时间戳聚合为固定维度嵌入。
- 在 Transformer 注意力中引入时间偏置和变量间偏置，替代传统位置编码。
- 使用混合因果掩码：历史前缀允许双向注意力，预测目标保持严格自回归。

### 2.2 关键技术细节

#### （1）时间感知 Patch 编码

- **连续时间映射**：借鉴 Time2Vec，将连续时间戳 \(t\) 映射为高维向量 \(\Phi(t)\)：
  - 第 0 维为线性项 \(w[i]\cdot t + a[i]\)，捕捉全局时间趋势；
  - 奇数维为正弦项 \(a[i]\cdot \sin(w[i]\cdot t)\)；
  - 偶数维为余弦项 \(a[i]\cdot \cos(w[i]\cdot t)\)；
  - \(w\)、\(a\) 为可学习频率和振幅参数。
- **Patch 内聚合**：
  - 对第 \(m\) 个 patch 内实际观测到的 \(n_m\) 个时间戳分别编码；
  - 使用可学习查询向量 \(q\) 做掩码注意力池化，得到固定维度 patch 时间嵌入 \(p_m\)；
  - 未观测位置通过 mask 排除，不参与 softmax、不贡献梯度；
  - 因此不同采样密度的 patch 可映射到同一表示空间，且不引入伪值。

#### （2）时间偏置注意力

- 标准注意力分数为 query 和 key 的缩放点积：
  - \(A_{i,j}^{(l)} = (W_Q x_i)^\top (W_K x_j) / \sqrt{d}\)。
- 为校准 patch 间时间错位和异步跨通道依赖，引入：
  - 时间相似性矩阵 \(G_{i,j} = p_i^\top W_E p_j\)，其中 \(W_E\) 可学习；
  - 同通道偏置 \(v_1^{(l)} I\{c_i = c_j\}\)；
  - 跨通道偏置 \(v_2^{(l)} I\{c_i \neq c_j\}\)。
- 更新后的注意力分数：
  - \(\hat{A}_{i,j}^{(l)} = A_{i,j}^{(l)} + \lambda^{(l)} G_{i,j} + v_1^{(l)} I\{c_i=c_j\} + v_2^{(l)} I\{c_i \neq c_j\}\)。
  - \(\lambda^{(l)}\) 为每层可学习缩放因子，动态调整时间偏置影响。
- 模型移除了传统位置编码，依赖时间偏置注意力感知 patch 间时间关系。

#### （3）混合因果掩码

- 给定前缀长度 \(k\)，掩码定义为：
  - 若 \(j \leq \max(i, k)\)，则 mask 为 0；
  - 否则为 \(-\infty\)。
- 含义：
  - 前缀段 \(i \leq k\)：双向全注意力，充分捕捉历史全局依赖；
  - 目标段 \(i > k\)：单向因果注意力，保证自回归生成。
- 最终注意力：
  - \(E_{i,j}^{(l)} = \text{softmax}(\hat{A}_{i,j}^{(l)} + M_{i,j})\)。
- 论文从条件概率分解角度论证该结构仍满足自回归形式：
  - \(P(T|P) = \prod_{i \in T} P(p_i | P, p_{T,<i})\)。

#### （4）训练策略与 VersaTSA

- **VersaTSA 数据档案**：
  - 包含海上风电扭矩与波高异步采样数据、LOTSA 去除 padding 后的数据、Time-IMM 的不规则多变量部分；
  - 使用 Apache Arrow 统一序列化存储；

  - 过滤 LOTSA 中与这些基准重叠的子语料，防止数据泄漏。
- **预训练**：
  - 动态窗口划分：按 Beta 分布随机选择划分点，将 patch 序列分为历史前缀和目标段；
  - 前缀允许双向信息流，目标段因果逐步预测；
