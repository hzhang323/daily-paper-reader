## 摘要
在部分可观察环境中的AI智能体需要协调主动感知与工作记忆，以维持不断演化的感知状态。然而，现有基准因引入物理与控制复杂性而难以单独评估这种感知状态的构建与解释能力。我们通过MNIST-PRO来解决这一问题，该基准将MNIST数字识别转化为一个带回溯约束的序列化、基于瞥视的搜索任务，从而隔离智能体感知。我们评估了十种多模态模型在四种记忆表征下的表现，包括原始视觉历史、文本状态、结构化度量网格地图以及整合视觉画布。尽管模型在完全可观察性下表现出色，但部分可观察性暴露了明显的性能差距。我们识别出三个不同的瓶颈。首先，感知状态的构建与解释构成挑战，因为智能体难以整合碎片化的瞥视。其次，智能体往往在看清完整序列之前就停止探索。第三，即使面对后续的矛盾证据，模型也常常无法修正早期错误的信念。这些结果表明，仅仅获取视觉证据是不够的。智能体还必须能够构建并更新可靠的感知状态。

## Abstract
AI agents in partially observable environments need to coordinate active sensing with working memory to maintain an evolving perceptual state. However, existing benchmarks struggle to isolate this perceptual-state construction and interpretation capability because they introduce physical and control complexities. We address this with MNIST-PRO, a benchmark that isolates agentic perception by converting MNIST digit recognition into a sequential, glimpse-based search task with lookback constraints. We evaluate ten multimodal models across four memory representations, including raw visual history, textual states, structured metric grid maps, and a consolidated visual canvas. While models excel under full observability, partial observability exposes a clear performance gap. We identify three distinct bottlenecks. First, perceptual-state construction and interpretation present a challenge, as agents struggle to integrate fragmented glimpses. Second, agents often stop exploring before they see the full sequence. Third, models often fail to revise early, incorrect beliefs even when faced with subsequent contradictory evidence. These results show that simply acquiring visual evidence is not enough. Agents must also be able to build and update a reliable perceptual state.

### 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：部分可观测环境下，AI智能体是否具备“智能体感知”（agentic perception）能力——即能否主动获取视觉证据，并在工作记忆中构建、维护和更新一个可靠的感知状态来指导决策。
- **背景**：
  - 标准多模态推理基准（如 MMBench、MMMU）一次性提供完整视觉输入，不要求智能体主动获取信息。
  - 主动感知/视觉搜索基准（如 ActiView、ActiveVision）允许积累无限视觉历史，无法区分“依赖原始图像历史”和“真正构建了状态化感知”。
  - 具身3D基准（如 ALFRED）引入导航碰撞、交互失败等物理噪声，难以将失败归因于感知、记忆、规划还是控制。
- **核心洞察**：识别能力 ≠ 智能体感知能力。仅有视觉证据远远不够，智能体必须能够将碎片化观察整合为持续更新的感知状态，并能在矛盾证据出现时修正早期信念。

### 2. 论文提出的方法论（核心思想与关键技术细节）
- **核心思想**：将 MNIST 数字识别改造为 POMDP 形式的顺序瞥视搜索任务——智能体只能通过一个局部“瞥视窗口”（glimpse window）观察完整图像，需要自主决定移动方向，并最终提交分类结果。
- **POMDP 定义**：
  - 状态空间 S =（全局画布 I，智能体坐标 p_t）；观测空间为仅露出 h×w 尺寸瞥视窗口的遮蔽图像。
  - 动作空间分为移动动作（up/down/left/right，步长 δ）和预测动作（终止回合并输出标签）。
  - 转移函数对坐标进行 clip 操作保证合法；MDP 定义每个状态分配下动作集合可能的转移，但环境本身应为静态画布+移动窗口。
  - 回合预算 T_max 设定为覆盖整张画布所需的最少离散步数（如 Level 1 中为 36 步、Level 2 为 78 步）。
- **智能体循环**：将任务分解为“证据获取→感知状态构建→感知状态解读→决策/行动”四个环节，并将预测函数分解为 H_θ = D_θ ∘ R_θ，用于区分感知状态的构建和后续解读阶段。
- **两种任务层级**：
  - **Level 1（单数字）**：只含一个居中数字，只需一个坐标系的集成（识别难度较低）。
  - **Level 2（多位数字序列）**：左右串联两个数字，需跨较大画布搜索、正确解码两个数字、同时保留顺序，空间与时间跨度更大。

### 6. 论文的主要结论与发现
- **识别优秀不等于感知构建优秀**：控制条件（全可见）下模型几乎都能识别数字（83.0%–99.0%），但在部分可观测条件下同一模型出现大幅下跌（例如 Gemini-3.1-Pro-Preview 从 99.0% 跌到 38.0%）。
- **证据获取 ≠ 证据利用**：覆盖率较高的模型（如 Claude-5-Opus、Claude-5-Fable）单靠自身判断时准确率偏低；而把它们的轨迹用离线画布方式拼接后再判断时，准确率大幅上升（Claude-5-Fable 在两级任务上分别达到 81.0% 和 69.0%），表明瓶颈主要在感知状态的构建与解读环节。
- **记忆表示影响显著，且存在交互作用**：
  - 并非“结构化程度越高越好”——Gemini-3.1-Pro-Preview 加入网格地图后反而比单纯文字状态下降；
  - Gemini-3.7-Flash 则依靠度量网格地图准确率更高；
  - Level 1 中多数模型的纯视觉历史明显占优；Level 2 中文本/结构化状态的相对价值上升。
  - 增加原始视觉历史（H 增大）提升不少Level 2 任务的准确率（Gemini-3.7-Flash 的文本状态从 6.0% 提升到 23.0%），代价是上下文增长。
- **多数字序列（Level 2）明显暴露新瓶颈**：即便两个数字都覆盖了 75% 以上的笔画，序列级准确率最高也只有 26.0%，说明记忆综合与解读可能比单纯的证据采集更关键。
- **探索行为模式存在明显差异**：
  - 快速承诺型（GLM-4.6V、GPT-5.6-Sol、Qwen-3.8-27B）：早早就停止探索，Level 2 上几乎失效；
  - 过度漫游型（GPT-5.6-Terra、Claude-5-Sonnet 等）：步数多、回溯率高但结果不佳；
  - 较好的模型（Gemini-3.7-Flash）在覆盖率与探索效率之间取得平衡。
- **智能体很难修正早期错误信念**：早期在文本状态中写入错误数字后，即便后续观察到矛盾的笔画，仍会把错误信念带入最终预测（Gemini-3.7-Flash 的 17/39 错误中 15/17 保留原错误）。
- **工具型 harness 要配合“自我构建”的状态才能发挥优势**：Gemini-3.7-Flash +（自动编写 canvas 拼图脚本）获得 L1 88.0%、L2 63.0% 的显著提升；持久记忆并不必然带来准确率增益，反而会降低行动效率并增多探索步骤。
- **盲目扩大看得到的窗口并不解决全部问题**：即便提供 128×128 大窗口，模型的准确率也仍然低于全可观察的控制上限；可见更大的一步到不了“看全”状态，系统性的搜索 + 反映空间结构的状态设计同等重要。

### 7. 优点
- **以极端简化的 MNIST 为媒介进行认知任务剥离**：物理与动作层面的混淆小，能将失败归因于证据获取、状态构建、状态解读或决策时机。
- **精细的消融设计**：通过历史长度可调、不同记忆表示、在线/离线画布等手段系统分离了“构建”和“解读”环节；交叉解码器实验是其亮点之一，清晰显示相同证据下替代模型能显著提升准确率。
- **量化探索策略的健康状况**：覆盖率、回溯率、探索轨迹的可视化和早期停止测量等指标有助于刻画模型行为特征。
- **引入“自建画布”的智能体行为** 发现即使工具环自主拼接观察，也不一定带来正确预测——避免过度乐观地将画布机制视为灵丹妙药。
- **跨模型比较点出“不完全可见性下的信心把握”问题**：这些结果实际指向了不确定性感知与证据充分性估计之间的结合缺陷。
- 对顺序、结构、编码的长期维持让任务挑战更接近实际 AI 智能体长程操作任务。

### 8. 不足与局限
- **领域范围过窄**：MNIST 数字的二值图极其简单，无法完全推广到任意自然图像、GUI、视频或3D 空间感知的状态构建任务；
- **100 次测试回合的规模偏小**，数字对为独立均匀采样时方差较大；文章给出的准确率非常粗糙（±若干百分点），难以支撑模型之间 1–2 个百分点的排序；
- **在线/离线比较的不完全等价性**：离线模式使用事后拼接画布，并不会纳入模型在探索中途可能形成的错误状态，因而可能高估该画布表示在“实时任务”中的效果；
- **模型 API 的黑箱属性**：没有固定思维链长度、随机种子、温度等参数说明，且“thinking level”因默认配置而异，可能把模型的“特质”错当成“能力差异”；
- **未评估刻意“不答”的类型**：如模型在不确定时收手或求助于外部反馈，或者说没有把“不做预测”选项纳入待预测的结果空间；
- **没有提供每个模型在实际正确路径上的相关度比较**，“覆盖率本身是否等价于‘看到判别性的关键笔画’”的问题不够严谨，作者自己也提到获取证据的“信息量”同覆盖率可能有显著差异；
- **视觉回溯长度仅做整数点扫描**：H=2 或 H=4 的梯度变化无法解释过渡机制细节；对在线画布实验里回溯量的影响也未完全控制；
- 完整修复错误信念的干预机制（例如显式回写冲突信息）并未专题研究，仅观察到问题存在；
- 在 “模型→智能体/ harness → 任务” 三层中，只对其中两个专有模型测试 harness，未能刻画工具型能力的普遍化影响。

——以上是根据原文内容进行的忠实总结。
