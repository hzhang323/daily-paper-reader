## 摘要
历史观测并非总是固定的：随着新证据的出现，统计机构会修订此前发布的值。因此，基于当前下载的数据进行预测，可能使模型接触到在其据称作出预测之日尚不可获得的信息。我们提出 VINTAGE-TS，一种对时间序列基础模型进行修订感知适配的方法，它区分观测时间与信息可用时间。其预测目标是下一期首次发布的值，以及该发布之后固定天数时可获得的值；二者均未被宣称为最终真值。一个联合预测分布保留了这些目标之间的依赖关系，并揭示其差异的不确定性。我们设计了一个基于 ALFRED 的滚动评估、一个匹配的 Chronos-2 对比、传统基线与修订感知基线，以及对预训练重叠的单独审计。随附软件实现了有效区间重建、延迟标签过滤、冻结主干的适配器接口，以及可复现的诊断。一个已执行的合成演示和一套包含 25 种配置的敏感性测试套件验证了该工作流程，揭示了不同随机种子和修订机制下的变异，并说明了后见之明污染如何改变所测性能。31 个自动化测试检验时间与集成契约。真实的 ALFRED 和 Chronos-2 实验尚未执行；未声称任何实证的基础模型优势。

## Abstract
Historical observations are not always fixed: statistical agencies revise previously published values as new evidence arrives. Forecasting from a contemporary download can therefore expose a model to information unavailable at the date it purportedly made a prediction. We propose VINTAGE-TS, a revision-aware adaptation of a time-series foundation model that distinguishes observation time from information-availability time. Its targets are the next period's first-published value and the value available a fixed number of days after that publication; neither is declared final truth. A joint predictive distribution preserves dependence between these targets and exposes uncertainty about their difference. We specify an ALFRED-based rolling evaluation, a matched Chronos-2 comparison, conventional and revision-aware baselines, and a separate audit of pretraining overlap. The accompanying software implements validity-interval reconstruction, delayed-label filtering, a frozen-backbone adapter interface, and reproducible diagnostics. An executed synthetic demonstration and a 25-configuration sensitivity suite verify the workflow, expose variation across seeds and revision regimes, and illustrate how hindsight contamination changes measured performance. Thirty one automated tests check temporal and integration contracts. Real ALFRED and Chronos-2 experiments have not been executed; no empirical foundation-model advantage is claimed.

## 2. 方法论：核心思想、关键技术与公式

### 2.1 双时间数据与目标契约
- 归档记录定义为 `e = (i, t, ve, ue, xe)`，其中 `[ve, ue]` 为记录值有效的闭区间（沿用 API 的 inclusive real-time-period 语义）。
- 预测起点 `o`（日末语义）时当前值：`y[o]_{i,t} = xe` 当且仅当 `ve ≤ o ≤ ue`。
- 历史事件集只含 `ve ≤ o` 的记录；未来的 `ue` 仅用于判定区间归属，**绝不作为输入特征**。
- 目标定义：
  - 首次发布：`Y^F_{i,t} = y[r_{i,t}]_{i,t}`
  - 成熟值：`Y^{M,L}_{i,t} = y[r_{i,t}+L]_{i,t}`
  - 修订差：`D^L_{i,t} = Y^{M,L}_{i,t} − Y^F_{i,t}`
- **标签可用性约束**：首次标签需 `r_{i,t} ≤ o`；成熟标签需 `r_{i,t}+L ≤ o`。参考适配器使用完整配对（更严格条件），但指出这会浪费部分近期首次发布标签，神经网络实现应用目标专属 loss mask。
- 每个训练特征向量都**在其自身历史起点重建**，绝不用事后修订"升级"上下文；前向填充保持因果性并保留缺失通道，禁止后向填充。

### 2.2 输入通道
- 对每个可见观测期构造：最新值、首次归档值、累计修订、发布年龄、事件计数、缺失指示。
- 全部为 `Io` 的函数；修订三角形被压缩为这些通道（有信息损失：相同摘要的两条修订路径不可区分）。
- 修订感知模式额外把这些通道作为 **past-only 协变量**传入，绝不传入未来修订量、未来事件数或已实现发布日期。

### 2.3 冻结主干适配器（可执行部分）
- 设 `bo` 为冻结主干（Chronos-2）对目标期的中位数，`so > 0` 为 as-of 上下文差异导出的尺度，`zo` 为特征向量。双输出残差适配器：

  `[Y^F; Y^{M,L}] | Io ~ N( bo·1 + so·B^T·z̃o , so²·Σ̂o )`

- 参考头为岭回归（惩罚 10、截距不正则化），使用 12 个上下文滞后、缺失指示，修订感知模式再加入对应修订、log-age、log-count 特征；Chronos 模式额外加入归一化主干中位数与区间导出的离散度特征。
- **协方差估计**：从最近 12 个完整、合格的校准配对估计残差协方差；均值头只用成熟目标日期 ≤ 首个校准起点的配对训练（purge 延迟标签重叠）；校准配对与均值拟合配对不相交。
- 修订分布直接由联合协方差导出：
  - `μD = μM − μF`
  - `σ²D = ΣMM + ΣFF − 2ΣFM`
  - 更一般地：`Var(Y^M) = Var(Y^F) + Var(D) + 2Cov(Y^F, D)`
  - 强调这优于在无依据的独立性假设下相加边际方差。

### 2.4 提议的神经扩展（未实现、未测试）
- 用分离的观测时间嵌入与发布时间嵌入编码每个事件，只对示例起点可见的事件做注意力。
- 两个头或一个联合条件密度预测 `Y^F` 与 `D^L`，从而恢复 `Y^M = Y^F + D^L`；支持已发布期的修订 nowcasting。
- 边际分位数头的可用目标函数：`L = Σ_{k∈{F,M}} λk Σ_{e,q} m_{e,k}(o)·ρq(Y_{e,k} − Q̂_{e,k,q})`，其中 `m_{e,k}(o)` 强制目标专属可用性；但两组边际分位数不足以识别修订分布，仍需联合似然或依赖模型。

## 6. 主要结论与发现

- **无稳健优势**：单种子演示中 Revision-linear 使成熟目标 MAE 降低 0.031，但 CRPS 反而更差；配对块 bootstrap 区间 `[−0.148, 0.195]` 跨零。
- **多种子下反转**：5 种子 180 天标准设置下，Revision-linear 成熟 MAE 均值 1.231，劣于 AR（1.007）与 state-space（0.918）；成熟 CRPS 0.875 也差于 0.728 与 0.656；首次发布比较同样不利。3 个种子的 95% 块 bootstrap 区间整体低于零（不利于修订特征）。
- **点精度与概率性能需分开评估**。
- **后见之明污染的方向不唯一**：Hindsight AR 成熟 MAE 比诚实 AR 低 0.077（区间 `[−0.045, 0.203]`），但首次发布目标方向相反（诚实减 hindsight MAE = −0.194，区间 `[−0.362, −0.017]`）。即后续修订可移除与早期报告误差相关的信息，污染不必改善每个指标也能使历史信息集失效。
- **成熟期与噪声敏感性**：AR 成熟 MAE 从 90 天的 0.973 升到 365 天的 1.046，state-space 稳定在约 0.91；修订误差乘子从 0.25 到 2 时，AR 成熟 MAE 由 0.798 升至 1.177。该合成生成器偏袒显式建模衰减误差的结构，**不证明 state-space 在真实新闻型修订下占优**。
- **核心结论**：当前数值结果既不确立经济预测收益，也不确立基础模型改进；真实 ALFRED 与 Chronos-2 实验未运行，无实证优势主张；零结果具有科学意义（修订历史可能信息量弱，或最新 vintage 模型已利用其有用后果）。
