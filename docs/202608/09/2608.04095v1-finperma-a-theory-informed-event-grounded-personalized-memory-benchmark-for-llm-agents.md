## 摘要
大型语言模型（LLM）代理越来越多地被用作金融咨询等高风险领域的个性化助手，然而它们能否在长时间跨度内维护和更新个性化的用户模型仍不清楚。现有的个性化记忆基准主要测试事实性保留，或依赖约束较弱的模型生成轨迹，导致事件驱动的偏好适应未得到充分探索。我们提出了FinPerMA，一个基于事件锚定的基准，针对冻结的纵向投资者轨迹评估个性化记忆。其生成流程结合了确定性的、理论指导的影响规则，受控的LLM叙述，以及自动化质量筛选；一个“冲击后”检查点用于隔离代理是否已将重大事件整合到其持久用户模型中。在来自276个角色的2,994个问题上，七个前沿LLM和最多七种记忆配置远未饱和：没有任何全上下文配置的总体准确率超过约0.47，或多项选择题准确率超过约39%。归因分析表明，基于摘要的记忆往往保留事实细节，但丢失了个性化所需的偏好信号；因此，简单的检索可以胜过专门构建的记忆系统，并且这种差距在冲击后扩大。

## Abstract
Large language model (LLM) agents are increasingly used as personalized assistants in high-stakes domains such as financial advising, yet it remains unclear whether they can maintain and update an individualized user model over long horizons. Existing personalized-memory benchmarks primarily test factual retention or rely on weakly constrained model-generated trajectories, leaving event-driven preference adaptation underexplored. We introduce FinPerMA, an event-grounded benchmark that evaluates personalized memory against frozen longitudinal investor trajectories. Its generation pipeline combines deterministic, theory-informed impact rules, controlled LLM narration, and automated quality screening; a Post-Shock checkpoint isolates whether an agent has integrated a material event into its persistent user model. On 2,994 questions from 276 personas, seven frontier LLMs and up to seven memory configurations remain far from saturated: no full-context configuration exceeds approximately 0.47 overall accuracy or approximately 39% on multiple-choice questions. Attribution analysis shows that summary-based memory often preserves factual details while losing the preference signals needed for personalization; simple retrieval can therefore outperform purpose-built memory systems, with the gap widening after shocks.

## 2. 论文提出的方法论

### 2.1 核心思想

FinPerMA通过**五阶段流水线**生成基准语料：

\[
\mathcal{C} = \{(P_i, T_i, D_i, Q_i)\}_{i=1}^N
\]

其中，每个角色 \(P_i\) 包含角色描述，\(T_i\) 是 5–8 个事件构成的时间线，\(D_i\) 是多会话对话集，\(Q_i\) 是评估问题集。核心对象是事件反应 \(R_{i,k}\)：

\[
R_{i,k} = \text{ImpactModel}(P_i, E_{i,k}, M_{i,<k})
\]

### 2.2 关键技术细节：三层影响模型（Impact Model）

**Layer 1：基于规则的冲击约束（ImpactConstraint）** —— 由五个子模块组成：

- **M1（BIT分类）**：依据Pompian（2012）将角色分为四类行为投资者类型——被动保护者（PP）、友好跟随者（FF）、独立个人主义者（II）、积极积累者（AA），不同类型门控偏好方向和禁止偏差集合。
- **M2（事件冲击系数）**：查询表将（BIT, 事件类型）映射到方向和系数，基准冲击幅度计算为：
  \[
  \text{base\_mag}(E) = c[E.\text{type}] \cdot \frac{E.\text{severity}}{5}
  \]
- **M3（大五人格乘数）**：基于神经质（N）和外向性（E）缩放冲击幅度：
  \[
  m_{\text{trait}}(P) = 1 + 0.30(P.N - 0.5) - 0.15(P.E - 0.5)
  \]
- **M4（经验历史聚合）**：基于年龄依赖的指数加权聚合经验收益，调节冲击幅度在 [0.6, 1.4] 范围内。
- **M5（符号记忆参考锚）**：基于标签集Jaccard重叠和事件类型匹配激活记忆，以指数衰减强度加权存储值形成参考点。

**Layer 2：受约束的LLM叙述器** —— 将ImpactConstraint作为硬边界注入提示词，要求LLM生成结构化的JSON输出，包含：偏好增量（preference_deltas）、内心独白（inner_monologue）、触发的偏差（biases_triggered）和置信度（confidence）。

**Layer 3：自动验证器与重试机制** —— 对风险方向一致性、风险增量边界（20%容差）、禁止偏差排除、事件类型一致性进行硬性检查；失败时触发最多三次重试，超出后使用置信度0.2的模板回退。

### 2.3 评估任务设计

- **三维框架**：记忆保真度（MF，事实回忆）、偏好推理（PR，从行为轨迹推断隐含偏好）、情境适应（CA，在新决策场景中应用可能更新的偏好）。

- **Post-Shock检查点**是论文的主要评估协议贡献，与LongMemEval（事实级更新）和LoCoMo（超长对话连续性）形成区别。

## 6. 论文的主要结论与发现

**发现一：存在巨大且依赖模型的差距。**
- 人物历史将每个模型的准确率从0.18–0.27（无记忆）提升至0.41–0.47（全上下文），提升1.5–2.4倍。
- 无历史时，多选题准确率接近随机水平（0.17–0.26）；即使有全上下文，也**没有配置的多选题准确率超过约39%**——基准远未饱和。
- 更强的参数知识（如Claude的强先验）并不能替代人物特定的证据。

**发现二：在固定骨干上，简单检索优于结构化记忆系统。**
- BM25和BGE-M3检索均恢复了上下界差距的约88%，而三个结构化/档案记忆系统仅恢复54–79%。
- 差距集中在开放式问题上：检索保留了摘要/档案系统可能丢弃的逐字证据。
- 成本因素改变排名：bge_rag以1.40k而非12.8k上下文令牌达到88%的恢复水平，在边际效率上拥有约12倍优势。

**发现三：冲击后差距扩大——更新是核心瓶颈。**
- Qwen3.7-Max上，full_context与mem0之间的差距从时间线内的8.0个百分点扩大到冲击后的13.0个百分点。
- 差距恰好在“新证据应修正已存储用户状态”时扩大，这证实了Post-Shock是一个不同于简单回忆的、独特的记忆更新测试。

**发现四：记忆整合保留事实但丢失偏好信号。**
- MemOS在事实回忆上与full_context匹配（27.7 vs 27.1），但在推理目标上大幅下降（偏好追踪：31.9 vs 52.9；偏差识别：32.6 vs 54.0）。
- 摘要记忆系统“保留事实表面，却丢失个性化所需的偏好信号”。

**发现五：错误模式揭示了三个独立瓶颈。**
- 主要错误模式为“零记忆默认”（zero-memory default），其次是“单信号过度推断”（single-signal over-inference）和“时间错位”（temporal misalignment），三者合计约占错误的66%。
- 这一发现将回忆、整合和时效性分离为不同的瓶颈，表明每个环节都需要单独的改进。

**发现六：反典型人物暴露刻板印象回退。**
- 所有模型在反典型人物上的得分比典型人物低4.5–11.2个百分点，表明当个体证据与熟悉档案冲突时，模型会回退到类型级刻板印象。

## 7. 优点（方法或实验设计的亮点）

1. **事件驱动设计的可审计性**：三层Impact Model将理论启发的启发式规则实现为可审计的生成骨架——Layer 1确定性产生冲击约束，Layer 2在约束下进行受控叙述，Layer 3执行自动检查与重试。同一输入跨运行产生确定性输出，确保可复现性。

2. **“冻结语料”原则**：事件轨迹和标签在评估任何记忆系统之前就已冻结（v8gold），避免了“生成器属性与评估目标纠缠”的问题。所有系统面对相同的轨迹，比较不依赖于为每个评估模型重新生成标签。

3. **Post-Shock检查点**：这是一个直接测试“是否将重大事件整合到持久记忆”的协议贡献，填补了现有基准（LongMemEval的事实级更新、LoCoMo的超长对话连续性）未覆盖的关键评估维度。

4. **理论驱动的可解释操作化**：行为金融学的核心理论（BIT分类、时变风险偏好、经验效应、记忆参考依赖、大五人格与风险容忍度的关系）被系统性地转化为符号化、可审计的生成规则，而非依赖不可解释的端到端生成。

5. **多维归因分析**：不只报告一个整体分数，而是通过能力雷达图、预标记干扰项失败模式、检查点级别差距、反典型人物分析四个维度，将失败定位到回忆、更新、整合、时效性、偏见等多个环节。

6. **干扰项的严格设计**：六选项MCQ、答案位置均匀洗牌、干扰项与正确选项在结构上匹配（中位长度差≤5个字符、52.9%在5字符内），有效降低猜对概率。

7. **基线选择合理**：no_memory下界和full_context上界构成了清晰的性能区间，使读者可以立即判断模型是“没有记忆”还是“有了记忆但仍不足”。

## 8. 不足与局限

1. **合成人物与实际投资人的差距**：FinPerMA使用合成人物和规则引导的偏好变化，基准准确率不能直接等同于真实投资者的表现。行为金融学规则是对真实人类行为的有意简化和操作化，并非实证估计的结构化行为模型。

2. **时间线规模有限**：每个角色仅5–8个事件，聚焦于个人金融领域。更长的历史（数月/年）可能揭示不同的记忆挑战；其他高风险领域（医疗、教育）也可能有不同模式。

3. **评估统计功效有限**：记忆系统比较仅用单一种子，各配置使用不匹配的原生令牌预算（对公平的架构比较构成限制）；2,994个问题在子群分析时统计功效可能不足。

4. **实验控制变量的缺口**：七个基座模型的比较未控制推理预算、提示工程策略或系统级差异；记忆系统的比较未在多个基座模型上验证（仅在Qwen3.7-Max上）。

5. **评估协议窗口限制**：部分全上下文配置中，35个查询因网关内容安全过滤器被丢弃（Claude和GPT），可能导致上界略有偏差。

6. **测试集与训练数据的潜在污染风险**：论文未明确讨论基准语料与基座模型预训练数据重叠的可能性。由于事件是基于真实2020–2026事件构建的，模型中可能已存在关于这些事件的知识，尽管“人物特定的偏好变化”应属于新信息，但仍需更明确的泄漏检测。
