## 摘要
大型语言模型（LLMs）正日益被部署为编排者，通过自然语言协调专门的子智能体来解决复杂任务。然而，在游戏和机器人等许多重要领域，最强的可用智能体并非语言模型。将非语言智能体与LLMs集成需要“言语化”：在每次交互步骤中，将其丰富的连续表示压缩为稀疏的文本摘要。为了研究言语化是否构成瓶颈，我们引入了\textsc{LLAMIA-Bench}，这是一个包含六个多样化协作国际象棋任务的套件，涵盖三个层面：行为模仿、状态评估和自然语言解释。每个任务都实例化了一个既有的国际象棋问题，而该问题仅靠LLM或国际象棋引擎都无法单独解决。为了解决LLM与非语言智能体的协作问题，我们引入了“潜在状态内化”，该方法将子智能体的连续表示直接投影为LLM的令牌流中的学习状态令牌，并在动作推进环境状态时进行动态重新编码。将内化与言语化集成进行比较，我们的实验揭示了一致的“言语化欠账”：性能差距在训练过程中不断扩大，并随着LLM参数量从4B扩展到14B而持续存在。一个使用潜在状态内化训练的14B单一模型\textsc{LLAMIA}，在所有基准任务中匹配或超越了任务专家和包括具有工具访问权限的GPT-5.1在内的前沿模型，并在分布外场景中实现了泛化，而任务特定的微调则在此时失效。

## Abstract
LLMs are increasingly deployed as orchestrators that coordinate specialized subagents to solve complex tasks through natural language. However, in many important domains like game playing and robotics, the strongest available agents are not language models. Integrating non-language agents with LLMs would require \emph{verbalization}: compressing their rich continuous representations into sparse textual summaries at each interaction step. To study whether verbalization constitutes a bottleneck, we introduce \textsc{LLAMIA-Bench}, a suite of six diverse collaborative chess tasks spanning three facets: behavioral imitation, state assessment, and natural-language explanation. Each task instantiates a well-established chess problem that neither the LLM nor the chess engine can solve alone. To solve LLM collaboration with non-language agents, we introduce \emph{latent state internalization}, which projects the subagent's continuous representations directly into the LLM's token stream as learned state tokens, with dynamic re-encoding as actions advance the environment state. Comparing internalization to verbalized integration, our experiments reveal a consistent \emph{verbalization debt}: the performance gap widens throughout training and persists as the LLM scales from 4B to 14B parameters. A single 14B model, \textsc{LLAMIA}, trained with latent state internalization, matches or exceeds task specialists and frontier models including GPT-5.1 with tool access across all benchmark tasks, and generalizes out-of-distribution where task-specific finetunes collapse

## 一、核心问题与整体含义

- **研究背景**：LLM 日益被用作通用“编排器”，通过自然语言协调专用子智能体解决复杂任务（如 Toolformer、ReAct、MetaGPT 等）。当子智能体同为语言模型时，文本沟通是低损耗的；但在游戏、机器人、自动驾驶等关键领域，当前最强的智能体往往不是语言模型，而是依靠连续潜在状态表征策略与价值的神经网络（如 AlphaZero、RT-1）。
- **核心问题**：如果 LLM 只能通过“言语化”（verbalization）——把子智能体的连续高维表征压缩为稀疏的文本摘要——来协作，是否会构成信息瓶颈？这种瓶颈是否随着任务交互深度的增加而加剧？
- **整体主张**：论文提出“言语化债务”（Verbalization Debt）概念，认为言语化是有损瓶颈，导致 LLM 无法充分获取非语言智能体的领域专长。为此提出“潜在状态内化”（Latent State Internalization），将子智能体隐含表征直接注入 LLM 的 token 流，使两类异构智能体能够在连续空间中深度协同。
- **检验平台**：以国际象棋为测试床（拥有开源强引擎 Lc0、丰富人机协作任务、可验证指标），构建 LLAMIA-Bench 基准并训练 LLAMIA 模型。

## 二、方法论

### 2.1 核心思想

- 让 LLM 和冻结的非语言子智能体（Lc0-BT4 引擎）沿同一条推理轨迹协作，轨迹中交错三类 token：
  - **语言 token**：LLM 的思维链；
  - **动作 token**：使环境状态推进的招法；
  - **潜在状态 token**：将子智能体倒数第二层激活，通过可学习投影映射到 LLM 嵌入空间的连续 token。
- LLM 自选时机调用 `get_policy`，可请求评估当前局面或假设局面；每次环境状态变化后，子智能体重新编码并注入新的潜在状态 token。
- 言语化方法（LLAMIA-Verb）只返回文字化的 top-moves/评估值，作为对照。

### 2.2 技术细节

- **子智能体**：Lc0-BT4，1.5 层 Transformer（240M），输出维度 1024。
- **LLM 骨干**：Qwen3 系列，规模 4B / 8B / 14B。
- **LatentBridge（投影器 Hφ）**：三层 MLP + GeLU，将 Lc0 的 1024 维状态映射为 k=32 个、维度等于 LLM hidden size 的连续嵌入。
  - 选择 Lc0 layer 14 (penultimate) 提取特征；
  - k=32 为性能/开销折中的最优值。
- **训练流程**：
  1. **Stage 1：投影器对齐**。冻结 LLM，仅训练 LatentBridge，在大量（state, policy）对上做交叉熵，让投影器学会输出可被 LLM 读懂的动作信息。
  2. **Stage 2：强化学习（DAPO）**。联合微调 LLM 和 LatentBridge，采用 group-relative policy optimization（不对称裁剪）；对动作 token 和语言 token 计算策略梯度，潜在状态 token 位置梯度掩码。
- **公式示意**：
  - 交互轨迹：τ = ⟨z₀^{1:k}, w₀^{1:j}, a₁, z₁^{1:k}, … , w_final⟩
  - 内化表征：z_t = Hφ(Gψ(s_t)) ∈ R^{k×e}
  - LLAMIA-Verb 只接收文本 w_t = Verbalize(Gψ(s_t))
  - RL 目标为带 group normalization 的 DAPO 形式，确保潜在状态通道参与端到端学习。

### 2.3 贡献集

- 首次系统化定义和量化“言语化债务”；
- 提出可迁移的潜状态内化训练范式；
- 构建包含六个协作任务的 LLAMIA-Bench；
- 开源代码、数据（含 Agadmator-2K 游戏级解说数据集）。

## 三、实验设计

### 3.1 Benchmark：LLAMIA-Bench

1. **行为克隆（Behavior Cloning）**
   - MAIA 基准（1100–1900 Elo 五个分桶）；

3. **谜题趣味度估计（Puzzle Interest）**

4. **招法标注（Move Annotation / Rationale）**
   - 给定局面与招法，生成解释（planning、comparative 等），指标 BLEU-2、G-eval。
5. **整局解说（Game Commentary）**
   - 引入 Agadmator-2K 数据集：1,900 局带时间对齐解说的对局；指标 G-eval 与 BLEU-2。
6. **（另有）行为克隆的泛化测试与棋力匹配**

## 六、主要结论与发现

1. **言语化债务持续存在**：无论 LLM 从 4B 增至 14B，还是训练步数不断增加，LLAMIA-Verb 与 LLAMIA 的差距都越来越大（收敛时约 2–3 倍 loss/reward gap）。
2. **潜状态内化大幅领先**：
   - 单一 LLAMIA-14B 在全部六项 LLAMIA-Bench 任务上匹配或超越 GPT-5.1+Lc0、Qwen3-14B+Lc0 及任务专用模型；
   - 在 Puzzle Interest 上所有言语化系统得分 ≤12，LLAMIA-14B 达到 52，证明了非言语化信号的可获取性。
3. **OOD 泛化能力强**：在 GM-25、Low-Time、ΔElo 等分裂上超过 Maia/Allie 等专家；而任务专用微调在面对相关 OOD 时失效。
4. **协作策略差异**：LLAMIA 会随任务改变策略（行为克隆用 override、解说用反事实查询、游戏用 engine-follow），而 LLAMIA-Verb 在所有任务中都退化为 engine-follow。
5. **潜状态受人类语言指令调节**：同一潜在状态，在 Elo 指导不同时，attention 聚焦不同特征，表明它不是静态特征，而是“感知性输入”。

## 七、优点

- **问题定义清晰且有理论意义**：将 verbalization bottleneck 形式化并给出实证度量；
- **方法构建合理**：采用“冻结子智能体 + 可学习投影 + LLM 联合 RL”的两阶段方式，防止灾难性遗忘，保留了子智能体专长；
- **基准设计多样**：同时覆盖低层行为克隆、高层语言生成，且包含具有“无可言化代理”的诊断性任务 Puzzle Interest；
- **消融实验全面、控制变量严格**：将接口作为唯一变量的 LLAMIA-Verb 配对比较，使得“言语化债务”不是模型规模或训练配方差异所致；
- **人类评估支持结论**：从人类玩家视角验证了模型潜隐的“人味”和解释深度；
- **跨域尝试（围棋）提供初步泛化证据**。

## 八、不足与局限

1. **域覆盖有限**：核心实验聚焦国际象棋，围棋只做了一个行为克隆结果；机器人、自动驾驶等论文声称重要的应用领域没有实证。
2. **需要访问子智能体权重**：潜状态内化依赖被调智能体的隐藏层激活，因此无法直接用于闭源 agent（论文提出通过 LLAMIA 作为中转对接闭源 LLM，但这会增加系统复杂度）。
3. **言语化实现方式偏弱**：LLAMIA-Verb 只用了 top-k 文本摘要，未充分探索更强 verbalization（如更详细的策略分布序列化、自我提问式摘要等），可能高估了言语化债务。
4. **任务与数据潜在偏向**：
   - Puzzle Interest 的“有趣度”是社区信号，不是明确客观标签；
   - Agadmator-2K 使用 Whisper 转录与自动对齐，可能存在噪声；
   - FEN 级防污染可保证训练/测试不重叠，但对闭源 LLM 预训练语料无法完全排除。
5. **人类评估规模有限**：游戏识别只用 12 名棋手，刺激量为 30 个片段，样本量较小，对结论的稳健性有限。
6. **端到端 RL 的计算量相对“玩具化”**：每个模型总训练量仅几十 GPU-hours，是否能推广到更大且复杂的环境仍需验证。
7. **论文对细节的呈现方式有些夸大性表述**（如声称“first empirical quantification”、GPT-5.1 等闭源模型能力），需注意其评测方式可能有利于内化模型；建议读者关注具体对照的公平假设。
