## 摘要
更长的历史可以提升时间序列基础模型（TSFMs），但需要显著更高的推理成本。因此，我们探究是否可以通过一小组学习到的 token 嵌入来更高效地提供上下文信息。我们提出 PaCTS，它以连续嵌入 token 的形式生成一小组实例自适应的潜在提示，并以可见上下文为条件。这些提示可作为冻结 TSFM 的紧凑上下文替代。PaCTS 根据实例特定的全局统计量构建这些提示，并利用片段级时间信息进一步精炼，从而同时捕捉全局特征与局部时间变化。该提示模块与冻结骨干网络一起在异构时间序列上联合训练并部署。大量实验表明，提示作为上下文是有效的，在多种上下文长度和模型架构上持续提升预测性能。在更短的输入上下文下，PaCTS 能够优于使用双倍上下文的同一冻结骨干网络，同时所需推理计算显著更少。与权重空间适配方法相比，PaCTS 取得了更强的提升和更好的分布外泛化。

## Abstract
Longer histories can improve time-series foundation models (TSFMs), but require substantially higher inference cost. We therefore ask whether contextual information can be provided more efficiently through a compact set of learned token embeddings. We introduce PaCTS, which generates a small set of instance-adaptive latent prompts in the form of continuous embedding tokens conditioned on the visible context. These prompts serve as compact context surrogates for frozen TSFMs. PaCTS constructs them from instance-specific global statistics and further refines them with segment-level temporal information, capturing both global characteristics and local temporal variations. The prompt module is jointly trained and deployed across heterogeneous time series with the frozen backbone. Extensive experiments demonstrate the effectiveness of prompts as context, consistently improving forecasting across context lengths and model architectures. With a shorter input context, PaCTS can outperform the same frozen backbone using double context while requiring substantially less inference computation. Compared with weight-space adaptation methods, PaCTS achieves stronger improvements and better out-of-distribution generalization.

## 1. 核心问题与整体含义
- **研究动机**：时间序列基础模型（TSFMs）通常通过提供更长历史上下文来提升预测，但长上下文会显著增加推理成本（FLOPs、显存、延迟）。
- **现实限制**：许多时间序列本身较短，无法提供更多历史；部分预训练骨干还有固定上下文窗口，超长输入可能被截断甚至有害。
- **核心问题**：能否在不扩展长历史、不更新冻结 TSFM 权重的情况下，用更紧凑的“上下文替代物”向模型提供预测相关信息？
- **整体含义**：论文提出 PaCTS，将少量实例自适应潜在提示作为紧凑上下文，证明其可部分替代长历史，并在多个骨干、上下文长度和预测任务上提升精度与效率。

## 2. 方法论
- **核心思想**：为冻结的 TSFM 生成一小组连续嵌入 token（latent prompts），将其前置到时间序列 patch token 之前，作为实例自适应上下文。
- **基本形式**：给定输入历史 \(x\)，模型原本预测 \(\hat y=f_\theta(E(x))\)；PaCTS 改为 \(\hat y=f_\theta([P;E])\)，其中 \(P\in\mathbb{R}^{M\times d}\) 是提示，\(M\ll L\)。
- **位置编码**：所有提示 token 位置索引设为 0，视为位置无关的条件信号；原始时间序列 token 保留原位置。
- **提示分解**：最终提示为  
  \(P(x)=P_s+\sigma(g)\cdot[P_a(x)+R(x)]\)，  
  其中 \(P_s\) 为共享静态提示，\(P_a(x)\) 为实例自适应部分，\(R(x)\) 为分段级细化，\(\sigma(g)\) 为可学习门控。
- **实例自适应生成**：
  - 从输入序列提取 10 个尺度不变统计量，如均值、标准差、最小/最大、半窗变化、一阶差分均值/标准差、lag-1 自相关、观测比例、对数长度。
  - 用小型 MLP 将统计量映射为组合系数 \(z\in\mathbb{R}^r\)，再线性组合 \(r\) 个可学习提示基 \(T_i\)：  
    \(P_a(x)=\sum_{i=1}^r z_i T_i\)。
  - 该设计避免直接预测 \(M\times d\) 大矩阵，保持轻量。
- **分段级细化**：
  - 从最近观测向前切分最多 \(S=16\) 个连续非重叠段，段长随可用历史自适应。
  - 每段计算同类统计量，加相对位置嵌入，经 MLP 得到描述子序列 \(H(x)\)。
  - 以 \(P_a(x)\) 为 query、\(H(x)\) 为 key/value 做多头交叉注意力，得到 \(R(x)\)。
  - 交叉注意力输出投影初始化为零，初始不改变全局自适应提示；若有效段不超过 1 个，则 \(R(x)=0\)。
- **训练目标**：冻结骨干，仅训练提示模块；使用分位数 pinball loss，对每个样本的有效预测位置做掩码并按有效位置数归一化。
- **默认配置**：\(M=10\)，秩 \(r=4\)，最多 \(S=16\) 段，AdamW，学习率 0.001；跨异构时间序列联合训练一个共享提示模块，推理时不再更新参数。

## 5. 主要实验结果

### 5.1 GIFT-Eval 主结果
- **整体表现**：PaCTS 在冻结骨干的前提下，于 GIFT-Eval 上同时改善 MASE 与 CRPS，优于 zero-shot 冻结骨干，并在多数配置上优于或接近权重空间适配基线（全量微调、LoRA、LayerNorm-only、BitFit、线性探测）。
- **与权重空间适配的对比**：
  - 权重空间方法通常需要更新（部分）骨干参数，且随上下文长度增长收益递减甚至不稳定；PaCTS 仅训练轻量提示模块，却能达到可比的精度，且在长上下文设定下优势更明显。
  - 在部分数据集上，全量微调因过拟合或分布偏移而弱于 zero-shot，而 PaCTS 的实例自适应机制对此更稳健。
- **上下文长度的作用**：
  - 随 Chronos-2 上下文从 4,096 增至 8,192，zero-shot 收益有限，而 PaCTS 在两种长度下均保持增益，说明提示提供的是与长历史互补、而非重复的信息。
  - 在较短上下文（如 4,096）下，PaCTS 能显著缩小与长上下文 zero-shot 的差距，表明紧凑提示可部分替代长历史。

### 5.2 TIME 迁移结果
- 在 TIME 这一与 GIFT-Eval 无数据集重叠的分布外 benchmark 上，PaCTS 仍保持增益，说明提示模块学到的实例自适应条件具有一定的跨数据集泛化能力，而非仅在训练分布内有效。
- 迁移增益通常小于 GIFT-Eval 内的增益，提示域偏移仍带来一定性能损失。

### 5.3 跨骨干验证
- **PatchTST-FM（encoder-only）**：PaCTS 同样带来精度提升，表明方法不依赖特定骨干架构。
- **TimesFM-2.5（decoder-only）**：在最长上下文（至 16,384）设定下仍有效，进一步支持方法对上下文窗口规模与解码结构的鲁棒性。
- 总体上，方法在 encoder-only、decoder-only 与混合架构上均表现出正收益，体现骨干无关性。

### 5.4 单变量与多变量设定
- 仅在单变量任务上训练提示模块，直接在多变量推理中使用（不做额外训练）仍能带来增益，说明提示模块捕获的条件信息在跨变量设定下具有一定可迁移性。

## 6. 效率分析

- **可训练参数量**：PaCTS 仅引入少量参数（提示基、统计量 MLP、交叉注意力模块），远小于全量微调与 LoRA 的参数量，接近 LayerNorm-only / BitFit 量级。
- **推理开销**：
  - 由于提示 token 数 \(M \ll L\)，相比扩展历史上下文，PaCTS 增加的 FLOPs、峰值显存与延迟都较小。
  - 与“以长历史换取精度”的策略相比，PaCTS 提供了更优的精度—成本折中：在同等或更低的推理成本下获得可比或更好的精度。
- **训练成本**：提示模块训练 epoch 少（≤12）、batch 小（48），整体训练开销显著低于适配基线的 5,000 步流程。

## 7. 消融与机制分析

- **消融组件**：
  - 仅用静态提示（\(P_s\)）已有一定增益，但弱于完整方法。
  - 加入实例自适应生成（\(P_a(x)\)）后精度明显提升，说明实例级条件信息是关键。
  - 再叠加分段级细化（\(R(x)\)）获得进一步增益；由于交叉注意力输出投影初始化为零，细化模块在训练早期不干扰全局提示，起到渐进式精调作用。
- **分段数量的影响**：最多 \(S=16\) 段，段长随可用历史自适应；当有效段不超过 1 时 \(R(x)=0\)，保证短序列场景下退化为纯全局自适应提示。
- **历史长度分组**：在历史较短的分组中，PaCTS 的相对增益通常更明显，符合“紧凑上下文替代长历史”的动机。
- **预测 horizon 分组**：在较长 horizon 上增益依然存在，说明提示提供的信息不仅利于短期外推。
- **位置编码设计**：提示 token 统一位置索引为 0、时间序列 token 保留原位置，避免提示干扰原始时间位置语义。

## 8. 结论、贡献与局限

### 8.1 主要贡献
- 提出 PaCTS：为冻结的时间序列基础模型生成实例自适应潜在提示，作为紧凑上下文替代长历史。
- 设计“共享静态提示 + 实例自适应组合 + 分段级交叉注意力细化”的分层提示结构，兼顾通用性与实例特异性。
- 在 GIFT-Eval、TIME 上跨 Chronos-2、PatchTST-FM、TimesFM-2.5 验证有效性，并系统对比权重空间适配方法。
- 在精度与效率之间取得更优折中，为冻结 TSFM 的高效适配提供新路径。

### 8.2 局限
- 论文未报告具体 GPU 型号、数量与训练时长，难以评估绝对算力与能耗。
- 提示模块需针对骨干训练，跨骨干迁移需重新训练（未验证提示模块的直接跨骨干复用）。
- 在分布外 benchmark 上增益有所下降，域偏移仍是挑战。
- 方法有效性依赖于可提取的统计量与分段结构，对极短序列或非平稳性极强的序列可能受限。

### 8.3 总体评价
- PaCTS 将“上下文扩展”问题重新表述为“紧凑上下文生成”问题，思路清晰、实现轻量，且与现有权重空间适配方法正交，具备与其它高效适配技术组合的潜力。
- 其核心洞见——冻结大模型时，实例自适应的潜在条件可部分替代长历史——对时间序列基础模型的高效部署具有实际意义。
