## 摘要
现实世界的时间序列通常受重复模式的支配，但其主导周期可能因数据集、预测设置和单个输入窗口而异。现有的周期感知预测器通常依赖于在数据集级别选择的单一周期，当周期行为随时间变化或存在多个周期并存时，这可能具有限制性。此外，基于补丁的模型通常统一处理所有补丁位置，尽管离预测边界较远的补丁可能需要更广泛的上下文细化，而最近的补丁包含的信息应更直接地保留。在移除周期行为后，剩余动态也可能跨越多个时间分辨率，无法在单一尺度上充分描述。我们提出了CAMP，一种用于解决这些挑战的周期感知多尺度补丁混合器。自适应周期学习模块为每个输入窗口分别识别主导频率，并生成历史和未来的周期分量，而无需预定义周期长度。地平线引导的补丁混合器引入了位置相关的细化，允许较早的补丁融入更广泛的时间上下文，同时保留靠近预测边界的信息。CAMP进一步通过时间对齐的多分辨率表示对去周期残差进行建模，从而在一个预测框架内捕获不同尺度的互补动态。在七个长期预测基准上，CAMP在六个数据集上取得了最佳平均MSE，在六个数据集上取得了最佳或并列最佳MAE。它还在四个PEMS交通基准的十六个设置中获得了最高的MSE获胜次数。

## Abstract
Real-world time series are often governed by recurring patterns, but their dominant periods may vary across datasets, forecasting settings, and individual input windows. Existing cycle-aware forecasters commonly rely on a single period selected at the dataset level, which can be restrictive when periodic behavior changes over time or when multiple cycles coexist. Moreover, patch-based models typically process all patch positions uni- formly, although patches farther from the forecast boundary may require broader contextual refinement, while recent patches contain information that should be preserved more directly. Af- ter cyclic behavior is removed, the remaining dynamics may also span multiple temporal resolutions and cannot be adequately de- scribed at a single scale. We introduce CAMP, a Cycle-Aware Multi-Scale Patch Mixer designed to address these challenges. The Adaptive Cycle Learning module identifies dominant fre- quencies separately for each input window and generates both historical and future cyclic components without requiring a pre- defined cycle length. The Horizon-Guided Patch Mixer intro- duces position-dependent refinement, allowing earlier patches to incorporate broader temporal context while preserving infor- mation close to the forecast boundary. CAMP further models the de-cycled residual through temporally aligned multi-resolution representations, enabling complementary dynamics at different scales to be captured within one forecasting framework. Across seven long-term forecasting benchmarks, CAMP achieves the best average MSE on six datasets and the best or tied-best MAE on six. It also obtains the highest MSE win count across sixteen settings on four PEMS traffic benchmarks.

- **现有方法的不足**：
  - 周期感知模型（如 CycleNet、FreqCycle）通常**在数据集级别预设或预先估计一个固定周期长度**，无法适应样本内周期变化或多周期并存的情况。
  - 基于 patch 的模型（如 PatchTST、HDMixer）一般**统一处理所有 patch 位置**，但距离预测边界较远的 patch 需要更广泛的上下文融合，而靠近边界的 patch 包含的信息应被更直接地保留。
  - 去除周期后的残差动态往往**横跨多个时间分辨率**，单一尺度难以充分刻画。
- **研究含义**：论文提出 CAMP（Cycle-Aware Multi-Scale Patch Mixer），将周期建模与多尺度残差建模统一在一个框架中，试图解决"周期自适应识别"与"位置感知多尺度残差建模"两个关键挑战。

## 二、方法论

### 核心思想
CAMP 沿用"周期–残差"分解范式：显式建模周期分量、从输入中移除、再在预测中注入；骨架网络只负责预测残差。但与 CycleNet 等固定周期方法不同，CAMP 的周期识别是**逐输入窗口（sample-adaptive）**的。

### 整体架构流程
1. RevIN 归一化输入 \(X_{in}\)
2. **Adaptive Cycle Learning（ACL）**：识别样本级主导频率，生成历史周期 \(C_{hist}\) 和未来周期 \(C_{pred}\)
3. 残差 \(R = X_{in} - D_{hist}\)
4. 用**平稳小波变换（SWT）**将残差分解为多分辨率对齐流：\([A_J, D_J, D_{J-1}, ..., D_1]\)
5. 每个流独立做 patch 化、线性投影、**Intra-Patch Mixer**（仅在 embedding 维度内混合）
6. 最粗细节流 \(D_J\) 使用 **Horizon-Guided Patch Mixer（HGPM）**；其余流使用 **Simple Patch Mixer**
7. 各流编码后取平均，经线性预测头得到残差预测 \(\hat{R}\)
8. 注入未来周期分量：\(\hat{Y}_{norm} = \hat{R} + C_{pred}\)
9. RevIN 反归一化得到最终预测

### 关键技术细节

- **Adaptive Cycle Learning（ACL）**：
  - 对每个输入窗口逐变量做 FFT，按通道平均得到幅度谱，抑制直流分量后取 **Top-K 最大幅度频率 bin**。
  - 对每个选中 bin 构造时间相位 \(\phi_k(t) = 2\pi i_k t / L\)，拼接正弦/余弦得到 2K 维 Fourier 特征，经共享两层 MLP（2K→D→C，GELU+dropout）映射为各通道的周期值。
  - 通过独立的通道级门控（sigmoid）分别控制历史周期 \(C_{hist}\) 和未来周期 \(C_{pred}\)。
  - ACL 网络**不需要预定义周期长度**，仅通过离散频率选择 + 共享合成网络实现样本自适应。

- **Horizon-Guided Patch Mixer（HGPM）**：
  - 核心思想：**patch 越靠近预测边界，保留的原始信息应越多**；越靠前的 patch 应有更多机会进行跨补丁上下文细化。
  - 实现方式：按前缀长度递减的顺序（从前 \(N-1\) 个 patch 到前 1 个 patch）依次处理，每次只更新对应前缀，每个前缀用独立参数的混合器（依次做特征混合、时间（patch 位置）混合、通道混合）。
  - 结果：patch \(U_j\) 共经历 \(N-j\) 次更新；**最靠近边界的 patch \(U_N\) 完全不参与跨 patch 混合**，以最原始的表征送入预测头。

- **多分辨率残差建模（SWT）**：
  - 使用**固定不可学习的平稳小波变换**，通过带膨胀（dilation 逐层翻倍）的分组一维卷积和循环填充实现，通道之间独立。
  - SWT 是未降采样的，因此所有流长度保持为 L，patch 位置跨流对齐，可直接做流间平均聚合。
  - 不使用逆 SWT，小波系数直接作为多分辨率特征流。

- **Simple Patch Mixer**：依次对 embedding 维、patch 维、通道维各做一次 MLP + 残差连接，与 HGPM 互为对照。

## 六、主要结论与发现

- **长期预测**：CAMP 在 7 个数据集中 **6 个取得最佳平均 MSE，6 个取得最佳或并列最佳 MAE**。
  - 代表性增益：ETTh2 上 MSE 0.309 vs. 第二好的 PatchTST 0.331；Weather 上 MSE 0.219 / MAE 0.261 均为最优；Electricity 上 MSE 0.154 最优，MAE 与 CycleNet 并列第一（0.251）。
  - **例外**：Traffic 上 CAMP 不是最优（SRSNet MSE 0.392 最低，PatchTST MAE 0.266 最低，CAMP 为 0.405/0.277）。论文推测原因是大规模强相关传感器变量场景下，密集的全通道混合可能引入无关依赖并造成过平滑。
- **短期预测（PEMS）**：CAMP 在 16 个设置中获得 **10 个最佳 MSE、7 个最佳 MAE**，为所有方法中 MSE 获胜数最高；在 \(H=12\) 时所有 4 个数据集的 MSE/MAE 全部最优；PEMS08 上全部 4 个视野 MSE 最优。
  - 在长视野下 iTransformer 和 SCINet 在部分 MAE 指标上反超，暗示交通场景长程预测可能需要更强的空间/跨传感器建模。
- **消融研究**：移除任何单一模块都会导致性能下降；"仅保留 HGPM 流"或"用 RecurrentCycle 替换 ACL"均不如完整 CAMP。说明**自适应周期学习、SWT 多分辨率残差、intra-patch 编码、horizon-guided patch 混合四者具有互补贡献**。
- **ACL 的通用性**：将 ACL 嵌入 CycleNet 后，在 ETTm1、Traffic、Weather 上 MSE 和 MAE 均获得改善（相对误差降低最高 2.90%），表明 ACL 可作为通用的周期学习组件。

## 七、优点

- **周期建模的自适应性**：ACL 无需预先指定或离线估计周期，逐窗口选择主导频率，有效应对周期随数据集、look-back 长度和输入窗口变化的问题，相比 CycleNet/FreqCycle 更灵活。
- **位置感知的 patch 混合机制（HGPM）**：不同于以往统一处理所有 patch 的做法，按距离预测边界的远近差异化地调节信息保留与上下文融合程度，设计直观且有明确动机。
- **多分辨率残差建模**：借助 SWT 的无降采样特性获得时间对齐的多分辨率流，使不同尺度的残差动态可以在同一框架内互补建模，且 patch 位置对齐便于聚合。
- **实验设计较为严谨**：
  - 长期 + 短期多基准覆盖；
  - 3 个种子取均值；
  - 6 组消融变体覆盖每个核心模块；
  - 额外做了 ACL 迁移实验，验证了组件的一般适用性；
  - 在 CycleNet 对比中固定相同 look-back，以避免不公平比较。
- **通道级门控设计**：对历史周期和未来周期分别设置门控，允许模型自适应决定周期分量在输入侧移除和输出侧注入的强度，且通过零初始化支持"从纯残差模型逐步引入周期信息"的稳定训练。

## 八、不足与局限

- **算力信息披露不足**：完全没有报告 GPU 型号、数量、训练时间等资源信息，削弱了实际部署成本的可评估性。
- **计算成本较高**：多分辨率 SWT 流 + 逐前缀参数化的 HGPM + 多个独立 patch 编码器，参数量和计算开销显著高于轻量级基线，且论文未提供复杂度分析或效率对比。
- **周期估计的可靠性**：FFT-based Top-K bin 选择在短序列、弱周期或非平稳输入上可能不够稳定；离散频率选择不可导，学习依赖合成网络和门控间接进行，可能限制自适应能力。
- **通道交互方式的局限**：对高维、强相关变量数据集（如 Traffic，维度 862）表现不佳，全通道混合可能引入噪声依赖和过平滑，说明当前架构缺少对通道关系选择性的建模。
- **长期基准报告协议存在乐观偏差风险**：从多个 look-back 中选最优报告结果，虽然跟随 SRSNet 的做法，但会掩盖模型对 look-back 长度的敏感性，实验公平性依赖于基线的配置是否同等优化。
- **PEMS 长视野上的竞争力不足**：在 \(H=48/96\) 的多个设置中，MAE 被 iTransformer 和 SCINet 超越，说明长程交通预测中空间建模能力仍是 CAMP 的短板。
- **消融报告粒度稍粗**：正文只报告跨 4 个视野的平均消融结果，单独视野的消融细节放在补充材料，降低了读者对模型在特定预测长度下行为差异的直接可读性。
