## 摘要
由于现实世界时间序列的多样性，没有任何单一预测模型能在所有样本上持续占据优势。集成学习通过结合互补的模型优势来解决这一问题，但现有方法依赖于固定规则或仅基于数值输入的黑盒模型，未能利用LLM推理进行可解释的权重决策。我们提出REATS，利用LLM推理能力作为智能集成路由器，联合处理文本时间序列模式描述和数值特征，通过思维链推理生成可解释的、样本自适应的集成权重。为实现有效的基于LLM的集成，我们研究其关键设计选择并提出：（i）结构化输入流水线，将原始时间序列转换为具有固定token成本的混合文本-数值表示，支持无需API依赖的基于规则的思维链构建，并增强以检索到的相似样本先验；（ii）多样化的多行权重监督方案，配合token高效的百分比表格格式，降低数值复杂度并减少LLM幻觉；（iii）结合SFT与GRPO的两阶段微调框架，其中倒数奖励映射将连续无界的MSE差距转换为有界信号，并放大近最优敏感性，解决了基于回归的GRPO朴素奖励设计中固有的均匀敏感性和离群值主导的优势压缩问题。在八个基准上的实验表明，REATS在优于竞争性集成基线的同时，提供自然语言解释，并展现出对未见候选模型的强迁移学习和域外泛化能力。

## Abstract
Due to the diversity of real-world time series, no single forecasting model consistently dominates across all samples. Ensemble learning addresses this by combining complementary model strengths, yet existing methods rely on fixed rules or black-box models based solely on numerical inputs, failing to leverage LLM reasoning for interpretable weighting decisions. We propose REATS, which leverages LLM reasoning capabilities as an intelligent ensemble router that jointly processes textual temporal pattern descriptions and numerical features to produce interpretable, sample-adaptive ensemble weights through chain-of-thought reasoning. To enable effective LLM-based ensembling, we study its key design choices and propose: (i) a structured input pipeline that transforms raw time series into hybrid textual--numerical representations with fixed token cost, enabling rule-based chain-of-thought construction without API dependency, augmented with retrieved similar-sample priors; (ii) a diverse multi-row weight supervision scheme coupled with a token-efficient percentage-table format that reduces numerical complexity and mitigates LLM hallucinations; and (iii) a two-stage fine-tuning framework combining SFT with GRPO, where a reciprocal reward mapping transforms the continuous unbounded MSE gap into bounded signals with amplified near-oracle sensitivity, addressing the uniform sensitivity and outlier-dominated advantage compression inherent in naive reward designs for regression-based GRPO. Experiments on eight benchmarks demonstrate that REATS outperforms competitive ensemble baselines while providing natural language explanations and demonstrating strong transfer learning and out-of-domain generalization to unseen candidate models.

## 2. 论文提出的方法论

**核心思想**

REATS将LLM作为"集成路由器"，通过结构化输入接收时间序列的文本-数值混合描述，输出各候选模型的权重；核心训练过程为"SFT + GRPO"两阶段微调，使LLM从模仿结构化的推理模式逐步过渡到直接优化集成预测误差。

**关键技术细节**

1. **混合文本-数值输入表示**
   - 将原始时间序列转化为八组结构化特征：平稳性、噪声、趋势、季节性、自相关、统计量、IQR离群点、分布。
   - 每个特征组采用两级结构（外层组标题+内层键值对），数值精度统一取三位有效数字，**token开销固定**（输入长度由96增至512时，文本化表示token保持1085不变；而原始序列文本表示从1656增至7480）。
   - 这种结构化表示既保留了数值信息，又为基于规则的CoT构建提供了显式推理锚点。

2. **检索增强的相似样本先验**
   - 构建知识池，检索与查询序列最相似的K=3个样本，将它们的oracle权重与特征聚合为"原型"注入系统提示词，使LLM的推理锚定于历史有效经验。

3. **基于规则的CoT构建（无需API）**
   - 利用训练集oracle权重反向推导模板化的推理链，分为四步：识别主导时序特征 → 基于规则匹配候选模型能力与特征 → 对比RAG参考权重 → 得出结论性分配。
   - 实证表明：规则CoT与GPT生成CoT效果相当（甚至略优），且零API成本，结构一致性更利于SFT学习。

4. **多样化的多行权重监督**
   - 每样本以1个oracle权重（QP求解的最优权重）为首，加上9个通过Dirichlet采样和多目标贪心筛选生成的多样权重行，共K′=10行。
   - 多行监督在SFT阶段防止单一解记忆，在GRPO阶段提供更密集的reward信号和更丰富的探索空间。

5. **Token高效的权重输出格式**
   - 权重视为整数百分比表格，如`CARD,SEMixer,TimeXer,LSINet`/`35,25,20,20`，较字典格式减少183% token消耗，并降低数值幻觉。

6. **两阶段微调**
   - **SFT阶段**：学习“先推理后决策”格式、模式感知推理以及粗粒度权重分配。
   - **GRPO阶段**：直接优化集成MSE，奖励由三部分构成：每个权重行的相对MSE、聚合MSE和oracle权重邻近度。
   - **倒数奖励映射**：$r = 1/(1 + k\delta)$，将无界的$\delta$压缩到[0,1]区间。其优势在于：
     - 多项式衰减保证大$\delta$区间仍保留非零信号；
     - 非线性曲率放大近oracle候选之间的归一化优势间距；
     - 有界性防止单个离群生成主导组方差，避免近优候选优势压缩。

1. **REATS在两个候选模型组上均全面超越基线**：基础模型组平均MSE较OptW_val降低13.3%（0.1384 vs 0.1597）；小模型组较OptW_tr降低20.1%（0.1080 vs 0.1352）。

3. **倒数奖励映射优于其他映射函数和GRPO变体**：其有效解决了连续无界回归奖励下的离群优势压缩问题；直接改进reward信号比仅调整优化过程（DAPO等）效果更好。

5. **RAG先验显著提升ID和OOD性能**，但在训练时需排除查询样本本身以避免标签泄露。
6. **整数百分比表格式在精度、token效率和推理速度三者间取得最佳平衡**。
7. **跨数据集迁移能力优于数值型基线**：文本语义推理对数据集分布变化具有天然鲁棒性。

## 7. 优点

1. **方法设计的系统性与完备性**：从输入表示→CoT构建→监督信号→输出格式→RL奖励设计，每个环节均有明确问题导向和实证验证，形成完整闭环。
2. **输入表示的创新性**：固定token成本的混合文本-数值表示同时解决了token膨胀和可解释性问题，而且支持规则CoT的自动化构建——这一组合在时间序列LLM研究中具有较强新颖性。
3. **奖励设计贡献突出**：倒数奖励映射将GRPO从离散任务拓展到连续回归任务，理论推导（多项式衰减、正下界证明、归一化优势分离分析）与实证结果相互印证，对后续LLM+RL在回归场景的应用有借鉴意义。
4. **全面的OOD评估**：多种跨组别泛化实验（小→基础、小→混合、组内、组间）验证了方法学到的不是模型身份记忆，而是可迁移的时序推理能力。
5. **效率与性能的平衡**：采用1.7B轻量模型、规则CoT替代API、整数百分比表降低token开销，在保持高性能的同时大幅降低部署成本。
6. **可解释性**：CoT推理使集成决策透明可审计，并展示GRPO能改善推理质量（Weather案例），形成"更好的推理→更好的权重"的正向循环。

## 8. 不足与局限

1. **实验设置的单一性**：
   - 仅考虑单变量预测、固定长度96对96的设定；未验证长预测区间提示（如96→336/720）下的性能；
   - 数据集集中于能源/电力、交通、气象、经济等标准benchmark，缺少金融高频、医疗、社交等更多样化的时间序列场景。

2. **OOD实验的部分局限**：
   - 虽然OOD泛化实验全面，但个别数据集（如Traffic）上REATS-GRPO相对最优基线的优势较小（0.1409 vs OptW_val 0.1564仍有优势，但个别数据略差）；
   - 未见对动态变化（如概念漂移、数据分布渐变）适应性的评估。

3. **算力与资源细节缺失**：
   - 未报告GPU数量、训练时长、显存占用、SFT和GRPO各阶段的能耗等关键资源指标；
   - 也未对推理时延与零样本LLM推理成本做系统对比（仅有格式对比）。

4. **依赖训练集ground truth的oracle权重**：
   - SFT监督和GRPO奖励计算都依赖训练集oracle权重（QP求解）。虽然这是监督学习的常规设定，其在实际中是否可获取需据情况而定；
   - K′=10行多样权重的生成依赖QP求解，计算复杂度可能随候选模型数量N的增加而上升。

5. **RAG知识池的冷启动问题**：对全新任务域（训练集完全不可用）的表现未做评估；RAG知识池需要预构建并随候选模型变化而重建。

6. **与LLM类零样本方法（GPT等）对比的系统性**：
   - 零样本LLM未做任何微调但使用相同提示，REATS则经过SFT+GRPO训练，对比并非完全对等；但这是方法属性的自然差异，且REATS在同规模（1.7B）可获得性上具有优势。

7. **理论分析中近似假设**：例如，一阶泰勒近似将$\sigma_r \approx |r'(\bar\delta)|\cdot\sigma_\delta$，在$\delta$分布方差较大时可能不完全精确；对归一化优势的几何变化分析也依赖特定分布假设。

---

**总体评价**：REATS是LLM推理驱动集成学习在时间序列预测中的一次系统而深入的研究，方法设计精巧、实验充分、理论分析扎实，尤其在奖励函数设计与OOD泛化方面做出了有价值的贡献，为后续“LLM+RL”用于数值回归任务提供了坚实的参考基准。
