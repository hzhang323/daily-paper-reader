## 摘要
尽管深度学习模型在时间序列异常检测中已达到最先进的性能，但其复杂架构带来了大量推理开销。现有方法通常对所有数据点采用统一的推理策略，这效率低下，因为异常本质上稀少，且绝大多数时间数据由可预测的正常模式组成。为缓解这一瓶颈，我们提出CARE，一种模型无关的级联推理框架，将轻量级预过滤器模型（LPM）与现有高容量复杂检测模型（CDM）集成。LPM使用残差MLP自编码器和正态性条件门控机制快速过滤高置信度的正常样本。关键地，我们引入结构注意力模块以显式捕获通道级异常贡献，并通过置信度引导的选择性路由目标优化门控网络，该目标学习可靠的路由决策以减少不必要的CDM调用。在八个真实世界基准上的广泛实验表明，CARE有效隔离高置信度正常样本。通过仅将不确定样本路由到CDM，我们的框架相比最准确的SOTA方法实现2.7倍至4.8倍的推理加速，同时保持有竞争力的检测质量。

## Abstract
While deep learning models have achieved state-of-the-art performance in time series anomaly detection, their complex architectures incur substantial inference overhead. Existing methods typically apply a uniform inference strategy across all data points, which is inefficient given that anomalies are inherently scarce and the vast majority of temporal data consists of predictable normal patterns. To mitigate this bottleneck, we propose CARE, a model-agnostic cascaded inference framework that integrates a Lightweight Pre-filter Model (LPM) with an existing high-capacity Complex Detection Model (CDM). The LPM rapidly filters high-confidence normal samples using a Residual MLP AutoEncoder and a Normality-Conditioned Gating mechanism. Crucially, we introduce a Structure Attention module to explicitly capture channel-wise anomaly contributions, and optimize the gating network via a confidence-guided selective routing objective that learns reliable routing decisions to reduce unnecessary CDM invocations. Extensive experiments across eight real-world benchmarks demonstrate that CARE effectively isolates high-confidence normal samples. By routing only uncertain samples to the CDM, our framework achieves $2.7\times$ to $4.8\times$ inference speedup compared to the most accurate SOTA approaches, while still maintaining competitive detection quality.

## 2. 论文提出的方法论

**核心思想**：将推理过程分解为两级——轻量预过滤器模型（Lightweight Pre-filter Model, LPM）与高容量复杂检测模型（Complex Detection Model, CDM）。LPM 快速拦截高置信正常样本，仅将不确定/高风险样本路由至 CDM 进行精细评估。

**关键技术细节**：

- **时间序列预处理**：Z-score 标准化 + 滑动窗口切分，窗口大小为 L×C。
- **RMA（Residual MLP-based AutoEncoder）**：纯 MLP 自编码器，含残差连接，避免自注意力计算，快速完成重构。
- **NCG（Normality-Conditioned Gating）**：
  - **结构注意力（Structure Attention）**：计算通道级平方重构偏差 → 时间池化 → 可学习通道注意力向量（softmax 归一化）加权聚合，得到结构化异常特征 f_st。
  - **置信门控网络**：融合窗口级特征 f_win、点级特征 f_pot 与结构特征 f_st，经两层 MLP + Sigmoid 输出正态性置信度 P。
- **两阶段训练**：
  - 阶段一：仅用重构损失训练 RMA，避免语义漂移；
  - 阶段二：冻结 RMA 与 CDM，用 CDM 在训练集上的异常分数作为先验，优化 NCG。
- **Quantile-Anchored Margin Loss**：由二部损失（Bipartite Loss）、边界损失（Boundary Loss）和正则项组成，利用 CDM 分数排序加风险分位数划分高/低风险样本，学习可靠路由决策。
- **MLE-based 分数对齐**：对 LPM 与 CDM 的异常分数分别拟合 Log-Normal 分布，用 CDF 将分数映射到统一概率域，解决异构分数空间问题。
- **级联推理**：由阈值 τ 对应的分位数划分高置信集合 N 与不确定集合 U；N 直接用 LPM 分数，U 调用 CDM 后统一对齐。

## 7. 优点

- **模型无关**：CARE 可无缝集成任何输出连续异常分数的 TSAD 模型，通用性强。
- **思想简洁且动机扎实**：利用异常稀疏性与正常模式可预测性，以“级联路由”替代“统一复杂推理”，直击部署痛点。
- **结构注意力创新**：显式建模通道级异常贡献，克服 MLP 隐式均等融合的缺陷，提升门控可靠性。

- **实验设计全面**：多数据集、多 baseline、多指标、多 CDM、消融与稳定性分析齐全，并公开了推理时间、吞吐量等效率指标。
