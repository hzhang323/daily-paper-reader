## 摘要
生产环境中的 LLM 智能体会在其演进过程中被反复评估，但完整的智能体基准测试重新运行成本高昂。我们研究了一个服务于数万名月活跃用户的生产分析智能体的高效周期性评估，并报告了第一手部署经验。利用该生产基准的 574 次历史运行，按时间顺序划分为校准期和留出期，我们比较了随机抽样、历史缓存、固定代表性子集以及基于 IRT 的自适应测试。结果表明，多维 2PL 自适应测试实现了最佳的整体分数保真度：执行 200 道题，即完整运行的 38.5%，MAE 为 1.03 个百分点。尽管如此，我们仍因运行简便性部署了按难度分层的固定子集，并表明它们无需重新校准即可迁移到另外五个智能体系列，且在短至一天的校准窗口内保持稳定。基于这一部署经验，我们报告了用于周期性生产智能体评估的实用建议。

## Abstract
Production LLM agents are evaluated repeatedly as they evolve, but full agent benchmarks are costly to rerun. We study efficient recurring evaluation for a production analytics agent serving tens of thousands of monthly active users and report first-hand deployment experience. Using 574 historical runs of the production benchmark, split chronologically into calibration and held-out periods, we compare random sampling, historical caching, fixed representative subsets, and IRT-based adaptive testing. The results show that multidimensional 2PL adaptive testing achieves the best overall score fidelity: executing 200 questions, 38.5% of a full run, yields 1.03 pp of MAE. We nevertheless deployed difficulty-stratified fixed subsets because of their operational simplicity, and show they transfer without recalibration to five other agent families and remain stable across calibration windows as short as one day. Drawing on this deployment experience, we report practical recommendations for recurring production-agent evaluation.

## 2. 方法论
- **问题设定**：
  - 完整基准有 \(N=519\) 道题，运行 \(r\) 的题目级结果为 \(y_{ri}\in\{0,1\}\)。
  - 完整 pass rate 为 \(s_r=\frac{1}{N}\sum_i y_{ri}\)。
  - 部分评估执行子集 \(S_r\subseteq Q\)，给出估计 \(\hat{s}_r\)。
  - 效率用执行比例 \(|S_r|/N\) 衡量；目标是最小化 MAE，并最大化 Spearman/Kendall 排序相关。
- **方法一：随机抽样**
  - 均匀无放回抽取 \(k\) 道题，直接报告这些题的平均通过率。
  - 作为最直接的基线。
- **方法二：历史结果缓存**
  - 使用滚动历史窗口计算每题历史通过率 \(\bar{y}_{ri}\)。
  - 若 \(\min(\bar{y}_{ri},1-\bar{y}_{ri})\le \epsilon\)，认为该题稳定，缓存其近期多数判决，不执行。
  - 其余题执行，最终估计为“执行题结果 + 缓存题结果”的全基准平均。
  - 阈值 \(\epsilon\) 控制缓存激进度。
- **方法三：固定子集评估**
  - 从历史运行中一次性选出一个代表性子集，之后每次评估复用同一子集。
  - **子集选择策略**：
    - **难度分层**：用 Rasch 模型估计题目难度，排序后分成 \(k\) 层，每层选接近中位难度的题，并按层大小加权。
    - **历史响应 K-means**：用题目跨历史运行的 pass/fail 向量聚类，选靠近簇中心的题。
    - **IRT 特征 K-means**：用 2PL 的题目参数 \([\alpha_i;\beta_i]\) 聚类，选靠近簇中心的题。
  - **分数估计器**：
    - **加权子集估计**：只使用所选题，按其簇/层权重加权平均。
    - **gp-IRT 估计**：先用 p-IRT 根据当前运行在子集上的表现估计能力 \(\hat{\theta}_r\)，再预测未观测题并重建全基准；最后将加权估计与 p-IRT 重建按权重 \(\lambda\) 混合。\(\lambda\) 由 IRT 重建偏差和加权估计方差共同决定。
- **方法四：IRT 自适应测试**
  - 根据当前运行已观测结果，逐步选择下一道“最有信息量”的题。
  - **Rasch 自适应**：用 Fisher information \(p_i(1-p_i)\) 选择最大信息题。
  - **多维 2PL 自适应**：使用多维能力向量和 D-optimal 选择，优先降低能力估计的不确定性。
  - 因自适应选的是信息量高的题而非代表性题，最终用 p-IRT 重建完整 pass rate。
- **部署取向**：统计上多维 2PL 自适应最佳，但生产系统最终部署难度分层固定子集，原因是运维简单、执行负载可预测、支持题级比较，且可并行执行。
