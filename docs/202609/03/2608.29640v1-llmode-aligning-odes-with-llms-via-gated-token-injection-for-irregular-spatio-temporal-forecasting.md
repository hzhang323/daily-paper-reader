## 摘要
大型语言模型（LLM）在时空预测中展现出潜力，但现有方法通常依赖规则采样的令牌序列，并因时间异步、表示空间错位以及有限的上下文窗口而难以处理不规则观测。我们提出了LLMODE，一种基于冻结LLM骨干的高效令牌框架，用于不规则时空预测。LLMODE首先使用图感知ODE编码器将不规则图观测重建为连续时间潜在轨迹。固定预算感知器重采样器随后将该可变长度轨迹压缩为固定数量的动态记忆令牌。同时，紧凑的统计描述符被编码并重采样为上下文记忆令牌。双源门控交叉注意力模块将两种记忆注入冻结的LLM，从而实现对外部时空证据的受控利用。在三个真实世界城市数据集和两个物理动力学基准上的实验显示了具有竞争力的整体性能，在稀疏或动态复杂的不规则采样下优势更为明显。对未见城市区域的额外评估进一步证明了无需适应的强零样本泛化能力。

## Abstract
Large language models (LLMs) have shown promise for spatio-temporal forecasting, but existing approaches often rely on regularly sampled token sequences and struggle with irregular observations because of temporal asynchrony, representation-space misalignment, and limited context windows. We propose LLMODE, a token-efficient framework for irregular spatio-temporal forecasting with a frozen LLM backbone. LLMODE first uses a graph-aware ODE encoder to reconstruct irregular graph observations as a continuous-time latent trajectory. A Fixed-Budget Perceiver Resampler then compresses this variable-length trajectory into a fixed number of dynamic memory tokens. In parallel, compact statistical descriptors are encoded and resampled into context memory tokens. A dual-source gated cross-attention module injects both memories into the frozen LLM, enabling controlled utilization of external spatio-temporal evidence. Experiments on three real-world urban datasets and two physical-dynamics benchmarks show competitive overall performance, with clearer advantages under sparse or dynamically complex irregular sampling. Additional evaluations on unseen urban regions further demonstrate strong zero-shot generalization without adaptation.

## 2. 论文提出的方法论

### 2.1 核心思想

LLMODE 的整体思路是：**先用图感知ODE把不规则观测变成连续的潜在轨迹，再用固定预算的感知器重采样把变长轨迹压缩成少量动态记忆token，同时用统计描述符构造上下文记忆token，最后通过双源门控交叉注意力将两种记忆注入冻结LLM，以查询槽（query-slot）对应的隐藏状态映射为预测结果。**

### 2.2 三大模块（关键公式与流程）

1. **图感知ODE编码器**
   - 每个节点 \(v\) 的潜在状态 \(h_v(t)\) 由常微分方程 \(\frac{dh_v(t)}{dt}=f_\theta(h_v(t))\) 控制，\(f_\theta\) 采用GRU-ODE参数化。
   - 当新观测 \(x_{v,i}\) 到达时：
     - ODE求解器先在时间间隔内传播得到 \(h_v(t_i^-)\)；
     - 观测编码器 \(\Phi\) 计算预测均值/方差与观测的标准化差异，构造描述符并映射为embedding；
     - 通过更新公式 \(h_v(t_i^+) = \mathrm{GRU}(h_v(t_i^-), \Phi(x_{v,i}, h_v(t_i^-)))\) 对状态进行修正；
     - 再通过相对消息传递与门控图残差更新得到图感知状态 \(\bar{h}_v(t_i^+)\)。
   - 将各时刻所有节点的状态堆叠为连续时间潜在轨迹 \(H_{dyn}\in\mathbb{R}^{N\times L\times d_{ode}}\)。

2. **固定预算感知器重采样器**
   - 使用 \(K\) 个可学习的潜变量查询 \(q_k\) 对轨迹做交叉注意力；
   - 注意力权重中引入**动力学感知偏置**：\(\alpha_{k,i}=\mathrm{softmax}_i(q_k^\top k_i/\sqrt{d_{mem}}+\beta\cdot\mathrm{Norm}(\|\dot{h}(t_i)\|_2))\)，使快速变化区间被优先保留；
   - 对每个输出 \(z_k\) 通过注意权重计算中心时间 \(t_k^{center}\)，并用正弦特征编码为时间标签，加到输出上形成时间感知的动态记忆token \(\tilde{Z}\in\mathbb{R}^{K\times d_{mem}}\)。

3. **双源门控交叉注意力模块**
   - 除动态记忆 \(\tilde{Z}\) 外，将观测历史整理为分段统计的文本描述，经文本编码器和重采样器得到上下文记忆 \(P\)；
   - 注入公式：
     - \(\Delta_{mem} = \lambda\mathrm{CrossAttn}(Y,\tilde{Z})+(1-\lambda)\mathrm{CrossAttn}(Y,P)\)
     - \(\hat{Y}=Y+\alpha_{attn}\Delta_{mem}\)
     - \(Y'=\hat{Y}+\alpha_{ffn}\mathrm{FFN}(\hat{Y})\)
     - \(\alpha_{attn}=\tanh(g_{attn})\), \(\alpha_{ffn}=\tanh(g_{ffn})\)，初始化为0，保证训练开始时是恒等映射。
   - 对Vicuna-7B，插入在第1层和第16层Transformer之后；提示中包含与预测时间戳对应的查询槽token，其最终隐藏状态经轻量回归头输出预测。

## 6. 论文的主要结论与发现

- **整体有效性（Q1）**：LLMODE在五个基准上整体性能具有竞争力，平均相对改进6.3%；在NYCcrime、Springs、Charged等稀疏/动态复杂场景下优势最明显；在稠密移动性数据上的提升较小（归因于测试集分布过度集中）。
- **零样本泛化（Q2）**：在未见80个城市区域的设置下，LLMODE在6项指标中5项最优，平均相对改进11.4%；在极稀疏的NYCcrime上泛化优势尤为突出。
- **连续时间建模的必要性（Q3）**：随着缺失率增加，离散ST编码器替换版（ST-Encoder）性能下降显著快于LLMODE；LLMODE在20%–80%缺失率下始终保持最低误差，差距随缺失率加大而扩大。
- **固定预算动态证据的有效性（Q4）**：K=5或K=8即可实现最佳精度-效率权衡，继续增加预算（K=30、K=90、甚至无压缩全轨迹）无一致增益；学习式重采样优于随机选取和线性投影；引入动力学偏置和显式时间标签均有正向贡献。
- **冻结LLM的价值（Q5）**：
  - 冻结LLM与MLP/随机Transformer在监督场景下性能接近，但在零样本场景下显著更优（Ze-ro-shot MAE从0.1131/0.0925降至0.0801），说明预训练语义能力对迁移至关重要；
  - 不同冻结骨干（Vicuna-7B、Llama-3.1-8B、Llama-2-13B）性能一致，表明该框架适用于多种LLM；
  - 门控交叉注意力优于普通交叉注意力，明显优于提示拼接；动态记忆和上下文记忆互补，打乱上下文会显著降性能。
- **令牌效率**：在NYCbike零样本上，相比UrbanGPT减少89.2%的令牌数，取得约7.7倍推理加速，同时精度更高。

## 7. 优点

- **方法论创新点突出**：
  - 将不规则图观测建模为连续时间ODE轨迹，从底层机制上解决了时间异步问题；
  - 用固定预算重采样器将长轨迹压缩为少量记忆token，兼顾信息保留与上下文长度约束；
  - 在注意力中直接注入瞬时动力幅度，使重采样保留"变化最快"的信息状态，具有物理直观性；
  - 双源门控交叉注意力设计为从零初始化的恒等映射，保证冻结LLM在训练初期不被破坏，且注入强度可通过门控自适应控制。

- **资源-效率视角**：在部署方面给出了token数和推理延迟的定量对比，说明方法在追求精度的同时兼顾实际可用性。

- **对稠密规则采样数据的增益不大**：在NYCtaxi inflow上近乎与ISTS-PLM打平，论文将其归因于测试分布过于集中，但仍表明连续时间建模在密集数据下的优势有待验证——是否值得为常规密集任务付出LLM推理开销存在疑问。
- **推理延迟仍高于非LLM方法**：LLMODE约84ms/sample，相比MTGNN/tPatchGNN的约10ms仍有数量级差距；论文虽将其限定为"LLM内部效率对比"，但真实场景中的端到端部署成本仍是短板。
