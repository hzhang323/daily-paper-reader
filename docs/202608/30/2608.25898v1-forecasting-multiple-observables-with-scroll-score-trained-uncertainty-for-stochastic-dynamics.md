## 摘要
预测随机动力系统很少意味着一个单一数值：人们希望得到几个可观测变量——未来状态、阈值事件、状态标签——每个都有自己的似然。标准的多任务方法会平衡每个任务的损失，通过调整或学习得到。相反，我们在共享主干网络上，将可观测量的似然组合到每个任务自由路由的最后一层信念中；这将依赖单位的损失缩放吸收到同一梯度更新中学到的似然参数中。随机动力学提供了静态基准无法提供的东西：预测方差的可计算真值。结果与理论预期一致：在良好指定、同方差的奥恩斯坦-乌伦贝克过程上，学习到的预测法则恢复了解析核，并且正确指定的基线持平。在异方差系统（随机Lorenz-63，真实空气质量数据）上，信念的输入依赖方差表现出优势：在状态和状态标签任务上取得最佳单次运行负对数似然（NLL），其校准性能仅被那些NLL被其击败的变体所匹配，而成本仅为调参网格的一小部分。在真实时间序列上，状态边际在五个滚动起点上保持一致。

## Abstract
Forecasting a stochastic dynamical system rarely means a single number: one wants several observables---future state, threshold event, regime label---each with its own likelihood. Standard multi-task recipes balance per-task losses, tuned or learned. We instead compose the observables' likelihoods in per-task free-routed last-layer beliefs on a shared backbone; this absorbs unit-dependent loss scaling into likelihood parameters learned in the same gradient pass. Stochastic dynamics supply what static benchmarks cannot: computable ground truth for the predictive variance. Results land where theory puts them: on the well-specified, homoscedastic Ornstein--Uhlenbeck process the learned predictive law recovers the analytic kernel and correctly specified baselines tie. On heteroscedastic systems (stochastic Lorenz-63, real air-quality data) the belief's input-dependent variance separates: best single-run NLL on the state and regime tasks, calibration matched only by arms whose NLL it beats, at a fraction of the tuned grids' cost. On the real series the state margin holds across five rolling origins.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在预测随机动力系统时，往往需要同时输出多个可观测量（如未来状态、阈值/屏障事件、状态标签），每个观测量都有自己的似然函数。标准多任务学习（MTL）采用加权求和各任务损失的方式，权重需要网格搜索（随任务数指数增长）或由学习得到（如Kendall等，2018）。
- **现有方法的缺陷**：单纯的权重缩放只能重新调整损失大小，却无法改变每个任务似然函数的结构。例如，一个使用交叉熵（CE）头部的模型，如果其边界无法表示阈值事件的偏移量，那么无论怎么调整权重，都不能修复这一结构性缺陷。而阈值似然（probit）通过可学习的切点可以自动吸收偏移。
- **论文主张**：采用贝叶斯路线——在共享骨干网络上，为每个可观测量保留独立的观测模型和独立的高斯最后一层信念（belief），将多任务目标自然地组合成各个任务共享腔（shared-cavity）损失之和。该方法称为SCROLL-MT。
- **核心动机**：随机动力学系统提供了静态基准无法提供的东西——预测方差的可计算真值（ground truth），因此可以严格检验所学预测法则的最优性。此外，多任务中损失的单位不匹配问题可以通过似然参数的隐式学习自动吸收，无需外在的权重搜索。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心思想

- **SCROLL-MT**：在共享骨干（shared backbone）ψ 上，为每个任务 k 独立定义：
  - 似然函数 p_k(y_k | w_k^T ψ; η_k)，参数 η_k（高斯任务的η_k为噪声尺度σ_obs，分类任务为probit切点）；
  - 最后一层信念 q_k(w_k) = N(μ_k, Σ_k)（高斯分布）；
  - 先验 p_αk(w_k) = N(0, α_k^{-1} I)。
- **自由路由（free-routing）**：不强制把信念绑定到某种后验形式（如共轭后验），而是将 (μ_k, Σ_k) 作为直接优化变量，由目标函数本身选择信念，使预测方差能追踪输入相关的条件方差。

### 2.2 目标函数（公式（1））

\[
F_{MT} = \sum_{k=1}^{K} \left[ -\sum_{n=1}^{N} \log \int p_k(y_n^{(k)} | w_k^T \psi_n; \eta_k) q_k(w_k) dw_k - \log \int p_{\alpha_k}(w_k) q_k(w_k) dw_k \right]
\]

- 每个任务的数据项就是该任务的边缘预测的负对数似然（负对数分数），即 log score。由于 log score 是严格适当的（strictly proper），在可表示的条件下，其总体风险的最小化对应真实条件分布。
- 每个任务的先验项（与观测无关）随 N 增长相对贡献趋于零（在 o(N) 条件下），因此总体目标在渐近意义下达到分数最优。
- **隐式任务加权**：所有数据项都以 nats 为单位，任务以单位系数进入目标，无需手动设置单位平衡权重。σ_obs、α_k 等作为普通目标参数在同一梯度步中学习。
- **尺度等变性（Proposition 1）**：若将某高斯任务的标签乘以 c，只需将 (μ, Σ, σ_obs², α) 相应映射为 (cμ, c²Σ, c²σ_obs², α/c²)，目标函数只改变与 c 有关的常数，最小化器不变。而固定加权损失则需要重新调整其他任务的权重，否则最优解偏移。

### 2.3 预测形式与实现

- 高斯任务（回归）：预测方差 V_n = σ_obs² + ψ_n^T Σ ψ_n，直接用于 NLL 计算。
- 二分类（阈值事件）：probit 模型，P(y=1|x_n) = Φ((μ^T ψ_n - τ_1)/D_n)，其中 D_n = √(c² + ψ_n^T Σ ψ_n)，c=1.005（固定，保证可辨识），切点 τ 可学习。
- 有序分类（序数标签）：ordinal-probit，桶质量由两个切点之间的概率差给出，切点参数化为严格递增 τ_r = τ_1 + Σ_{j<r} e^{δ_j}。
- 所有积分一维高斯积分闭式可解。

## 3. 实验设计：使用了哪些数据集 / 场景，它的 benchmark 是什么，对比了哪些方法

### 3.1 数据集/场景

1. **Ornstein–Uhlenbeck (OU) 过程**：一维线性 SDE，同方差，V*(Δ) 解析已知（σ²/(2θ)(1 - e^{-2θΔ})），作为 well-specified 且同方差的锚点。
2. **随机 Lorenz-63 系统**：三变量混沌系统加噪声，异方差（条件标准差 p10/p90 = 1.5/8.4），没有解析解，通过蒙特卡洛重模拟（200 个成员/状态）计算每个状态的 V*(x)。
3. **北京 PM2.5 真实数据**（2010–2014 小时数据）：无计算真值，任务由监管要求确定（状态、事件、频带），用于检验真实数据上的泛化能力（滚动时间起点验证）。

每个数据集上 K=3 个任务：状态回归（lead Δ后的状态值）、阈值事件（如 O U 中 X≥1.5；Lorenz 中 x>0；PM2.5 中 24 小时均值>75μg/m³）、序数标签（窗口平均值或未来状态的四分位数）。

### 3.2 对比方法

- **SCROLL-MT**：三种信念协方差结构：None（无信念，仅学习 σ_obs）、Diag（对角 Σ）、Full（自由 Σ）。默认报告 Diag。
- **MAP 基线**：CE 或 probit 头部，固定 λ=1 或 49 点网格搜索（λ1, λ2 ∈ {0.01,...,30}²）。
- **Kendall 不确定性加权**：学习每任务 log 尺度。
- **MLE σ(x) 臂**：Nix & Weigend 式，添加输入依赖的回归标准差头，所有损失以 NLL 训练（无信念）。

- **深度集成（Ens-5）**：5 个种子重训练的集成。

所有方法共享相同的候选架构（单隐层宽度 H=50，四种骨干变体 relu / relu+LN / tanh / tanh+LN），每个数据集/种子按验证损失选择骨干。训练协议：Adam，lr=0.03，最多 5000 步，早停，全批量，10 个种子。

## 6. 论文的主要结论与发现

- **同方差锚点（OU）**：SCROLL-MT 的预测总标准差在每一 lead 下与解析 V*(Δ) 相差 ≤2%，恢复了解析核；所有方法都达到熵下界（正确指定），但 SCROLL-MT 没有引入额外虚假方差（50 维信念项被先验压缩）。
- **异方差系统（Lorenz）**：
  - 自由路由的对角信念 Diag 在状态任务上单次运行 NLL 最佳（2.333），Full 更好（2.230）；Full 在状态和序数任务上都显著优于公平网格，事件任务持平。
  - 预测方差 V_n 与蒙特卡洛 V*(x_n) 的 Pearson 相关为 0.61（Diag）和 0.85（Full），秩相关 0.56/0.66；闭环路由的方差几乎平坦（跨度 <1.3×，而 V* 跨度 284×）。
  - MLE σ(x) 方法可以匹配校准误差但在 NLL 上输掉；Laplace 后验无法带来同样收益；无信念的 None 回到 MAP 水平。
- **真实数据（PM2.5）**：
  - SCROLL-MT (Diag) 在三个任务（reg/evt/ord）上单次运行均取得最优或统计持平的最优 NLL（1.250 / 0.450 / 1.203），校准误差 0.024。
  - 状态任务的优势在五个滚动时间起点上一致保持（相对各权重基线 -0.061 到 -0.088 nats，约 4.8 个起源间标准误）。
  - Full 在真实数据上比 Diag 差（过参数化、序数头对膨胀信念敏感）。
- **权重的作用**：
  - 在 OU 和 PM2.5 上，权重网格相对于固定 λ=1 几乎无改进；在 Lorenz 上网格有收益（0.25 nats），但成本高出 13-18 倍，且 SCROLL-Full 能更好地完成。
  - 隐式权重学习（Kendall）在 Lorenz 上表现最差（回归 NLL 2.798，校准误差大），说明输入依赖方差是稳定性的关键。
- **理论验证**：Corollary 1（分数最优性）在异方差系统上得到验证；Proposition 1（尺度等变性）在实验中通过映射热启动精确恢复（0.000±0.000 nats 差距），整个残差由优化器而非目标函数产生。
- **共享骨干**：OU 上免费共享，Lorenz 上付出 0.06-0.07 nats 干扰代价，PM2.5 上离散任务间共享有帮助。

  - 组合目标只是边际分数的求和，没有显式建模同一观测窗口内不同可观测量的联合依赖（如残差相关性）；论文仅在附录中以扩展探针说明其可行性，但没有在主实验中考虑这一点。
- **计算资源信息缺失**：
  - 未报告 GPU/CPU 型号、并行度、能耗等，仅给出以秒计的时间，不利于复现和资源估算。
- **“无任务权重”的表述需限定在固定任务清单下**：如果将同一个观测量列两次，其数据项就会翻倍，相当于人为改变了权重——任务清单的选择本身是一个设计杠杆，论文只是承认但没有系统探索。
