## 摘要
在长上下文时间序列中进行精确异常定位是临床护理、工业运营、金融服务和物流等监控应用中的关键任务，在这些场景中，简短证据可能隐藏在高频数据的长跨度中。时间序列语言模型（TSLM）能够摄取时间序列数据，并以自然语言表述异常发现；然而，最近的基准测试报告显示，在长上下文下检索性能下降，这反映了文本、视觉和音频中的失败模式。在文本领域，递归语言模型（RLM）通过将上下文保留在大语言模型（LLM）外部，允许模型通过代码查询上下文，从而可以恢复大部分丢失的性能。我们提出了TimeRLM，一种用于时间序列的RLM公式，通过代码和视觉能力顺序地操作信号。我们进一步引入了AnomalyXL，一个带有程序化注入异常的综合长上下文异常定位基准，该基准需要精确检索。我们实现了五种不同的任务类别和两种变体：AnomalyXL-MCQ和AnomalyXL-Localize。在AnomalyXL-Localize的五个任务中，TimeRLM在四个任务上优于所有评估的TSLM和单次基线，在定位上达到0.682的IoU，在带证据分类上达到0.745，而所有基线的最高分别仅为0.329和0.072。我们使用强化学习对TimeRLM进行后训练。所得模型进一步提高了性能，并且产生最终答案所需的智能体交互轮次约为其未训练基础模型的三分之一。在未见过的真实世界心电图、睡眠和软件可观测性记录上，后训练的TimeRLM保持或提高了性能，尽管仅在合成数据上训练，却超过了TSLM。我们的研究结果表明，与时间序列的递归交互是长时域检索的有效方法。

## Abstract
Precise anomaly localization over long-context time series is a crucial task in monitoring applications across clinical care, industrial operations, financial services, and logistics, where brief evidence may hide inside long spans of high-frequency data. Time-Series Language Models (TSLMs) are able to ingest time series data and verbalize findings on anomalies in natural language; however, recent benchmarks report a decrease in retrieval performance at long contexts, mirroring failure modes in text, vision, and audio. In the text domain, Recursive Language Models (RLMs) can recover much of this lost performance by keeping context external to the large language model (LLM), allowing the model to query it through code. We present TimeRLM, an RLM formulation for time-series that sequentially manipulates the signal using code and vision capabilities. We further introduce AnomalyXL, a synthetic long-context anomaly localization benchmark with programmatically injected anomalies that require precise retrieval. We implement five different task categories and two variants: AnomalyXL-MCQ and AnomalyXL-Localize. TimeRLM outperforms every evaluated TSLM and single-pass baseline on four of the five AnomalyXL-Localize tasks, reaching 0.682 IoU on localization and 0.745 on classify-with-evidence, versus at most 0.329 and 0.072 across all baselines. We post-train TimeRLM using reinforcement learning. The resulting model further improves performance and requires approximately one-third as many agent interaction turns as its untrained base model to produce a final answer. On unseen real-world ECG, sleep and software observability recordings, the post-trained TimeRLM retains or improves performance, surpassing TSLMs despite being trained exclusively on synthetic data. Our findings suggest recursive interaction with time-series is an effective approach for long-horizon retrieval.

## 2. 论文提出的方法论

### 2.1 TimeRLM 公式（核心思想）

**R L M 公式（递归语言模型公式）**
- 将完整时间序列存储为**沙箱环境中的 JSON 变量**（环境变量），而非放进模型上下文窗口。
- 模型通过**多轮动作**操作信号：
  - 策略（policy）πθ（即根 LLM）在每一步选择动作，动作空间为 A = C ∪ {FINAL(ŷ)}；
  - C 表示在 Python REPL 沙箱中**执行代码**（可访问 numpy、scipy 等标准数据科学库），每次执行返回观测结果；
  - FINAL(ŷ) 表示提交结构化 JSON 答案并终止回合；
  - 回合结束时获得单一可验证奖励 r(ŷ, y) ∈ [0,1]。
- 单次（single-pass）预测是 N=1 特例：无代码动作，直接从"信号 + 问题"的初始观测回答。

**三种变体配置**
1. **Text 变体**：模型通过代码（numpy/scipy）对信号进行统计分析；
2. **Image 变体**：沙箱额外提供 Python 视觉库，模型可渲染信号图为图像并通过视觉感知；
3. **递归子智能体（sub-RLMs）**：模型可递归地调用自身的子实例处理全量或部分时间序列。

### 2.2 AnomalyXL 基准构造

**核心参数**
- 样本上下文长度：**16k–131k 数据点**，最多 **16 通道**；
- 每通道 z 归一化（保证注入异常的尺度可比）；
- 由随机噪声过程（白噪声、红噪声、AR(1)）加可选周期/趋势成分合成场景。

**异常类型（5 种 + 无异常）**
- 瞬态尖峰（Transient Spike）：三角形脉冲；
- 电平偏移（Level Shift）：符号持续阶跃；
- 趋势变化（Change in Trend）：斜坡后保持；
- 方差变化（Change in Variance）：注入额外高斯噪声；
- 季节性变化（Change in Seasonality）：叠加新正弦；
- No anomaly（无异常）作为一级负例。

**两种评测形式（基于完全相同底层信号）**
1. **AnomalyXL-MCQ**：固定选项集，F1 评分，覆盖 6 个类别（存在性、起始时间、类型、幅度范围、受影响通道、超前/滞后指示）；
2. **AnomalyXL-Localize**：结构化 JSON 精确输出，使用连续评分指标：
   - Localize：IoU；
   - Classify-with-evidence：kind × IoU（错误类型得零分）；
   - Measure magnitude：相对误差线性衰减（50% 误差归零）；
   - All-channels：事件集合匹配 F1（IoU > 0.3）；
   - Lead-lag：方向正确 + 偏移误差容限。

### 2.3 强化学习后训练

- 使用 **GRPO（Group Relative Policy Optimization）**，Qwen3.5-4B 全参数训练，无监督 warm start；
- 训练数据由**生成器在训练循环中实时合成**（每次迭代全新样本，无重复）；
- 奖励函数引入惩罚项：
  - Rᵢ = sᵢ − λ_tok·sᵢ·κᵢ − λ_fail·1{forced final}；
  - κᵢ 为组内归一化 token 代价（相对于同组最啰嗦 rollout 的比例）；
  - token 代价惩罚仅作用于任务奖励非零的 rollout；
  - 强制终止惩罚 λ_fail = 0.25。
- 超参数：300 步，组大小 G=8，batch 128，训练序列长 64k token，每 episode 上限 15 轮；
- 前 220 步不引入无异常样本（防止策略过早依赖"no anomaly"答案），之后恢复。

## 6. 论文的主要结论与发现

### 结论一：MCQ 形式高估了 TSLM 的检索能力
- 经典基线（特征 + GBT）在 MCQ 上平均达 0.81（超过所有 LLM/TSLM/RLM），但在精确 Localize 下骤降至 0.30；
- 说明 **MCQ 任务可以从聚合统计量中求解**，无需精确定位——现有 TSLM 基准的"高表现"掩盖了其真正检索缺陷。

### 结论二：递归交互显著增强精确异常定位能力
- 在 AnomalyXL-Localize 上：
  - TimeRLM（image, GPT-5.5）Localize IoU 达 **0.682**，单次最优仅 0.329；
  - Classify-with-evidence 达 **0.745**，所有基线 ≤ 0.072；
  - 递归 depth=1 进一步提升 C+E 至 0.745、LAC 至 0.551；
- RLM 的优势随上下文长度而增大——单次 image 从 L=16k 的 0.48 降至 L=131k 的 0.16，而 RLM 稳定在 0.61–0.79。

### 结论三：RL 后训练能提升性能并降低交互成本
- Qwen3.5-4B RLM 经 RL 训练后，Localize IoU 从 0.205 升至 **0.538**（超过 32B Toto 的 0.323 和单次 GPT-5.5 的 0.329）；
- C+E 从 0.001 升至 0.364；
- **交互轮次降至未训练基础模型的约三分之一**（token 代价惩罚的直接效果）。

### 结论四：合成数据训练可迁移至真实世界
- TSLM（ChatTS/OpenTSLM/ITFormer/Toto）在未见临床数据上 IoU 均 ≤ 0.004；
- RL 后训练的 TimeRLM 在 LTAF 上 F1 从 0.36 升至 0.45、Sleep-PSG 上从 0.17 升至 0.34；
- 作者推测原因：**代码推理提供了信号无关的学习环境**——动作空间跨信号分布不变，模型学到的是通用异常定位流程。

### 结论五：ARFBench 上的交叉验证
- TimeRLM-image（GPT-5.5）在 ARFBench Tier 2 上准确率 61.4%、macro-F1 57.9%，均领先所有基线；
- 与 AnomalyXL-MCQ 的相对表现模式一致，说明两个基准的行为具有可比性。

## 7. 优点

### 方法层面
1. **新颖的范式迁移**：首次将文本领域验证的 RLM 范式系统性地引入时间序列分析，理论动机清晰；
2. **外部化上下文的优雅设计**：信号作为环境变量，模型通过代码进行多轮交互，绕过了固定上下文窗口的长度限制和压缩瓶颈；
3. **"决策过程"的形式化**：将异常定位表述为有限时域顺序决策问题，与 RL 训练框架自然衔接；
4. **细粒度的评分设计**：按任务设计了 IoU、kind×IoU、线性衰减、集合匹配 F1 等连续评分，避免 MCQ 的二值化信息损失；
5. **RL 训练与生成器集成**：实时合成数据避免过拟合固定训练集，是训练-评估闭环设计的亮点。

### 实验层面
1. **长时域性能分解**：图 3/4 提供逐长度、逐类别分析，清晰展示了单次模型与 RLM 的性能分水岭；
2. **配对（paired）基准设计**：MCQ 与 Localize 共用相同底层信号，隔离了"信号内容"与"评测格式"两个变量；
3. **泛化集选取真实临床数据**：LTAF（心电图）与 Sleep-PSG（睡眠呼吸）覆盖了多样化的真实异常形态；
4. **开源完备性**：生成器、RL 环境、评测代码和数据全部开源（GitHub: OpenTSLM/TimeRLM）。

## 8. 不足与局限

### 实验覆盖与数据层面的局限
1. **合成基准的形态有限**：异常事件完全由参数化模板生成，无法覆盖真实世界中语义模糊、依赖上下文的异常；
2. **泛化集仅覆盖临床域**：未验证工业、金融、物流等其他长上下文应用场景；
3. **泛化集异常比例受限**：每窗口最多一个异常，未测试多异常、交错异常的复杂场景；
4. **窗口采样存在选择偏差**：LTAF/Sleep 窗口经过筛选（排除邻近注释异常），无法代表所有真实记录分布。

### 方法层面的局限
1. **标量答案任务（测量幅度）提升有限**：RLM 相对单次模型在 Memory Magnitude 任务上几乎无增益（0.480 vs 0.440），说明递归交互对需要精确数值估计而非定位的任务帮助有限；
2. **交互成本较高**：即使 RL 后降到基础模型的约 1/3 轮次，远高于单次模型；image 变体平均比 text 多用 3.1 轮，实际应用延迟可能成为瓶颈；
3. **图像优势未迁移到 RLM**：图像变体在 RLM 中并未优于 text 变体（IoU 0.682 vs 0.677），但 token 成本更高——图像路径的边际价值存疑；
4. **RL 后训练的本地化性能仍未解决**：虽然 F1 提升，但 RL 后训练在 LTAF/Sleep 上的 IoU 仍接近 0（0.016/0.002），说明**精确的时间边界定位在跨域迁移中仍然是开放问题**。

### 对比公平性与偏差风险
1. **Toto 与其他 TSLM 不对等**：Toto 使用 32B VLM 骨干、预训练于真实观测数据、已有异常定位后训练，而其他 TSLM 共享 4B 骨干——直接比较有失公平；
2. **经典基线"知识内建"**：手工特征设计本身编码了任务知识（如 PELT、矩阵轮廓等），其高 MCQ 表现部分来自"作弊式"的先验注入；
3. **缺少纯文本单次模型的全上下文对照**：单次 text 变体通过降采样适配上下文长度，降采样可能掩盖了模型在完整分辨率下的真实能力边界。

### 计算与复

### 计算与复现性层面的局限

1. **算力细节披露不足**：论文未给出具体 GPU 型号与数量、RL 300 步的实际墙钟时间、以及 8 次 SFT 微调与 RL 训练的总算力开销，外部研究者难以准确评估复现成本与可行性；
2. **RL 训练的超参数敏感性未做系统消融**：token 代价惩罚系数、强制终止惩罚 λ_fail、无异常样本引入时点（前 220 步）等关键设计，均只给出最终设定值而未展示敏感性分析；
3. **评测代码与生成器虽已开源，但 RL 训练管线（含 GRPO 实现、沙箱环境、reward 计算细节）的复现复杂度较高**，非标准 LLM 训练栈，需要额外工程投入。

### 其他值得注意的局限

1. **缺少对"推理失败模式"的诊断分析**：论文未详细分析 RLM 在哪些信号形态或异常类型上仍然失败（如低信噪比尖峰、多通道耦合异常），也未报告错误案例的定性展示；
2. **未探讨模型幻觉风险**：代码执行返回的观测是真实统计量，但模型仍可能在 FINAL 阶段编造未验证的数值——论文未讨论这种"基于真实观测但生成虚假推理"的混合幻觉问题；
3. **单通道 vs 多通道的归纳规律未揭示**：基线在 16 通道上的检索退化是否比单通道更严重，RLM 的多通道扩展性如何，论文缺乏相应分解实验；
4. **对"递归子智能体"的分析较浅**：虽然报告了 depth=1 带来了提升，但未说明子智能体何时被调用、内部处理了哪些子区间、递归的收益在哪些任务类别上最大。

## 9. 改进方向与开放问题

### 可直接推进的改进方向

1. **成本-精度自适应策略**：引入早期退出（early exit）机制，让模型先做低成本粗略诊断，仅在疑似异常时调用更多代码轮次，缓解交互延迟问题；
2. **混合粒度检索**：结合文本 RLM 中已验证的"先粗后细"模式（如先检索显著统计量、再聚焦局部窗口），在 action space 中显式加入"缩放/聚焦"原语；
3. **跨域 RL 数据增强**：将更多真实遥测与临床采样纳入 RL 训练循环（而非仅在合成生成器上训练），有望进一步改善跨域 IoU 接近于零的现状；
4. **引入多异常与无异常校准**：当前基准每窗口最多一个异常，可扩展为多异常、重叠异常、以及更难判定的"弱异常"（低信噪比），检验 RLM 的查全 vs 查准权衡；
5. **对图像变体做更审慎的评估**：既然 image 变体在 RLM 中未显著优于 text 变体但成本更高，未来应探索"何时图像真正必要"的条件性使用策略。

### 尚未回答的关键开放问题

1. **递归交互的上限在哪里？** 当前只验证了 depth=1 和最多 15 轮交互，更深的递归与更长的交互能否持续带来收益，是否存在收益饱和点？
2. **RLM 的长尾泛化能力**：合成信号之间的分布偏移（不同噪声过程、不同生成器）对 RL 后策略的鲁棒性影响如何？
3. **与专用异常检测算法的关系**：RLM 的代码动作空间实际上覆盖了经典算法的能力（PELT、矩阵轮廓等），那么 RLM 是否可以视为"可学习的算法组合器"？其与 AutoML 式检测器组合的性能对比值得探索；
4. **真实世界长上下文基准的缺失**：何时能有与 AnomalyXL 类似规模的、带精细标注的真实长时域异常基准，以更严格地检验 RLM 范式的临床与工业落地价值？

## 11. 一句话总结

> TimeRLM 通过将时间序列外部化为沙箱环境、让语言模型以代码驱动多轮递归交互的方式，系统性地解决了长上下文时间序列中"一次性吞入"式 TSLM 检索能力急剧退化的问题，并借助合成数据 + GRPO 后训练实现了对真实临床信号的迁移；然而，精确时间边界定位在跨域场景下仍未攻克，且 Toto 等基线的不对等比较使其"SOTA"主张需要审慎看待。
